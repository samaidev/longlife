# 巨噬细胞极化失衡：M1/M2 开关与抗衰干预

> 巨噬细胞极化（Macrophage Polarization）是 2023 年 López-Otín 团队在 *Cell* 上更新衰老标志框架（"Hallmarks of Aging: An Expanding Universe"）时**新增的第 10 项标志**。本文按"起源 → 极化分类 → 信号机制 → 代谢重编程 → 衰老失衡 → 疾病后果 → 干预"全链条展开，并贯穿本库 NO 主线视角。

---

## 一、核心概念

**一句话定义**：巨噬细胞极化是指巨噬细胞在微环境信号驱动下，向促炎杀菌的 **M1 型（经典活化，classically activated）** 与抗炎修复的 **M2 型（替代活化，alternatively activated）** 两端分化的可塑性过程；衰老中这一平衡被打破，表现为 M1 偏向增强、M2 修复功能衰退，驱动慢性炎症与组织纤维化。

**为什么重要**：巨噬细胞是固有免疫的核心执行者，也是组织稳态、损伤修复、代谢调控的枢纽。极化失衡不是孤立事件——它既是**慢性炎症（第 12 项标志）** 的放大器，又是**细胞衰老 SASP（第 7 项标志）** 的重要来源，还直接参与动脉粥样硬化、肥胖、纤维化、肿瘤与神经退行性疾病（详见第七节）。2023 年将其单列为衰老标志，标志着免疫-代谢-组织损伤交叉研究从"现象描述"进入"可干预靶点"阶段。

**与抗衰的关系**：极化开关是少数**双向可逆**的衰老相关过程——重极化（re-polarization）策略在动物模型中可逆转纤维化、改善代谢与血管功能。由于 M1 的核心效应分子正是 **iNOS 催化产生的 NO**（详见第五节），巨噬细胞极化与本库的 NO 主线形成天然交汇：NO 既是 M1 的武器，又是 M2 的调节信号，浓度与来源决定角色。

---

## 二、巨噬细胞起源：组织驻留 vs 单核细胞来源

传统"单核吞噬系统"（mononuclear phagocyte system, MPS）学说认为巨噬细胞全部由骨髓单核细胞分化而来。2010 年前后的**谱系追踪（fate mapping）革命**推翻了这一观点：

| 特征 | 组织驻留巨噬细胞（TRM） | 单核细胞来源巨噬细胞（MDM） |
|---|---|---|
| 胚胎起源 | 卵黄囊（yolk sac）与胎肝造血 | 骨髓造血干细胞 → 单核细胞 |
| 发育时相 | E8.5 卵黄囊原始造血 / E12.5 胎肝 | 出生后持续补充 |
| 自我更新 | 局部增殖（M-CSF/IL-34 依赖） | 依赖循环单核细胞浸润 |
| 寿命 | 数月至数年 | 数天至数周 |
| 代表 | 小胶质细胞、Kupffer 细胞、肺泡巨噬细胞、皮肤朗格汉斯细胞 | 炎症浸润巨噬细胞、肿瘤相关巨噬细胞（部分） |

**关键例证**：小胶质细胞（microglia）完全起源于卵黄囊，几乎不依赖骨髓补充——用骨髓嵌合体（bone marrow chimera）难以清除小胶质细胞；Kupffer 细胞（肝脏）与肺泡巨噬细胞（肺）在稳态下同样由胚胎前体自我更新维持，仅在组织损伤时被单核细胞来源巨噬细胞大量替换。这一区分有重要**衰老含义**：TRM 长期暴露于组织微环境，随龄累积表观改变与损伤；而 MDM 的补充依赖骨髓输出，老年骨髓造血偏向髓系（见 04-immunosenescence.md 克隆性造血 CHIP），使浸润巨噬细胞天然带促炎倾向。

**衰老中的起源-表型耦合**：老年肺组织中的肺泡巨噬细胞呈现 M1 化（CD11c↑、TNF-α↑），同时 TRM 自我更新能力下降（对 IL-34 的应答减弱）；老年脑中小胶质细胞进入"致敏/营养不良"（dystrophic）状态，DAM（disease-associated microglia）亚群累积——这些变化是巨噬细胞极化失衡在组织水平的起点（证据等级：动物强关联，人体观察支持）。

## 三、极化定义与分类：从二元模型到连续谱

### 3.1 经典分类体系

极化概念源于 1986 年 Mosmann 提出的 Th1/Th2 二分框架，后经 Gordon、Mills 等移植到巨噬细胞：

- **M1（经典活化）**：由 **IFN-γ**（Th1 细胞/NK 细胞来源）或 **LPS**（TLR4 配体）诱导，受 **STAT1、IRF5、NF-κB** 转录因子驱动。标志物：CD86、CD80、MHC-II↑、iNOS（小鼠）、IL-1β、IL-6、TNF-α、CXCL9/10/11。功能：杀菌、抗肿瘤、促炎。
- **M2（替代活化）**：由 **IL-4/IL-13** 诱导，受 **STAT6、PPARγ、KLF4** 驱动；IL-10、TGF-β、糖皮质激素也可诱导 M2 样表型。标志物：CD206（甘露糖受体，MRC1）、Arg1、Ym1（小鼠）、FIZZ1（小鼠）、IL-10、TGF-β。功能：抗炎、组织修复、免疫抑制、纤维化促进。

**M2 的三个亚型**（Mantovani 2004 分类）：

| 亚型 | 诱导信号 | 标志 | 功能 |
|---|---|---|---|
| M2a | IL-4、IL-13 | CD206、Arg1、Ym1 | 组织修复、Th2 免疫 |
| M2b | 免疫复合物 + TLR 配体 | IL-10↑、IL-1β↑、TNF-α↑ | 免疫调节、Th2 极化 |
| M2c | IL-10、TGF-β、糖皮质激素 | IL-10、TGF-β、MerTK | 免疫抑制、基质沉积 |

### 3.2 连续谱争议：二元模型的局限

M1/M2 二分法提供了强大的概念工具，但存在系统性偏差：

1. **标志物物种差异**：iNOS 在小鼠是可靠 M1 标志，但**人巨噬细胞 iNOS 表达极低且难以诱导**（人 M1 常以 IL-1β、CXCL9/10 定义）；Arg1 在人巨噬细胞同样表达微弱——小鼠 M1/M2 标志物直接套用到人存在明显局限。
2. **体外诱导 ≠ 体内状态**：体内巨噬细胞同时暴露于混杂信号，单细胞测序显示组织巨噬细胞呈**连续转录谱**而非离散两极（如脂肪组织巨噬细胞同时表达 M1 与 M2 标志）。
3. **表型可塑性**：M1 与 M2 可在数小时内互相转换（极化不是终末分化），且存在多种中间态（如 Mox——氧化型 LDL 诱导；Mhem——血红素诱导，抗动脉粥样硬化）。

因此当代共识是：**M1/M2 是连续谱的两个参考端点**，用于描述趋势而非贴标签。本文沿用 M1/M2 术语但强调其启发式本质——这一认知对干预设计至关重要：**极化不是"杀死 M1"或"制造 M2"的开关，而是整体表型权重的再平衡**。

## 四、分子机制全链条：信号 → 转录 → 效应

### 4.1 M1 极化信号与转录程序

```
上游信号                         转录因子              效应输出
─────────────────────────────────────────────────────────────
LPS ── TLR4 ── MyD88 ── IRAK1/4 ── TRAF6
      └── TRIF（晚期 IRF3 通路）         │
                                        ▼
IFN-γ ── IFNGR ── JAK1/JAK2 ── STAT1（Y701 磷酸化）── 二聚化入核
                                        │
TNF-α ── TNFR1 ── RIPK1 ── IKKα/β ── IκBα 降解 ── NF-κB(p65/p50) 入核
                                        │
                                        ▼
                        STAT1 + IRF5 + NF-κB 协同结合启动子
                                        │
                                        ▼
        iNOS(NOS2) / IL-1β / IL-6 / TNF-α / CXCL9/10 / IL-12
        （+ NLRP3 炎症小体组装 → Caspase-1 → IL-1β/IL-18 成熟）
```

**关键节点解析**：

- **TLR4 双通路**：LPS 经 TLR4 激活 MyD88 依赖通路（早期 NF-κB，产生 TNF-α/IL-6）与 TRIF 依赖通路（晚期 IRF3 → IFN-β，自分泌放大 IFN-γ 样信号）——这是 LPS 诱导的 M1 为何"又快又持久"的结构基础。
- **STAT1 是 M1 核心开关**：IFN-γ 经 JAK1/JAK2 磷酸化 STAT1 的 Tyr701，STAT1 同源二聚化入核；STAT1 与 IRF5、NF-κB 在 iNOS 启动子区协同结合，三者缺一不可——单一敲除 STAT1 即可大幅削弱 M1 转录程序。
- **NLRP3 炎症小体**：M1 巨噬细胞中，信号 1（NF-κB 上调 NLRP3 与 pro-IL-1β）+ 信号 2（ATP、晶体、ROS 触发组装）→ Caspase-1 活化 → 剪切 IL-1β/IL-18 并诱导焦亡（pyroptosis）。衰老组织中的"无菌炎症"正是信号 2 的来源之一（损伤相关分子模式 DAMP，如 HMGB1、游离 mtDNA）。

### 4.2 M1 效应：iNOS/NO 与促炎细胞因子

**iNOS 是 M1 的标志性效应酶**（详见 03-immunity/01-no-immune.md）。其效应链：

```
L-精氨酸 ──iNOS(NOS2)──▶ NO + L-瓜氨酸
   │                        │
   │                        ├─▶ 与 O₂⁻ 反应 ──▶ ONOO⁻（过氧亚硝酸盐）
   │                        │      └─ 氧化铁硫簇 → 失活乌头酸酶/呼吸链复合物I、II
   │                        │      └─ 硝化酪氨酸（3-NT）→ 损伤蛋白
   │                        │      └─ 消耗 GSH、损伤 DNA（8-oxoG）
   │                        ├─▶ 高浓度 NO 直接抑制病原代谢酶（S-亚硝基化）
   │                        └─▶ 激活可溶性鸟苷酸环化酶（sGC）→ cGMP
   │
   └─▶（与 Arg1 竞争同一底物，见 4.4）
```

**剂量双刃剑**：M1 巨噬细胞经 iNOS 产生**微摩尔级（μM）**NO 数小时至数天（iNOS 的钙调蛋白以极低 Ca²⁺ 亲和力组成性结合，一旦诱导即持续高产），高浓度 NO 与超氧阴离子反应生成 ONOO⁻，执行广谱杀菌。但同一机制也是组织损伤源——类风湿关节炎滑膜、动脉粥样硬化斑块中硝基酪氨酸（3-NT）沉积即是证据。**关键悖论**：iNOS 敲除小鼠对胞内病原（分枝杆菌、利什曼原虫、李斯特菌）易感性显著升高（杀菌功能丧失），但脓毒症中非选择性 NOS 抑制剂临床试验却未获益甚至有害——高浓度 NO 的双刃剑属性在人体层面被反复验证。

**其他 M1 效应**：IL-1β 经 IL-1R 放大局部炎症并激活内皮；IL-6 驱动急性期反应（CRP 升高）与 Th17 极化；TNF-α 诱导内皮粘附分子（ICAM-1/VCAM-1）促进白细胞浸润；ROS（经 NADPH 氧化酶 NOX2）直接杀菌。**净效应**：M1 是"清除者"——清除病原、肿瘤细胞、坏死组织，但过度或持续激活即损伤自身组织。

### 4.3 M2 极化信号与转录程序

```
上游信号                       转录因子              效应输出
─────────────────────────────────────────────────────────────
IL-4/IL-13 ── IL-4Rα/IL-13Rα1 ── JAK1/JAK3 ── STAT6（Y641 磷酸化）── 二聚化入核
      │                                                      │
      │                                                      ▼
      └─ IL-4Rα 也可激活 IRS2 ── PI3K ── AKT（促存活）    STAT6 + PPARγ + KLF4
                                                             │
IL-10 ── IL-10R ── JAK1/TYK2 ── STAT3 ── SOCS3 抑制炎症        ▼
                                                          Arg1 / CD206(MRC1) /
TGF-β ── TGFBR ── Smad2/3（+ 非经典通路）                  Ym1 / FIZZ1 / IL-10 /
                                                          TGF-β / VEGF / EGF
糖皮质激素 ── GR ── 反式抑制 NF-κB（蛋白-蛋白互作）
```

**关键节点解析**：

- **STAT6 是 M2 核心开关**：IL-4/IL-13 经 JAK 磷酸化 STAT6 的 Tyr641，STAT6 同源二聚化入核驱动 Arg1、CD206、Ym1 等 M2 基因；STAT6 敲除小鼠完全丧失替代活化能力。
- **PPARγ 的代谢-转录耦合**：PPARγ 是脂质活化转录因子，与 STAT6 协同调控 M2 基因；其激动剂（噻唑烷二酮类，如罗格列酮）在体外与动物中均促 M2 极化——但代价是脂肪蓄积（PPARγ 本身就是脂肪生成主控基因）。
- **KLF4 的辅助作用**：KLF4 与 STAT6 协同激活 M2 基因，同时抑制 NF-κB 依赖的 M1 基因（KLF4 与 NF-κB 竞争共激活因子）。KLF4 缺失使巨噬细胞偏向 M1。

### 4.4 M2 效应与精氨酸竞争开关

**M2 的核心效应**：(a) **Arg1（精氨酸酶 1）** 催化 L-精氨酸 → 鸟氨酸 + 尿素，鸟氨酸进入多胺（细胞增殖）与脯氨酸（胶原合成）合成——这是 M2 促组织修复、促纤维化的代谢基础；(b) **CD206（甘露糖受体）** 介导糖蛋白清除与抗原递呈调节；(c) **IL-10** 经 STAT3 抑制促炎基因并上调 SOCS3；(d) **TGF-β** 促基质细胞活化、胶原沉积；(e) **VEGF** 促血管新生——伤口愈合与肿瘤血管化共享此通路。

**精氨酸竞争是极化方向的代谢开关**（Mills 2000 年提出"精氨酸开关"假说）：

```
                L-精氨酸（同一底物）
               ┌─────────┴─────────┐
          iNOS（M1）              Arg1（M2）
               │                    │
        NO + 瓜氨酸            鸟氨酸 + 尿素
               │                    │
        杀菌/炎症/硝化应激     多胺（增殖）+ 脯氨酸（胶原）
               └──── 竞争同一底物池 ────┘
        微环境决定：Th1 细胞因子 → iNOS 占优 → M1
                    Th2 细胞因子 → Arg1 占优 → M2
```

这一竞争的意义在于：**极化方向不是"空转的基因表达"，而是底物通量的再分配**。M1 把精氨酸烧成 NO 杀菌，M2 把精氨酸变成多胺与胶原修复组织；两者的胜负决定组织走向"清除+损伤"还是"修复+纤维化"。补充外源精氨酸并不能简单"增强"某一方——它同时喂饱两条通路，实际效应取决于微环境极化信号强度（详见第六节与 NO 的联系）。

## 五、代谢重编程：极化的"燃料系统"

巨噬细胞极化伴随**深刻的代谢重编程**，代谢状态既是极化的结果也是极化的原因（正反馈）：

### 5.1 M1：糖酵解 + 戊糖磷酸途径 + 琥珀酸

```
葡萄糖 ──▶ 糖酵解（HK2/PKM2 上调）──▶ 丙酮酸 ──▶ 乳酸（Warburg 样）
              │                            │
              ▼                            ▼
        戊糖磷酸途径(PPP)          线粒体"断点"：柠檬酸循环截断
        （G6PD 上调）              （异柠檬酸脱氢酶 IDH 下调）
              │                            │
              ▼                            ▼
        NADPH 供应                 柠檬酸 → 衣康酸(Itaconate) 累积
        （供 NOX2 产 ROS、        琥珀酸 → 稳定 HIF-1α
        供 iNOS 产 NO）                  │
                                        ▼
                                  促炎基因转录（IL-1β 等）
```

- **糖酵解上调**：M1 巨噬细胞糖酵解速率大幅升高（类似肿瘤 Warburg 效应），尽管产能效率低，但提供快速 ATP 与生物合成中间体；关键酶 HK2、PFKFB3、PKM2 上调。
- **PPP 上调**：葡萄糖-6-磷酸脱氢酶（G6PD）驱动 PPP，产生 **NADPH**——NADPH 同时是 iNOS（产 NO）与 NOX2（产 ROS）的辅因子，也是谷胱甘肽再生（抗氧化）的还原力。NADPH 的分流方向决定 M1 的"进攻-自保"平衡。
- **TCA 截断与琥珀酸**：M1 中异柠檬酸脱氢酶（IDH）下调使柠檬酸循环在异柠檬酸处截断，柠檬酸外流至胞质供脂质合成；琥珀酸累积并通过抑制脯氨酰羟化酶（PHD）**稳定 HIF-1α**——HIF-1α 再上调糖酵解酶与 IL-1β 转录，形成"琥珀酸 → HIF-1α → 炎症"闭环。
- **衣康酸**：由 IRG1（免疫应答基因 1）催化顺乌头酸生成，是 M1 的内源性抗炎刹车（抑制 SDH 并烷基化 KEAP1 激活 Nrf2）——M1 自带负反馈。
- **HIF-1α 的双重角色**：M1 中 HIF-1α 稳定驱动糖酵解与炎症；但 HIF-1α 也上调 VEGF 与精氨酸代谢酶，其净效应取决于信号背景。

### 5.2 M2：脂肪酸氧化（FAO）+ 氧化磷酸化

```
脂肪酸 ──▶ CPT1（肉碱穿梭）──▶ 线粒体 β-氧化 ──▶ 乙酰-CoA ──▶ TCA ──▶ 氧化磷酸化
              ▲                                                    │
              │（CD36、FABP4 摄取上调）                              ▼
          STAT6/PPARγ 转录上调                              大量 ATP + 低 ROS
                                                          （电子传递链"安静"运行）
```

- M2 巨噬细胞以 FAO + OXPHOS 为主，产能充分但响应慢；PPARγ 是 FAO 与 M2 基因的共同驱动器（脂质代谢与抗炎表型的分子桥梁）。
- **线粒体动态**：M2 中线粒体融合增强（Mfn1/2）、嵴结构完整；M1 中线粒体碎片化（Drp1 依赖）。线粒体自噬（mitophagy）受损的巨噬细胞偏向 M1 促炎——与衰老中自噬下降（见 01-foundations/06-proteostasis-autophagy.md）直接关联。

### 5.3 代谢-极化正反馈与衰老

衰老对代谢-极化耦合的三重打击：(a) **NAD⁺ 下降** → SIRT1 活性降低 → SIRT1 对 NF-κB（去乙酰化 p65 的 K310）与 PPARγ 的调控减弱 → M1 去抑制、M2 支持下降；(b) **线粒体功能下降** → M1 的琥珀酸/HIF-1α 通路被进一步放大；(c) **自噬下降** → 受损线粒体堆积 → 氧化型 mtDNA 泄漏激活 cGAS-STING → 干扰素信号 → 促炎。**结果**：老年巨噬细胞代谢指纹整体偏向"糖酵解 + 炎症"。

## 六、衰老中的 M1/M2 失衡

### 6.1 失衡表现

| 组织 | 衰老改变 | 证据等级 |
|---|---|---|
| 脂肪组织 | M1（CD11c⁺、iNOS）浸润↑，M2（CD206⁺、Arg1）↓，促炎因子↑ | 动物实锤（老年鼠脂肪组织）+ 人体观察 |
| 肝脏 | Kupffer 细胞促炎化，M1/M2 比值↑ | 动物强 |
| 骨骼肌 | 肌间脂肪与浸润巨噬细胞 M1 化，TNF-α↑ 损害卫星细胞再生 | 动物强 + 人体观察 |
| 大脑 | 小胶质细胞致敏/营养不良，DAM 亚群累积，IL-1β/TNF-α↑ | 动物强 + 人体尸检 |
| 肺 | 肺泡巨噬细胞 M1 化，老年肺对损伤修复能力↓ | 动物支持 |
| 血管 | 斑块内 M1/M2 比值↑ 与斑块不稳定相关 | 人体观察（病理标本） |

### 6.2 机制：为什么老年巨噬细胞偏向 M1

1. **转录因子漂移**：老年巨噬细胞 NF-κB 活性升高（老年小鼠肝/脾 NF-κB DNA 结合活性升高数倍），STAT1 基础磷酸化升高；PPARγ 表达下降（脂肪组织尤甚）——M1 驱动器上调、M2 驱动器下调。
2. **微环境信号改变**：衰老细胞 SASP（IL-6、IL-1β、TNF-α）持续刺激巨噬细胞促炎；老年组织 DAMPs（HMGB1、mtDNA）经 TLR 激活 NF-κB；性激素下降（雌激素促 M2，绝经后女性炎症负担上升与此相关）。
3. **efferocytosis（胞葬）功能下降**：巨噬细胞清除凋亡细胞的能力随龄下降——受体 MerTK、MFG-E8、TIM-4 表达下调；若凋亡细胞清除不净则继发坏死 → 释放 DAMPs → 炎症持续，形成"清除失败 → 炎症 → 更多损伤"的恶性循环。这是巨噬细胞极化失衡与慢性炎症标志之间的**直接因果桥**。
4. **表观锁定**：老年巨噬细胞启动子区表观修饰漂移（如促炎基因位点 H3K4me1 富集、增强子可及性改变），使极化"记忆"更顽固、重极化难度增大（训练免疫 trained immunity 的衰老版本）。
5. **NO 生物利用度下降**（本库主线）：eNOS 活性随龄下降 → 低浓度 NO 供给不足 → NF-κB 去抑制 → M1 偏向；同时老年巨噬细胞 iNOS 诱导能力下降（见 04-immunosenescence.md），M1 的"杀菌效率"下降但"炎症输出"升高——**功能错配**。

### 6.3 净后果

老年组织的巨噬细胞呈现"**高炎症输出 + 低清除效率 + 低修复能力**"的错配表型：既不能有效清除病原与凋亡细胞（防御下降），又持续分泌促炎因子（组织损伤），还削弱组织修复（M2 功能受损）——这一错配是免疫衰老（immunosenescence）的核心组成，也是"巨噬细胞极化失衡"独立于"慢性炎症"被单列为衰老标志的理由。

## 七、极化失衡与疾病

### 7.1 动脉粥样硬化：斑块内的 M1/M2 拉锯

斑块内巨噬细胞是动脉粥样硬化的核心细胞：(a) 早期，单核细胞浸润分化，氧化型 LDL 经 CD36/SR-A 摄取形成泡沫细胞；(b) 斑块进展期 M1 占优——IFN-γ、TNF-α 促进基质金属蛋白酶（MMP-9/12）分泌 → 纤维帽降解 → 斑块不稳定；M1 分泌的组织因子（TF）促血栓；(c) M2（尤其 Mhem 亚群）在稳定斑块中相对富集，分泌胶原保护纤维帽。**人体证据**：症状性/破裂斑块中 M1/M2 比值显著升高（病理标本免疫组化，多项研究一致）；斑块内 3-NT（硝化应激标志）沉积与 M1 共定位。**干预含义**：促进斑块巨噬细胞向 M2/Mhem 重极化（而非单纯降脂）是稳定斑块的策略之一（详见 02-vascular/06-lipid-atherosclerosis.md）。

### 7.2 肿瘤相关巨噬细胞（TAM）：被"策反"的 M2

肿瘤微环境将浸润巨噬细胞驯化为 **TAM**——表型接近 M2（CD163⁺、CD206⁺、Arg1 相关基因上调），功能上促血管新生（VEGF）、免疫抑制（IL-10、TGF-β、PD-L1 表达、抑制 T 细胞）、促侵袭转移（EGF、MMP）。**机制链**：肿瘤分泌 CSF-1（M-CSF）、IL-4、IL-10、乳酸（代谢信号）→ 巨噬细胞 M2 化；缺氧区 HIF-1α 进一步促 TAM 的免疫抑制表型。**临床证据**：多种实体瘤中高密度 TAM 与不良预后相关（荟萃分析一致）；CSF-1R 抑制剂（如 Pexidartinib，已获批腱鞘巨细胞瘤）通过耗竭/重编程 TAM 抗肿瘤，但实体瘤单药疗效有限——TAM 靶向需与免疫检查点抑制剂联用。**衰老视角**：老年肿瘤微环境中 TAM 的 M2 偏向更顽固，与年龄相关免疫逃逸叠加。

### 7.3 肥胖与脂肪组织巨噬细胞（ATM）

肥胖时脂肪组织巨噬细胞（ATM）从 M2 保护型（维持胰岛素敏感性、清除凋亡脂肪细胞）转向 M1 促炎型（CD11c⁺、TNF-α、IL-1β），浸润量可占脂肪组织细胞 40% 以上。**机制**：脂肪细胞肥大 → 缺氧（HIF-1α↑）→ 趋化因子 CCL2（MCP-1）募集单核细胞；脂毒性（饱和脂肪酸经 TLR4 激活 NF-κB）；坏死脂肪细胞释放 DAMPs。**因果证据**：CCL2 或其受体 CCR2 敲除小鼠肥胖时巨噬细胞浸润减少、胰岛素敏感性改善；**但** CCR2 敲除也加重脂肪组织缺氧——说明 ATM 清除是一把双刃剑（巨噬细胞同时承担脂质缓冲功能）。人体：肥胖者脂肪组织 M1/M2 比值升高与胰岛素抵抗相关（HOMA-IR），减重后比值回落——**极化可逆性的人体证据**。

### 7.4 纤维化：M2 的"修复过度"

M2 巨噬细胞是组织修复的执行者，但持续/过度 M2 极化驱动纤维化：TGF-β 活化肌成纤维细胞 → 胶原沉积 → 器官硬化。**特发性肺纤维化（IPF）**是典型例子——促纤维化巨噬细胞（表达 SPP1/骨桥蛋白）在 IPF 肺中富集。**关键联系（本库特色）**：英矽智能 AI 研发的 TNIK 抑制剂 Rentosertib（INS018_055）在 IPF 中显示抗纤维化疗效，其临床前与蛋白质组学分析提示**巨噬细胞由促炎/促纤维化表型向修复性表型转变**（详见 04-drugs/01-rentosertib.md）——这是"重极化干预"进入临床概念验证的标志性案例（2026 年已启动 III 期）。**注意张力**：纤维化治疗需要"抑制 M2 的促纤维化面"而非"促进 M2"——M2 内部亚型（M2a 修复 vs M2c 基质沉积）的区分对治疗设计至关重要，简单的"促 M2"口号在纤维化场景是危险的。

### 7.5 阿尔茨海默病：小胶质细胞的双面性

小胶质细胞（脑内 TRM）在 AD 中：(a) 清除 Aβ 能力随龄下降（CD33、TREM2 通路改变）；(b) 对 Aβ 的慢性刺激转向促炎（IL-1β、TNF-α、补体 C1q 介导突触修剪过度）；(c) DAM 亚群（TREM2-APOE 通路）在斑块周围累积，功能介于清除与促炎之间。**证据**：TREM2 功能丧失突变（R47H）使 AD 风险升高约 2-3 倍（人体遗传学实锤）；但 TREM2 敲除小鼠 Aβ 清除下降——小胶质细胞激活是"清除不足"与"过度炎症"的平衡问题，与巨噬细胞极化的整体叙事一致。**干预**：TREM2 激动抗体（如 AL002）已进入临床试验，思路是"增强清除而非单纯抗炎"。

|---|---|---|

## 九、与 NO / NAD+ / 长寿网络联系（本库特色视角）

### 9.1 iNOS/NO 是 M1 的核心效应轴

M1 的"杀伤功能"几乎全部经由 iNOS 产生的 NO 执行（见 03-immunity/01-no-immune.md）。这使巨噬细胞极化与 NO 通路形成**分子级耦合**：

```
M1 极化 ──▶ iNOS 诱导 ──▶ μM 级 NO ──▶ 杀菌 / 硝化应激
                                        │
老年 NO 生物利用度↓ ──▶ NF-κB 去抑制 ──▶ 炎症放大（M1 偏向）
                                        │
低剂量 NO（eNOS 来源）──▶ S-亚硝基化 p65(Cys38) / 经 SIRT1 去乙酰化 p65
                        ──▶ NF-κB 活性↓ ──▶ M1 抑制、M2 偏向
```

### 9.2 精氨酸竞争是极化的"代谢开关"

Arg1 与 iNOS 竞争同一底物 L-精氨酸（见 4.4）——这是 NO 通路与极化方向最直接的代谢交汇点。**干预推论**：单纯补精氨酸无法定向（同时喂饱两条通路）；定向需要"信号层面"（促 M2 细胞因子/药物）与"代谢层面"（抑制 iNOS 或增强 Arg1 活性）协同。**有趣的悖论**：抑制 iNOS 可减少硝化损伤（抗炎面），但也削弱杀菌（防御面）——在脓毒症试验中这一悖论已显现，干预必须区分"炎症性 M1"（病理）与"杀菌性 M1"（保护）。

### 9.3 NAD+/SIRT1 轴连接极化与代谢

- SIRT1 去乙酰化 NF-κB p65（K310）抑制其转录活性 → NAD⁺ 充足时 M1 受抑；
- SIRT1 去乙酰化并激活 PGC-1α → 线粒体生物发生 → 支持 M2 的氧化代谢指纹；
- 老年 NAD⁺ 下降（NAMPT 活性↓）同时削弱上述两条 → 助长 M1 偏向。Rentosertib 的蛋白质组分析显示 NAMPT↑→NAD⁺↑→Sirt1 激活伴随巨噬细胞 M1→M2 重极化（04-drugs/01-rentosertib.md），是"NAD⁺-极化"轴在临床样本中的首次提示。

### 9.4 干预交叉点汇总

| 干预 | 极化效应 | NO 通路联系 |
|---|---|---|
| 膳食硝酸盐/NO 供体 | 低剂量 NO → 促 M2 修复极化 | 直接补充 NO 池 |
| NAD+ 前体（NMN/NR） | SIRT1↑ → 抑 NF-κB → 抑 M1 | 共享 SIRT1-NO 正反馈 |
| 运动 | 脂肪组织 M2↑、炎症↓ | 剪切应力激活 eNOS |
| PPARγ 激动剂 | 促 M2 | 与 NO 抗炎协同（待证实） |
| Senolytics | 清除 SASP 源 → 巨噬细胞炎症刺激↓ | 减少 iNOS 诱导信号 |
| 中药益气活血（见 06-tcm/） | 黄芪/丹参等调节巨噬细胞极化（临床前） | 部分经 NO/eNOS 通路 |

## 十、干预方向与可执行建议

### 10.1 促 M2 极化药物（临床前为主）

| 类别 | 代表 | 机制 | 成熟度 | 风险 |
|---|---|---|---|---|
| PPARγ 激动剂 | 罗格列酮、吡格列酮 | 转录促 M2 | 已上市（降糖），极化效应为附加 | 水钠潴留、体重增加、心衰风险 |
| IL-4/IL-13 模拟 | IL-4 融合蛋白、IL-4Rα 激动剂 | 激活 STAT6 | 临床前 | 过敏/Th2 疾病风险、促纤维化 |
| STAT6 激活剂 | 小分子（筛选阶段） | 激活 M2 转录 | 临床前 | 特异性存疑 |
| 他汀类 | 阿托伐他汀等 | 附带促 M2/抗炎 | 已上市 | 已大规模验证安全性 |
| 二甲双胍 | — | AMPK↑ → 抑 NF-κB | 已上市 | 已大规模验证 |
| TREM2 激动抗体 | AL002 | 增强小胶质细胞清除 | I/II 期（AD） | 免疫相关不良反应 |

### 10.2 抗衰导向的可执行策略（证据分级标注）

1. **运动**（人体证据 II 级）：每周中等强度有氧运动降低老年人体循环炎症标志（IL-6、CRP），动物中逆转脂肪组织 M1 偏向——可执行性最高、副作用最低的首选。
2. **热量限制/健康饮食**（人体观察 + 动物）：改善脂肪组织巨噬细胞表型；地中海饮食降低炎症负荷。
3. **Senolytics**（动物实锤、人体早期）：达沙替尼+槲皮素清除衰老细胞后，老年组织的巨噬细胞炎症刺激源减少（见 04-drugs/03-senolytics.md）；人体应用仍在试验阶段，不可自行使用。
4. **NAD+ 前体**（人体早期）：NMN/NR 补充提高 NAD⁺，理论上经 SIRT1 抑 NF-κB 支持 M2；人体试验结果混杂（对炎症标志的影响不统一），证据尚不足以支撑明确推荐。
5. **膳食硝酸盐**（人体 II 级，血管终点）：甜菜根汁等提高 NO 生物利用度，改善内皮功能；对巨噬细胞极化的直接人体证据缺乏，作为 NO 通路的间接干预合理（详见 02-vascular/02-dietary-nitrate.md）。
6. **抗炎药审慎**：非甾体抗炎药长期使用有心血管/消化道风险（ASPREE 试验教训）；不应以"抗炎"为名自行长期服药。

### 10.3 干预的时间窗口与"极化剂量学"

重极化干预的效果依赖**时相与剂量**：(a) 急性损伤期需要 M1 清除坏死组织（过早促 M2 反而不利愈合）；(b) 慢性期需要 M2 修复（持续 M1 造成纤维化）。衰老场景是典型的慢性期——理论上促 M2 合理，但必须警惕：(i) M2 的促纤维化面（见 7.4）；(ii) M2 的免疫抑制面（肿瘤风险）；(iii) 极化干预的个体差异（遗传背景、菌群、合并症）。**"极化剂量学"（polarization dosing）——靶向性、阶段性、可逆性——是未来个体化抗衰干预的设计原则。**

## 十一、开放问题与争议

1. **M1/M2 二分法的存废**：单细胞时代已证明巨噬细胞呈连续谱，但连续谱框架尚未产生可操作的干预靶点——二分法仍是最实用的"工作模型"，其简化在何时开始误导治疗设计（如纤维化中"促 M2"的反噬）？
2. **极化失衡是原因还是结果**：老年 M1 偏向与慢性炎症互为因果；巨噬细胞极化失衡作为独立衰老标志的"因果权重"尚不明确——需要谱系特异性的基因操作在老年模型中证明"纠正极化可延缓多器官衰老"。
3. **重极化的持久性**：体外与动物中 M1↔M2 转换可逆，但老年组织中的表观"锁定"（训练免疫）是否使重极化不可持续？Rentosertib 停药后抗衰信号是否回落（未见数据）？
4. **促 M2 的肿瘤风险**：M2 是 TAM 的免疫抑制表型——系统性促 M2 干预是否增加肿瘤免疫逃逸？极化干预的肿瘤监测成本如何设计？
5. **人鼠标志物鸿沟**：人巨噬细胞 iNOS/Arg1 表达微弱，小鼠模型的重极化结论能否外推人体？需要以人源化模型与临床样本的单细胞数据填补。
6. **iNOS 抑制的悖论**：抑制 iNOS 减少硝化损伤（抗炎面）同时削弱杀菌（防御面）——"炎症性 M1"与"杀菌性 M1"能否分子层面区分并选择性靶向？
