# 巨噬细胞极化：M1/M2 开关与衰老免疫

> 主题定位：巨噬细胞作为免疫系统的"可塑中枢"，其 M1/M2 极化状态决定组织是走向炎症损伤还是修复再生。本章覆盖表型标志物、极化信号、代谢重编程、NO 的角色、衰老巨噬细胞极化漂移，以及 TNIK 抑制促 M1→M2 转化的前沿（Rentosertib）与组织特异性巨噬细胞。

---

## 1. 引言：一个细胞的两副面孔

巨噬细胞是先天免疫中功能最多样的细胞：它们吞噬病原体、呈递抗原、分泌细胞因子、重塑组织。这种多样性并非来自不同细胞亚群，而是同一个细胞在微环境信号驱动下的**功能极化（polarization）**——即"巨噬细胞可塑性"。

经典二分框架由 **Mills 等于 2000 年提出（*J Immunol*）**，随后 Gordon（2003）与 Mantovani（2004）完善了 M1/M2 命名体系：

- **M1（经典活化，classically activated）**：由 IFN-γ + LPS/TNF-α 驱动，促炎、杀菌、抗肿瘤。
- **M2（替代活化，alternatively activated）**：由 IL-4/IL-13 驱动（M2a），或免疫复合物/IL-10/糖皮质激素驱动（M2b/c），抗炎、促修复、促纤维化。

**重要警示**：M1/M2 是体外实验的简化理想型，体内巨噬细胞常呈混合/中间表型（"M1.5"、"M2d"等），且表型可逆——这是理解极化研究的正确姿势。

## 2. M1/M2 表型标志物全景

### 2.1 标志物对照表

| 维度 | M1（经典活化） | M2（替代活化） |
|------|----------------|----------------|
| 诱导信号 | IFN-γ + LPS / TNF-α | IL-4 + IL-13（M2a）、IL-10/IC（M2b/c） |
| 核心转录因子 | STAT1、IRF5、NF-κB、AP-1 | STAT6、IRF4、PPARγ、KLF4 |
| 精氨酸代谢 | iNOS（精氨酸→NO） | Arg1（精氨酸→鸟氨酸→多胺/脯氨酸） |
| 特征酶 | iNOS↑ | Arg1↑、Ym1（小鼠）、Fizz1（小鼠） |
| 细胞因子 | IL-12↑、IL-23↑、TNF-α↑、IL-1β↑、IL-6↑ | IL-10↑、TGF-β↑、IL-1ra↑、CCL17/CCL18/CCL22↑ |
| 趋化因子 | CXCL9/10/11（T 细胞募集） | CCL17/18/22（Th2/Treg 募集） |
| 表面标志 | CD80↑、CD86↑、MHC-II↑ | CD163↑、CD206（MRC1）↑、CD204↑ |
| 受体 | TLR4 高响应 | 清道夫受体↑、甘露糖受体↑ |
| 功能 | 杀菌、促炎、抗肿瘤、组织损伤 | 抗炎、组织修复、血管生成、促纤维化、促肿瘤 |
| 代谢 | 有氧糖酵解 + 磷酸戊糖途径 | 氧化磷酸化 + 脂肪酸氧化 |

### 2.2 关键"标志性酶"对：iNOS vs Arg1——精氨酸竞争开关

M1/M2 极化的最经典分子对决发生在**精氨酸代谢**层面：M1 巨噬细胞诱导 iNOS 将 L-精氨酸转化为 NO；M2 巨噬细胞诱导 Arg1（精氨酸酶 1）将 L-精氨酸转化为鸟氨酸。两者竞争同一底物，构成"代谢开关"：

```
                        L-精氨酸
                           │
              ┌────────────┴────────────┐
              ▼                         ▼
        iNOS（M1）                  Arg1（M2）
              │                         │
              ▼                         ▼
        NO + L-瓜氨酸            鸟氨酸
              │                    ├──► 多胺（细胞增殖）
       杀菌/促炎                 └──► 脯氨酸（胶原合成，纤维化）
```

**人鼠差异再次出现**：Arg1 作为 M2 标志物在小鼠巨噬细胞清晰可靠，但在人巨噬细胞中 Arg1 诱导较弱且不太可靠——人 M2 更依赖 CD163/CD206 与 CCL18 等标志。引用时需注明物种。

### 2.3 转录调控网络

```
M1 通路：                              M2 通路：
IFN-γ ──► IFNGR ──► JAK1/2 ──► STAT1     IL-4 ──► IL-4Rα ──► JAK1/3 ──► STAT6
LPS  ──► TLR4 ──► NF-κB/IRF3/IRF5        IL-13 ──► IL-13Rα1 ──► JAK1/TYK2 ──► STAT6
        │                                      │
        ▼                                      ▼
  STAT1 + IRF5 + NF-κB                    STAT6 + IRF4 + PPARγ + KLF4
        │                                      │
        ▼                                      ▼
  iNOS, IL-12, TNF-α, CXCL9/10          Arg1, Ym1, Fizz1, CD206, IL-10
        │                                      │
        └── 负向交叉抑制 ────────────────────────┘
           STAT1 抑制 STAT6 靶基因；STAT6 抑制 STAT1 靶基因
```

**交叉抑制的分子基础**：STAT1 与 STAT6 竞争共同的辅助因子；KLF4 抑制 NF-κB 依赖的促炎基因；IRF5 与 IRF4 互相拮抗。这种"跷跷板"结构保证了极化方向的相对稳定性，也解释了为何极化一旦建立较难快速翻转。

## 3. 极化信号：微环境决定命运

### 3.1 M1 诱导信号

- **IFN-γ**：T 细胞/NK 细胞/ILC1 来源，经 IFNGR→JAK1/2→STAT1；STAT1 磷酸化（Tyr701）后二聚化入核，诱导 iNOS、IL-12 等；IFN-γ 同时上调 IRF1 与 MHC-II。
- **LPS/病原体**：TLR4→MyD88/TRIF 双通路，激活 NF-κB（p65/p50）与 IRF3/IRF5；LPS 的 priming 作用使后续 IFN-γ 反应放大。
- **TNF-α、GM-CSF**：协同增强 M1 程序。
- **微环境因素**：缺氧、高糖、胆固醇晶体均可增强 M1 倾向。

### 3.2 M2 诱导信号

- **IL-4/IL-13**：Th2 细胞、嗜碱性粒细胞、肥大细胞、ILC2 来源；经 IL-4Rα→JAK1/3→STAT6；STAT6 诱导 Arg1、CD206、Ym1 等。
- **IL-10**：M2c 诱导，经 STAT3，促进清道夫受体表达与抗炎。
- **免疫复合物 + LPS（M2b）**：FcγR + TLR 联合刺激，产生 IL-10 与 IL-6 共存表型。
- **糖皮质激素、TGF-β**：M2c，促修复与纤维化。
- **代谢信号**：脂肪酸氧化增强（PPARγ 配体）驱动 M2；乳酸积累促 M2 样表型。

### 3.3 信号的时间动力学

极化不是一步到位：LPS 刺激后 0–2 小时为"早期促炎"（TNF-α 峰值），2–24 小时转向"持续炎症/杀菌"（IL-12、iNOS），若损伤持续则微环境逐渐转向修复（M2 化）——**组织修复的时序本质是巨噬细胞从 M1 到 M2 的程序化转换**。这一转换失败（M1 持续不退）是慢性炎症与纤维化疾病的共同病理。

## 4. 代谢重编程：极化的"燃料"与"引擎"

巨噬细胞极化与代谢状态深度耦合（"免疫代谢"，immunometabolism）——代谢不只是供能，更是极化的驱动与执行器。

### 4.1 M1 的代谢特征：有氧糖酵解

```
葡萄糖 ──► 糖酵解 ──► 丙酮酸 ──(LDH)──► 乳酸（即使有氧！）
             │
             ▼（分流）
        磷酸戊糖途径（PPP）
             │
             ▼
        NADPH ──► NOX2 呼吸暴发 + iNOS 辅因子
```

- **Warburg 样效应**：M1 巨噬细胞即使在富氧环境也偏好糖酵解，乳酸大量产生。驱动因素：HIF-1α（LPS 可稳定 HIF-1α 即使常氧）、mTOR 活化、PFKFB3 上调。
- **意义**：糖酵解速度快，为快速杀菌提供 ATP 与生物合成前体（核苷酸、氨基酸）；PPP 提供 NADPH 支持 NOX2 与 iNOS（NADPH 是 iNOS 电子供体）；**线粒体 TCA 循环在琥珀酸脱氢酶（SDH）处"断裂"**，导致琥珀酸堆积——琥珀酸通过稳定 HIF-1α 进一步放大 IL-1β 产生。
- **关键节点**：SDH 抑制（二甲氧基丙二酸 DMM）可降 IL-1β；衣康酸（itaconate，由免疫应答基因 1 IRG1 合成）抑制 SDH 并具抗炎作用——内源性抗炎代谢物。

### 4.2 M2 的代谢特征：氧化磷酸化与脂肪酸氧化

```
葡萄糖/脂肪酸/谷氨酰胺
        │
        ▼
  糖酵解(低速) + FAO(β-氧化) + 谷氨酰胺代谢
        │
        ▼
  乙酰-CoA ──► TCA 循环（完整）──► NADH/FADH₂
        │
        ▼
  氧化磷酸化（ETC）──► ATP（高效）
```

- M2 细胞线粒体功能完整、OXPHOS 效率高、ROS 产生低；PPARγ/PPARδ 与 PGC-1β 驱动脂肪酸氧化。
- 谷氨酰胺代谢支持 UDP-GlcNAc 合成 → **蛋白糖基化修饰**（M2 表面标志 CD206 等需要糖基化）。
- **意义**：M2 需长期维持组织修复功能，高效产能 + 低氧化损伤 + 合成胶原前体（脯氨酸来自精氨酸-鸟氨酸通路）是其代谢设计的核心。

### 4.3 代谢-极化互作总结

| 代谢特征 | M1 | M2 |
|----------|----|----|
| 主要产能 | 有氧糖酵解 | OXPHOS + FAO |
| HIF-1α | 高（琥珀酸、ROS 稳定） | 低 |
| TCA | 断裂（SDH 前堆积琥珀酸） | 完整 |
| 关键产物 | NADPH、乳酸、衣康酸 | ATP、UDP-GlcNAc、脯氨酸 |
| 线粒体 ROS | 高（杀病原） | 低 |
| 可塑性 | 可向 M2 转换 | 可向 M1 转换（LPS 再刺激） |

## 5. NO 在巨噬细胞极化中的角色

NO 与极化形成双向调控：

1. **NO 是 M1 的"身份证"与武器**：iNOS 表达是 M1 的核心标志；NO 介导 M1 的杀菌与抗肿瘤效应（见 NO 章节）。
2. **NO 反馈抑制 M1、促进 M2 转换**：高浓度 NO 抑制 NF-κB 与 STAT1 活性（S-亚硝基化修饰 IKKβ/p65 的半胱氨酸），下调 IL-12；同时 NO 促进 STAT6 磷酸化（部分经抑制蛋白酪氨酸磷酸酶），偏向 M2 程序——即**NO 是 M1 的"自限开关"**。
3. **NO 与 Arg1 竞争精氨酸**：M1 高 iNOS 消耗精氨酸→限制 Arg1；M2 高 Arg1 消耗精氨酸→限制 NO 产生。二者互为底物竞争，构成极化稳态的代谢锚。
4. **NO 影响组织修复**：M2 阶段适度 NO 促进血管生成与伤口愈合（VEGF 上调），过度 NO 则致纤维化。

```
M1 活化 ──► iNOS ──► NO 升高
                        │
              ┌─────────┴──────────┐
              ▼                    ▼
       杀菌/抗肿瘤            反馈抑制 NF-κB/STAT1
       （正面效应）           + 促进 STAT6 → M2 化
                               （自限、转向修复）
```

## 6. 衰老巨噬细胞：极化漂移与 SASP

### 6.1 衰老巨噬细胞的表型改变

| 特征 | 年轻巨噬细胞 | 衰老巨噬细胞 |
|------|--------------|--------------|
| 基础极化 | M1/M2 平衡、可塑 | M1 倾向（IL-6/TNF-α 基础分泌升高） |
| 吞噬能力 | 强 | 下降（吞噬受体表达↓、细胞骨架老化） |
| 趋化/迁移 | 正常 | 受损（整合素信号钝化） |
| 抗原呈递 | 强 | MHC-II 下调（MHC-II 与 CD80 表达↓） |
| iNOS 诱导 | 强 | 减弱（NF-κB 信号钝化、表观遗传漂移） |
| 线粒体 | 健康、自噬正常 | mtROS↑、自噬↓、mtDNA 泄漏 |
| SASP 分泌 | 低 | 高（IL-6、IL-1β、MMP 等） |

### 6.2 极化漂移的机制

1. **表观遗传锁定**：衰老巨噬细胞炎症基因启动子/增强子区域组蛋白修饰改变（H3K4me3 增加、H3K27me3 减少），NF-κB 靶基因"预活化"——对 LPS 反应更强更持久（"炎症超敏"），但对 IL-4 的 M2 诱导反应减弱（STAT6 信号钝化）。
2. **线粒体功能障碍**：mtROS↑ 直接激活 NF-κB 与 NLRP3；自噬下降使损伤线粒体堆积；mtDNA 经 cGAS-STING 驱动 SASP。
3. **微环境信号变化**：老年组织 SASP 因子（IL-6、TNF-α）本身持续驱动 M1 化，形成"炎症-极化"正反馈。
4. **NAD⁺ 下降**：SIRT1 活性降低 → p65 乙酰化升高 → 炎症转录增强；SIRT1 激动剂/NAD⁺ 前体（NMN/NR）可部分逆转老年巨噬细胞的 M1 偏斜（多项动物实验）。

### 6.3 衰老巨噬细胞的"滞留"表型

老年组织中巨噬细胞还表现出**组织滞留**特征：迁移能力下降、驻留时间延长，导致局部 SASP 累积（"炎症病灶化"）。这在动脉粥样硬化斑块、脂肪组织、肝脏（Kupffer 细胞）尤为明显。

## 7. TNIK 抑制与 M1→M2 重极化：Rentosertib 前沿

### 7.1 TNIK 是什么

**TNIK（TRAF2-和 NCK-相互作用的激酶，TRAF2 and NCK interacting kinase）** 是一种 Ste20 家族丝氨酸/苏氨酸激酶，最初发现于 Wnt/β-catenin 信号通路（与 TCF/LEF 转录复合物结合，是 Wnt 通路的关键共激活因子）。近年研究发现 TNIK 还参与：

- 细胞骨架重构（与 NCK 相互作用）
- 炎症信号：与 TRAF2 结合参与 TNF/NF-κB 信号
- 衰老/纤维化相关信号通路

### 7.2 TNIK 抑制的发现路径

TNIK 抑制剂最初作为**抗纤维化药物**开发：2021 年前后，临床阶段的 TNIK 抑制剂（如 **Rentosertib，前称 INS018_055，由 Insilico Medicine 开发**）在特发性肺纤维化（IPF）适应症中进入临床试验（中国 NMPA 与 FDA 均获批开展）。其作用机制研究中发现，TNIK 抑制不仅抗纤维化，还能**驱动巨噬细胞从促炎的 M1 表型向抗炎修复的 M2 表型重极化**。

### 7.3 机制链条（当前理解）

```
TNIK 抑制（Rentosertib）
        │
        ▼
  Wnt/β-catenin 信号减弱
   + 炎症转录程序下调（NF-κB 相关）
        │
        ▼
  巨噬细胞促炎基因（TNF-α、IL-1β、iNOS）↓
  修复基因（Arg1、CD206、IL-10）↑
        │
        ▼
  M1 ──► M2 重极化
        │
        ▼
  炎症消退 + 成纤维细胞活化减弱 ──► 抗纤维化
```

**证据要点（截至 2025 年前后公开数据）**：

- 临床前：Rentosertib 在 IPF 小鼠/大鼠模型（博来霉素诱导）中降低肺纤维化评分，肺组织巨噬细胞 M2 标志物升高、M1 标志物下降。
- 临床：II 期试验（中国）显示肺功能（FVC）改善趋势与良好安全性；全球多中心 II 期进行中。
- 机制研究（公开文献/会议报告）：TNIK 抑制下调巨噬细胞中 Wnt 靶基因与炎症基因共表达网络；TNIK 敲低与药理学抑制表型一致。

**谨慎声明**：TNIK→M1/M2 重极化的详细分子链条（直接底物、与 STAT/NF-κB 的交互）仍在研究中，部分数据来自公司披露与会议摘要，独立同行评审证据尚在积累。本章呈现的是"当前主流理解"，非最终定论。

### 7.4 意义与局限

- **意义**：TNIK 代表"可药化的极化开关"——小分子抑制剂即可系统性推动 M1→M2 重极化，为纤维化、慢性炎症乃至衰老相关疾病提供新策略；其"AI 制药"出身（Insilico Medicine 生成式 AI 设计）也是该领域的标志性案例。
- **局限**：M1→M2 的"全面转向"可能削弱抗感染免疫（M1 是杀菌主力）；长期 M2 化增加纤维化与肿瘤风险——"修复表型"与"病理表型"只有一线之隔。巨噬细胞极化的治疗性操纵必须在时空上精准，这是所有极化靶向策略的共同挑战。

## 8. 组织特异性巨噬细胞：极化在器官中的落地

巨噬细胞并非千篇一律——组织驻留巨噬细胞（tissue-resident macrophages, TRM）在胚胎期定植（卵黄囊/胎肝来源，自我更新），与单核细胞来源的浸润巨噬细胞（MoM）共存，功能高度组织化：

| 组织 | 驻留巨噬细胞 | 主要功能 | 极化倾向 |
|------|--------------|----------|----------|
| 肝脏 | Kupffer 细胞 | 清除内毒素/红细胞碎片、铁代谢 | 静息 M2 样（耐内毒素） |
| 脑 | 小胶质细胞（microglia） | 突触修剪、Aβ 清除 | 稳态 M2 样；AD 中偏 M1（神经炎症） |
| 肺 | 肺泡巨噬细胞（AM） | 表面活性物质清除、免疫监视 | 静息 M2 样；吸烟/博来霉素时 M1 |
| 脂肪组织 | ATMs | 脂质缓冲、产热调节 | 瘦者 M2（抗炎）；肥胖者 M1（胰岛素抵抗） |
| 骨 | 破骨细胞（单核谱系融合） | 骨吸收 | 特殊终末分化（非典型 M1/M2） |
| 脾/骨髓 | 红髓/边缘区巨噬细胞 | 红细胞回收、铁循环 | 静息 M2 样 |
| 皮肤 | Langerhans 细胞 | 抗原呈递 | 可塑性强 |

**要点**：组织驻留巨噬细胞的"极化"更多是**组织特异的静息程序**，而非简单 M1/M2 二分。疾病（纤维化、肿瘤、神经退行、肥胖）中，驻留细胞被激活并向炎症表型偏移，同时单核细胞来源巨噬细胞大量浸润——**"极化漂移+新浸润"双轨制**是器官病理中巨噬细胞变化的真实图景。

**肿瘤相关巨噬细胞（TAM）**：肿瘤微环境中巨噬细胞被"驯化"为 M2 样（TAM），分泌 VEGF、TGF-β 促血管生成与免疫抑制（PD-L1 上调），是免疫治疗抵抗的重要机制；"TAM 重极化"（M2→M1，如抗 CD40、CSF-1R 抑制、TLR 激动剂）是肿瘤免疫治疗的前沿策略。

## 10. 开放问题

1. **极化的"可逆性窗口"**：M1→M2 转换在体内究竟能走多远？已建立的纤维化/肿瘤微环境中，重极化能否逆转组织结局，还是只缓解症状？
2. **TNIK 抑制的完整机制链**：TNIK 的直接底物是什么？它如何与 STAT/NF-κB 通路交互？抑制 TNIK 对 M1（杀菌）功能的影响是否构成临床安全风险？
3. **人鼠极化标志物鸿沟**：Arg1、Ym1、Fizz1 等小鼠标志物在人巨噬细胞中不可靠——人类 M1/M2 的"黄金标志物组合"究竟是什么？
4. **衰老巨噬细胞极化漂移是可逆的吗**：NAD⁺ 补充、senolytics 或代谢干预能否把老年 M1 偏斜"拨回"M2？治疗后的极化状态能维持多久？
5. **TAM 重极化的临床转化**：为什么大量"TAM 重极化"策略在动物有效、人体试验却大多折戟？肿瘤微环境的多重免疫抑制冗余是否是根本障碍？
