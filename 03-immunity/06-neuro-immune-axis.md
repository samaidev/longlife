# 神经-免疫轴 Neuro-Immune Axis

## 核心概念

神经系统与免疫系统通过三条主干双向通信：① **迷走神经-脾脏胆碱能抗炎通路**（炎症反射，Tracey 2002）；② **下丘脑-垂体-肾上腺（HPA）轴**（糖皮质激素抗炎）；③ **交感神经-儿茶酚胺通路**。健康状态下该轴维持炎症的"制动器"；随龄或慢性应激下神经免疫调节失衡、促炎状态放大——这是"慢性应激促炎→加速衰老"的神经学接口，也是冥想/呼吸/运动等行为干预发挥抗炎作用的生物学基础。免疫细胞（T/B/巨噬细胞）普遍表达神经递质受体（α7nAChR、β2-AR、GR），神经系统则被免疫介质（细胞因子）反向调节——双向通信的解剖与分子基础完整存在。

## 分子机制全链条

### 1. 胆碱能抗炎通路（CAP，Tracey 2002）

Tracey 团队 2002 年在 *Nature* 提出"炎症反射"：迷走传出纤维激活脾脏 CD4⁺ T 细胞释放乙酰胆碱（ACh），ACh 结合巨噬细胞表面 **α7 烟碱型乙酰胆碱受体（α7nAChR）**，抑制 NF-κB 并激活 JAK2/STAT3，最终抑制 TNF-α、IL-1β、IL-6 释放。2003 年 *Nature* 进一步以 α7 敲除小鼠证明该受体为通路核心。

```
迷走传出（ACh）→ 脾神经（NE）→ 脾脏 CD4⁺ T 细胞（ChAT⁺，表达β2-AR）
      ↓ NE 经 β2-AR 激活 ChAT⁺ T 细胞 → 释放 ACh
巨噬细胞 α7nAChR（配体门控离子通道，兼代谢型信号）
      ↓
JAK2 → STAT3 磷酸化（入核，抗炎转录程序，上调 SOCS3）
      ↓ 同时
IκBα 稳定 → NF-κB（p65）入核↓ → TNF-α/IL-1β/IL-6 转录↓
      ↓
全身炎症下调（脓毒症/关节炎/IBD 模型均验证）
```

- **机制细节**：α7nAChR 是五聚体配体门控离子通道（Cys-loop 家族），激活后经 JAK2/STAT3 上调 SOCS3（细胞因子信号抑制物）抑制 NF-κB；同时激活 PI3K/Akt 抗凋亡信号。脾脏内是"神经-T 细胞-巨噬细胞"**三级接力**：迷走纤维并不直接接触巨噬细胞，而是经脾神经释放 NE → 激活 ChAT⁺ CD4⁺ T 细胞 → T 细胞释放 ACh → 作用于巨噬细胞（Rosas-Ballina 2011, Science）。脾切除或 ChAT⁺ T 细胞缺失均阻断该通路（动物实验实锤）。
- **量化**：迷走电刺激可使脓毒症小鼠血清 TNF-α 下降约 **50-70%**、存活率显著提升；α7nAChR 激动剂在 LPS 内毒素血症模型中抑制 TNF 峰值达 **70%+**。

### 2. HPA 轴

```
应激 → 下丘脑室旁核 CRH → 垂体前叶 ACTH → 肾上腺皮质 皮质醇
      ↓
GR（糖皮质激素受体，NR3C1）转位入核
      ↓
① 抑制 NF-κB/AP-1 转录活性（蛋白-蛋白互作，transrepression）
② 上调 IκBα 合成 → 胞质扣留 NF-κB
      ↓
抗炎 + 代谢/免疫重塑（淋巴细胞减少、胸腺萎缩、中性粒细胞↑）
```

- **急性应激**：皮质醇短暂升高是保护性的（抑制过度炎症、动员能量）。
- **慢性应激**：高皮质醇持续暴露 → **胸腺萎缩、淋巴细胞减少、免疫监视下降**（伤口愈合延迟、潜伏病毒再激活）；海马 GR 下调 → HPA 负反馈迟钝 → 皮质醇节律扁平化（晨峰消失）——与老年衰弱、认知衰退相关。
- **糖皮质激素抵抗**：慢性炎症下调 GR 表达与功能（GRβ 亚型占位），抗炎制动失灵——"越炎越不抗炎"的恶性循环。
- **量化**：慢性应激者（照护者队列，Kiecolt-Glaser）CRP/IL-6 较对照组显著升高；高皮质醇负荷（累积暴露）与端粒缩短相关（Epel 2004）。

### 3. 交感神经（β2-AR）

- 去甲肾上腺素（NE）经 **β2-肾上腺素受体**双向调节免疫：**急性**应激促 NK 细胞动员入血（"战斗或逃跑"的防御准备，30 分钟内 NK 可升高数倍）；**慢性**过度激活则抑制 Th1/细胞免疫、促 Th2 漂移、升高骨髓髓系炎症细胞输出。
- **机制**：β2-AR 激活 → Gs → cAMP/PKA → 抑制 T 细胞增殖与 IL-2 产生；单核细胞 IL-12↓、IL-10↑；改变 T 细胞趋化（CXCR3 下调）。
- **解剖基础**：交感神经直接支配脾脏（脾神经）、淋巴结、骨髓——是神经-免疫相互作用的主要效应臂。

### 4. 感觉神经（CGRP/SP）

- 伤害性感觉神经纤维（TRPV1⁺）释放 **CGRP** 与 **P 物质（SP）**：SP 促肥大细胞脱颗粒（组胺、TNF-α、蛋白酶），参与**神经源性炎症**；CGRP 双向调节 DC 抗原呈递（低剂量促、高剂量抑）。
- **临床**：神经源性炎症在类风湿关节炎（关节神经支配丰富）、偏头痛（CGRP 单抗已获批治疗）、银屑病、哮喘中驱动局部炎症。

## 神经-免疫与衰老（慢性应激）

```
慢性应激 → HPA 迟钝（GR↓/皮质醇节律扁平） + 交感过度激活 + 迷走张力↓（HRV↓）
      ↓
糖皮质激素抵抗 → 抗炎制动失灵 + 交感炎症驱动↑
      ↓
NF-κB 慢性激活 → 炎症衰老（inflammaging）加速
      ↓
衰弱 / 心血管病 / 认知衰退 / 抑郁 / 免疫衰老加速
```

- **老年神经免疫特征**：迷走张力下降（HRV 降低，10 年随访中 HRV 低者炎症高、全因死亡↑）；HPA 轴迟钝（皮质醇节律扁平化）；交感静息张力升高（NE 水平随龄上升）。
- 慢性应激与炎症衰老互为放大：**神经免疫失衡是炎症衰老的"放大器"而非"起因"**——这一因果权重仍在争论中。

## 临床/实验证据

- **迷走神经刺激（VNS）**：类风湿关节炎、炎症性肠病小样本试验显示 TNF 与疾病活动度下降（RA 试验 TNF 降幅约 50-60% 部分患者）；VNS 已批准用于难治性癫痫/抑郁，**抗炎适应症在研**。
- **α7nAChR 激动剂**：临床前强效抗炎；人试验（GTS-21 等）安全性良好但疗效未定（脓毒症 II 期未达主要终点）。
- **冥想/正念**：RCT 显示下调 NF-κB 相关炎症基因表达（转录组学，Bhasin 2013：8 周冥想后外周血 NF-κB 通路基因下调、IκB 上调），降低 CRP/IL-6；效应量小、混杂难排除（依从性/生活方式）。
- **呼吸训练**：慢呼吸（6 次/分，迷走共振频率）增强迷走张力（HRV↑）、降低静息炎症与血压——"呼吸性窦性心律不齐"增强迷走传出。
- **运动**：规律运动增强迷走张力、降低静息炎症（IL-6/CRP↓）、改善 HPA 反应性——证据最扎实的行为干预。
- **衰老表现汇总**：老年 HRV↓、皮质醇节律扁平化、慢性应激→炎症衰老加速，与衰弱/心血管/认知衰退关联；社会心理干预（照护者支持）可部分逆转炎症升高。

## NO 在神经免疫中的角色

| NOS 亚型 | 细胞来源 | 神经免疫角色 |
|---|---|---|
| **nNOS（NOS1）** | 神经元 | 中枢突触传递与神经保护；NO 作为神经递质/气体信使调节 HPA 轴与突触可塑性 |
| **eNOS（NOS3）** | 内皮 | 维持血管张力；迷走抗炎的血管基础（脾脏血流与免疫细胞转运）；α7nAChR 信号与 eNOS/NO 生成耦合 |
| **iNOS（NOS2）** | 巨噬细胞/小胶质细胞 | 高浓度 NO 杀菌；慢性炎症下过度产生 → 过氧亚硝酸盐（ONOO⁻）→ 硝化应激损伤神经与免疫组织 |

- **迷走抗炎与 NO 耦合**：迷走刺激 → 脾脏 eNOS/NO 上调，NO 参与抑制巨噬细胞炎症；α7nAChR 激活可经 PI3K/Akt 磷酸化 eNOS。
- **交感与 NO**：β 受体激活影响内皮 NO 生物利用度；慢性交感过度激活 → NO↓、内皮功能障碍。
- **iNOS 悖论**：慢性应激下炎症组织 iNOS 高表达 → 大量 NO + 超氧 → 过氧亚硝酸盐 → 加重神经炎症（小胶质细胞活化、血脑屏障损伤）。**NO 在神经免疫呈剂量依赖"低促保护、高促损伤"**。

## 细胞因子入脑与神经炎症

神经-免疫轴还包括"免疫→脑"的方向——外周炎症如何影响中枢：

- **血脑屏障（BBB）**：外周 IL-6/TNF-α 可经 BBB 的脉络丛与室周器官（CVO）主动转运入脑；慢性炎症损伤 BBB 紧密连接（claudin-5 下调），通透性↑。
- **迷走传入**：外周细胞因子激活迷走传入纤维（结节神经节），将炎症信号经孤束核（NTS）传入脑干——"细胞因子→脑"的快速神经通路（脑与脾之间双向）。
- **小胶质细胞**：入脑的炎症信号激活小胶质细胞，NF-κB 通路持续活化，产生 TNF-α/IL-1β——神经炎症与 AD 等神经退行病相关（慢性神经炎症是 AD 病理的重要环节）。
- **行为表现**：外周炎症诱导"病态行为"（疲乏、社交回避、食欲下降）——经上述通路的中枢效应；老年期该反应被放大（神经炎症加重）。
- **NO 的桥梁角色**：小胶质细胞 iNOS 产生 NO，与超氧生成过氧亚硝酸盐，损伤神经元并激活更多胶质细胞——神经免疫炎症的自我放大环，也是干预靶点（iNOS 抑制在神经退行模型中显示保护）。

## 迷走张力测量与临床关联

迷走张力（vagal tone）的量化核心是**心率变异性（HRV）**：迷走对窦房结的抑制作用形成呼吸性窦性心律不齐，高频功率（HF）与 RMSSD 反映迷走传出强度。应用要点：

- HRV 低与 CRP/IL-6 升高、心血管事件、全因死亡相关（10 年随访队列）。
- 老年 HRV 显著低于青年；运动、慢呼吸、冥想可提升 HRV——是可测量的干预终点。
- 注意混杂：HRV 受年龄、药物（β 阻滞剂）、心律失常影响，解读需校正。

## 神经免疫与精神神经免疫学（PNI）证据链

心理神经免疫学（psychoneuroimmunology）提供了"心理→神经→免疫→健康"的完整证据链：

- **急性应激**：公开演讲/考试等急性应激使唾液皮质醇、循环 NK 数量与活性短期升高——免疫系统为"战斗或逃跑"动员。
- **慢性应激**：长期照护者、丧偶者、低收入人群的 CRP/IL-6 持续升高；DHEA/皮质醇比下降（HPA 轴老化加速）。
- **抑郁与炎症**：重度抑郁患者外周 IL-6/TNF-α 升高，抗 TNF 治疗（英夫利昔单抗）在部分炎症型抑郁亚型中改善症状——"炎症假说"双向证据。
- **孤独与社会隔离**：转录组学显示孤独者 I 型干扰素应答下调、NF-κB 通路上调（Cole 2007, Genome Biol）——"社会基因组学"开创性证据。
- **早期逆境**：童年逆境通过表观遗传（GR 启动子甲基化）持久重塑 HPA 轴与炎症程序——发育期神经免疫印记影响终身健康。

**综合判断**：慢性应激、孤独、抑郁均经 HPA/交感/迷走三条通路汇聚到 NF-κB 炎症程序，构成可量化的免疫风险；行为干预（运动、冥想、社交支持）正是从"上游神经信号"而非"下游炎症分子"入手——这解释了为什么此类干预虽效应量小却机制合理、副作用可忽略。

## 开放问题

1. 迷走抗炎在人是**脾脏依赖**还是多器官效应（脾切除证据仅限动物）？
2. α7nAChR 激动剂能否成为安全口服抗炎药（受体选择性 vs 胆碱能副作用）？
3. 冥想/运动的抗炎获益是否显著优于一般健康生活方式的混杂因素（需更严格对照）？
4. 神经免疫失衡是炎症衰老的**"因"还是"放大器"**；恢复迷走张力能否逆转人类免疫衰老？
5. 慢性应激的"炎症记忆"（表观遗传印记，如 NF-κB 基因位点甲基化改变）是否可被行为干预擦除？
