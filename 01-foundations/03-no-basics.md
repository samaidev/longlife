# NO 基础（Nitric Oxide Biology）

> 一氧化氮（NO）——气体信号分子——由 L-精氨酸在 NO 合酶（NOS）催化下生成。它是迄今唯一被证实的、以自由基形式发挥生理功能的哺乳动物信号分子，也是心血管健康与长寿的核心节点（1998 年诺贝尔生理学或医学奖：Furchgott、Ignarro、Murad）。

---

## 1. 一氧化氮合酶（NOS）三种亚型

### 1.1 基因定位与表达谱

哺乳动物存在三种 NOS 同工酶，由三个独立基因编码：

| 亚型 | 基因 | 人类染色体 | 主要表达 | 基础输出 | Ca²⁺ 依赖 |
|---|---|---|---|---|---|
| nNOS | NOS1 | 12q24.22 | 神经元、骨骼肌、气道 | 低（nM 级） | 是（Ca²⁺/CaM 依赖） |
| iNOS | NOS2 | 17q11.2 | 巨噬细胞、内皮、肝 | 极高（μM 级） | 否（CaM 组成性结合） |
| eNOS | NOS3 | 7q36.1 | 内皮、心肌、血小板 | 低（pM–nM 级） | 是（Ca²⁺/CaM 依赖） |

**关键差异**：nNOS 与 eNOS 受胞内 Ca²⁺ 瞬时升高激活，输出以"脉冲式"低浓度为主；iNOS 因钙调蛋白（CaM）以极低 Ca²⁺ 亲和力组成性结合，一旦被转录诱导（炎症因子 TNF-α、IFN-γ、LPS）即可持续、高水平产 NO 数小时至数天。

**表达调控**：三种 NOS 的表达受不同机制调控。eNOS 为组成性表达，但转录仍受剪切应力、雌激素（经雌激素受体直接结合 NOS3 启动子）、他汀（稳定 eNOS mRNA 半衰期）与氧化应激（下调）调节；其蛋白还经 N 端甘氨酸**豆蔻酰化**与**棕榈酰化**修饰锚定于内皮细胞小窝（caveolae）膜微区，与小窝蛋白 caveolin-1 结合呈"静止态"，Ca²⁺/CaM 结合后方脱离小窝而激活——这一亚细胞定位机制保证 eNOS 可被瞬时精确开关。nNOS 在神经元组成性表达，受神经元活动与神经营养因子调节；iNOS 则由 NF-κB、STAT1、IRF-1 等转录因子在炎症信号下强力诱导，其启动子含多个炎症响应元件，故称"诱导型"。

### 1.2 蛋白结构：同源二聚体

三种 NOS 均为**同源二聚体**，每个单体含两大致功能域，中间由一段约 20–30 氨基酸的钙调蛋白结合（CaM-binding）柔性铰链连接：

```
          ┌────────────────── 单体 ──────────────────┐
N端       │  加氧酶域 (Oxygenase)   │   还原酶域 (Reductase) │  C端
          │  O₂ 结合 / 精氨酸结合     │   电子传递               │
          │  血红素(b-Heme)          │   FMN — FAD — NADPH     │
          │  BH4 结合               │                        │
          │  Zn²⁺ 中心             │                        │
          └────────────────────────┴────────────────────────┘
                      ↑                ↑
                   CaM 结合区（铰链）    自动抑制元件(AL)
```

- **加氧酶域**（N 端，约 450 aa）：含**b 型血红素（铁原卟啉）**，是 O₂ 与 L-精氨酸结合及活化的中心；含**BH4（四氢生物蝶呤）**结合位点；含**Zn²⁺ 四配位中心**（Zn²⁺ 桥接两个单体的 Cys，稳定二聚体界面）。
- **还原酶域**（C 端，约 400 aa）：含 FMN、FAD 与 NADPH 结合位点，含一个**自动抑制元件（autoinhibitory element, AL）**，CaM 结合后解除抑制、释放电子流。
- **CaM 铰链**：位于两域之间；Ca²⁺ 浓度升高 → Ca²⁺ 结合 CaM → CaM 构象改变结合铰链区 → 解除 AL 抑制 → 启动电子流。

**磷酸化位点**（eNOS 尤为关键）：
- **Ser1177**（人序列，内皮）：**激活**位点。Akt/PKB、AMPK、PKA、PKG 均可磷酸化此位点，显著提高酶对 Ca²⁺ 的敏感性（降低激活阈值）。磷酸化后即使胞内 Ca²⁺ 较低也能产 NO。
- **Thr495**（人序列）：**抑制**位点。由 PKC 磷酸化，降低 CaM 结合亲和力、抑制电子流。Akt 磷酸化 Ser1177 与 PKC 磷酸化 Thr495 呈拮抗关系，共同构成 eNOS 活性的"开关"。
- **Ser615 / Ser633**：磷酸化激活，与 Ser1177 协同。

### 1.3 催化机制：两步氧化 + 电子流

eNOS/nNOS/iNOS 催化 L-精氨酸氧化为 L-瓜氨酸并释放 NO，分**两步单加氧反应**：

```
Step 1:  L-Arg ──O₂, NADPH, BH4──> Nω-羟基-L-精氨酸 (NHA)
Step 2:  NHA   ──O₂, NADPH, BH4──> L-瓜氨酸 + NO
净反应:  2 L-Arg + 3 NADPH + 4 O₂ → 2 L-瓜氨酸 + 3 NADP⁺ + 4 H₂O + 2 NO
```

**电子流全程（每步）**：

```
NADPH → FAD → FMN → [CaM 铰链] → 血红素(Fe²⁺) → 活化的 O₂
          ↑                          │
          └──────── BH4 参与───────┘
```

- **第一步**：L-精氨酸的胍基氮在血红素-氧复合物催化下被羟基化，生成 NHA。
- **第二步**：NHA 的羟基被氧化脱氢，释放 NO 与 L-瓜氨酸；此步依赖 BH4 提供单电子，防止"解偶联"。

**BH4 与解偶联（uncoupling）**：BH4 通过稳定血红素上的氧活性中间体、参与第二步的单电子传递，保障 O₂ 全部用于精氨酸氧化。当 BH4 缺乏或被氧化（BH4→BH2），eNOS 无法完成精氨酸氧化，电子流向 O₂ 生成**超氧阴离子（O₂⁻）**而非 NO——此即"eNOS 解偶联"，是血管衰老、高血压、糖尿病内皮功能障碍的核心机制之一。

**剪切应力激活**：血流对内皮的剪切应力经 PECAM-1/VE-cadherin/VEGFR2 复合体感知，激活 PI3K–Akt 通路磷酸化 eNOS Ser1177，同时促进 Ca²⁺ 内流，双路径协同使 eNOS 在数秒至数分钟内启动——这是运动获益与"血流介导的血管舒张"（FMD，临床评估内皮功能的标准方法）的分子基础。

## 2. NO 信号通路

### 2.1 sGC/cGMP/PKG 全链条

NO 的经典信号为**可溶性鸟苷酸环化酶（sGC）→ cGMP → PKG**：

```
NO ──► 结合 sGC 血红素 Fe²⁺ (配位键, 5配位→6配位)
      │
      ▼
sGC 活性 ↑ 100–200 倍  ── GTP → cGMP
                            │
                            ▼
                cGMP 依赖蛋白激酶 (PKG / cGK)
                            │
              ┌─────────────┼──────────────┐
              ▼             ▼              ▼
        平滑肌舒张     血小板抑制      心肌/神经调控
        (MLCK/肌球蛋白  (GP1b/αIIbβ3     (离子通道,
         轻链去磷酸化)   去磷酸化)        收缩力调节)
```

- **sGC**：含血红素辅基，NO 以皮摩尔–纳摩尔浓度即可与其 Fe²⁺ 高亲和结合，使酶活性提升百倍以上，将 GTP 环化生成 cGMP。
- **cGMP**：作为第二信使，激活 PKG（cGK-I/II）。
- **PKG** 下游效应（血管）：磷酸化肌球蛋白轻链磷酸酶（MLCP）使其激活 → 平滑肌肌球蛋白轻链去磷酸化 → 肌丝松弛 → **血管舒张**；同时抑制 L 型钙通道、激活 K⁺ 通道使细胞膜超极化。
- **NO–sGC–cGMP 通路的药理支点**：硝酸甘油（释放 NO）、sGC 激动剂（利奥西呱）、PDE5 抑制剂（西地那非抑制 cGMP 降解）。1998 年诺贝尔奖即源于此通路。

### 2.2 S-亚硝基化化学（S-nitrosylation）

NO 并非只走 cGMP 通路，还能对蛋白**半胱氨酸巯基（Cys-SH）**进行可逆共价修饰——S-亚硝基化（S–NO），形成蛋白级"NO 代码"：

```
R-SH (半胱氨酸巯基) + NO⁺/N₂O₃ ──► R-SNO (S-亚硝基化) + H⁺
                                      │ 还原性环境 / 硫氧还蛋白
                                      ▼
                              R-SH (可逆恢复)
```

- **化学本质**：生理条件下 NO 本身不直接亚硝基化巯基，需经 N₂O₃（NO 与 O₂ 反应产物）或过渡金属介导传递 NO⁺。
- **基序偏好**：常见修饰位点处于**酸性残基（Asp/Glu）与碱性残基（Lys/Arg/His）包围的 Cys**，如 CXXC、CX₃C 等基序；血红素蛋白、金属硫蛋白巯基优先被修饰。
- **可逆性**：S–NO 键在细胞内可被**谷胱甘肽（GSH）、硫氧还蛋白（Trx）**等还原体系快速逆转，故为可逆、动态、可编程的翻译后修饰。
- **功能后果**：调控离子通道、受体、转录因子、代谢酶（如 ryanodine 受体、血红蛋白、NF-κB）活性。S-亚硝基化异常（尤其衰老/氧化应激下）被指与神经退行、内皮障碍相关。

### 2.3 NO 与超氧反应：过氧亚硝酸盐（ONOO⁻）

当 NO 与超氧阴离子同时存在且浓度相当，发生**扩散控制级反应**（速率常数 ~10⁹–10¹⁰ M⁻¹s⁻¹，比 SOD 催化还快）：

```
NO•  +  O₂•⁻  ──►  ONOO⁻  (过氧亚硝酸盐, 强氧化剂)
                        │
                        ├──► 硝化酪氨酸 (3-nitrotyrosine)  → 蛋白损伤
                        ├──► 氧化脂质、DNA
                        └──► 线粒体复合物 I/II 抑制 → 能量衰竭
```

- ONOO⁻ 及其质子化形式 ONOOH 是强氧化剂，选择性硝化酪氨酸残基（形成 3-硝基酪氨酸，病理标志物），氧化含硫残基，抑制线粒体呼吸链。
- **生理 vs 病理**：生理低浓度 NO 几乎不与超氧相遇（局部浓度低）；当 iNOS 高输出（脓毒症、慢性炎症）或 eNOS 解偶联产超氧时，NO 与 O₂⁻ 摩尔比趋近 1:1，ONOO⁻ 生成激增 → **硝化应激**。这是 NO 双刃剑的分子根源。

### 2.4 NO 信号的非经典通路

除 sGC/cGMP/PKG 经典通路与 S-亚硝基化外，NO 还有几条重要的非经典信号机制，在特定组织与条件下发挥关键作用：

- **cGMP 非依赖的 PKG 激活**：NO 可在缺乏 cGMP 的情况下直接经 S-亚硝基化激活某些信号分子，包括小 GTP 酶（Ras、RhoA）、转录因子（NF-κB 的 p50 亚基、HIF-1α）与激酶（JNK、p38 MAPK）。这些通路介导 NO 的基因表达调控功能，例如 HIF-1α 的 S-亚硝基化可稳定其蛋白、增强低氧适应基因（VEGF、EPO）的转录——这是 NO 参与血管新生与缺血预适应的机制之一。
- **与线粒体的直接对话**：NO 以可逆方式结合细胞色素 c 氧化酶（复合物 IV）的血红素-铜中心，与 O₂ 竞争结合位点——在低氧时 NO 可"接管"复合物 IV 的氧结合位点，抑制呼吸链、改变线粒体膜电位与活性氧生成。这一机制使 NO 成为"氧传感器"的组成部分：低氧 + 高 NO 时线粒体转向产生活性氧作为信号（mitochondrial ROS signaling），激活 HIF-1α 与细胞保护程序（缺血预适应）。生理浓度的 NO 还可抑制复合物 I，减少电子漏出，起抗氧化作用；而高浓度 NO/ONOO⁻ 则不可逆损伤复合物 I/II，走向病理。
- **NO 与血红素蛋白的相互作用谱**：除 sGC 外，NO 还结合血红蛋白（转运与灭活 NO）、肌红蛋白（低氧时作为 NO 的"还原酶"将其转化为硝酸盐）、细胞色素 P450（抑制药物代谢）、过氧化氢酶（可被 NO 抑制，间接升高 H₂O₂）。这些相互作用的净效应取决于局部氧分压与 NO 浓度——解释了 NO 在"生理信号"与"病理损伤"之间转换的连续性。
- **亚硝酸盐还原为 NO 的非酶促途径**：在低氧/酸性条件下（缺血组织、胃腔、口腔），亚硝酸盐（NO₂⁻）可被脱氧血红蛋白、脱氧肌红蛋白、黄嘌呤氧化酶或维生素 C 还原为 NO——这是"膳食硝酸盐→NO"旁路的化学基础（详见 02-vascular/02-dietary-nitrate.md），也是 NO 生物学从"酶促唯一"拓展为"酶促+非酶促双通路"的关键认识转变。

## 3. NO 生理功能

| 系统 | 功能 | 核心机制 |
|---|---|---|
| **血管** | 内皮依赖性舒张、抗血小板聚集、抗白细胞黏附、抗平滑肌增殖 | eNOS 产 NO → sGC/cGMP/PKG → 血管扩张；抑制粘附分子表达 |
| **神经** | 突触可塑性（LTP）、神经递质释放调节、脑血流 | nNOS 产 NO 逆向扩散入突触前，经 cGMP/PKG 调控；NO 是"逆行信使" |
| **免疫** | 巨噬细胞杀菌/抗肿瘤 | iNOS 产高浓度 NO 与 ROS 协同杀伤病原体与肿瘤细胞 |
| **代谢** | 胰岛素敏感性、线粒体生物发生、糖摄取 | NO → AMPK/PGC-1α 通路；NO 促进骨骼肌 GLUT4 转位 |

- **血管**：NO 是内皮源性舒张因子（EDRF）的本质。血流剪切应力激活 eNOS，维持血管基础张力（静息时持续低量产 NO），保护动脉完整。NO 还抑制血小板 GPIIb/IIIa 活化与 P-选择素表达，防止血栓形成；抑制单核细胞黏附分子（VCAM-1/ICAM-1），是"内皮保护"的核心。内皮 NO 生物利用度是 FMD 测得的血管功能指标，也是心血管事件风险的独立预测因子。
- **神经**：nNOS 定位于突触后致密区，受 NMDA 受体激活的 Ca²⁺ 内流调控，产 NO 逆向扩散至突触前，参与长时程增强（LTP，学习记忆）。NO 还调节脑血流耦合（神经元活动与局部灌注的匹配）、嗅觉信号与胃肠蠕动（肠肌丛 NO 是抑制性递质）。
- **免疫**：iNOS 在巨噬细胞中被病原体/细胞因子诱导，产生 μM 级 NO，与活性氧协同构成杀菌武器。NO 也双向调节免疫——低浓度抑制淋巴细胞增殖与炎症，高浓度诱导凋亡清除过度炎症细胞。
- **代谢**：NO 增强肌肉对葡萄糖摄取、促进线粒体生物发生，与运动获益及胰岛素敏感性相关。NO 还调控脂肪细胞脂解（抑制）与棕色脂肪产热（促进），参与产热代谢调节。

### 3.1 NO 与运动适应：剪切应力的"运动处方"逻辑

运动是激活 eNOS 的最强生理刺激，其机制链条完整清晰：肌肉收缩驱动血流加速 → 血管内皮承受的剪切应力升高（层流剪切 10–20 dyn/cm²）→ PECAM-1/VE-cadherin/VEGFR2 机械感受复合体被激活 → PI3K/Akt 磷酸化 eNOS-Ser1177 → NO 生成增加 → 血管舒张、血流灌注改善、血管重塑。**单次急性运动即可提升 NO 依赖的血管舒张功能数小时；长期规律运动则通过上调 eNOS 表达、改善内皮抗氧化能力、增加内皮祖细胞动员，实现"血管年轻化"的结构性适应。**

运动处方中的剂量-效应关系：中等强度有氧运动（最大摄氧量的 50–70%）对 eNOS 激活最优；高强度间歇训练（HIIT）通过反复剪切应力脉冲产生类似效果且时间效率更高；阻力训练则主要改善肌肉血流与毛细血管密度。值得注意的是，**久坐本身是一种"NO 剥夺"**——长时间静态姿势使局部剪切应力骤降，eNOS 表达下调，这解释了为何"久坐-运动缺乏"是独立于总体活动量的心血管风险因素（如长时间飞行后深静脉血栓风险升高，部分与静脉血流淤滞、NO 依赖的内皮抗栓功能减弱有关）。

### 3.2 NO 与免疫调节：从杀菌到免疫稳态

NO 在免疫系统中的角色是"浓度决定立场"：巨噬细胞经 iNOS 产生的 μM 级 NO 是杀灭病原体的核心武器（与吞噬体 ROS 协同，硝化病原体蛋白与 DNA）；但这一杀伤性输出必须被严格限制在炎症局部。系统层面的 NO 生物学效应还包括：

- **调节性 T 细胞（Treg）功能**：生理浓度 NO 促进 Treg 分化与 Foxp3 表达，抑制效应 T 细胞增殖，维持外周免疫耐受——NO 生物利用度下降时，免疫平衡向促炎方向偏移。
- **树突状细胞成熟**：NO 抑制树突状细胞的过度成熟与抗原提呈，防止自身免疫反应；iNOS 敲除小鼠更易发生实验性自身免疫脑脊髓炎（EAE，多发性硬化模型）。
- **肥大细胞与过敏性反应**：NO 抑制肥大细胞脱颗粒，减轻过敏反应；呼出气 NO（FeNO）因此成为气道炎症的临床标志物（哮喘诊断与监测）。
- **抗感染与抗肿瘤的边界**：NO 的抗肿瘤作用（高浓度杀伤肿瘤细胞）与促肿瘤作用（低浓度促进血管新生、抑制抗肿瘤免疫）并存，是"NO 双刃剑"在肿瘤免疫中的体现——这也解释了为何 iNOS 抑制剂在肿瘤治疗中的结果相互矛盾。

### 3.3 NO 与衰老：从血管到全身的"NO 耗竭假说"

NO 生物利用度随年龄进行性下降（40 岁后每十年约降 10–15%），机制包括：eNOS 表达下调、BH4 氧化导致解偶联、精氨酸酶活性升高（与 eNOS 争抢底物）、ADMA 累积（DDAH 活性下降）、氧化应激增强（O₂⁻ 直接淬灭 NO）、SASP 炎症因子抑制 eNOS 信号。**"血管衰老 = NO 耗竭"在多个层面成立**：FMD 随龄下降（30 岁约 8–10% → 70 岁约 4–5%）、主动脉僵硬度（PWV）随龄上升、内皮祖细胞数量与功能随龄衰退。

更广义的"NO 耗竭假说"认为：NO 是连接衰老各标志的枢纽分子——它同时影响线粒体功能（复合物 IV 调控）、炎症（NF-κB 抑制）、代谢（AMPK/PGC-1α）、表观调控（SIRT1 激活）与干细胞功能（内皮祖细胞）。因此，**维持 NO 生物利用度既是血管健康的直接目标，也是抗衰老干预的共同下游**（运动、热量限制、膳食硝酸盐、NAD⁺ 补充、部分中药成分均以恢复 NO 通路为重要机制，详见 02-vascular 与 06-tcm 各篇）。

## 4. NO 双刃剑：浓度依赖与时空特异

```
                    浓度（对数轴）
pM ── nM ────── nM–μM ────────── μM ── mM
 |        |             |              |
 基础信号   生理舒张    炎症/iNOS       病理高输出
 抗凋亡    抗血小板     亚硝化应激       线粒体损伤
 抗炎      细胞保护     适量杀菌         细胞毒性
```

- **低浓度（pM–nM）**：抗炎、抗凋亡、抗血小板、保护内皮。这是血管健康所需的"生理 NO"。
- **高浓度（μM）**：iNOS 诱导产生，虽可杀菌，但伴 ONOO⁻ 生成 → 硝化应激、线粒体损伤、DNA 损伤，参与脓毒症休克、慢性炎症、衰老。
- **时空特异**：NO 半衰期仅数秒（受氧与血红蛋白快速清除），作用半径约 100–300 μm，故其效应高度依赖"产生地点-时间-浓度"三要素。eNOS/nNOS 的脉冲式低输出与 iNOS 的持续高输出是同一分子的正反两面。

## 5. NO 测量方法

| 方法 | 原理 | 检测限 | 优势/局限 |
|---|---|---|---|
| **Griess 反应** | NO 氧化产物亚硝酸盐/硝酸盐 (NOx) 与磺胺重氮化、与 NED 偶联显色 | ~0.5–1 μM | 简单廉价；但只能测稳定代谢物，需还原硝酸盐，反映累积量而非瞬时浓度 |
| **化学发光法** | NO/O₃ 反应产生激发态 NO₂⁺，发光被光电倍增管检测 | pM–nM | 高灵敏、近实时、可直接测 NO；为金标准之一，但设备昂贵、需气液分离 |
| **电子顺磁共振（EPR）** | NO 与铁螯合物（如 Fe-DETC）形成加合物，检测其顺磁信号 | nM | 直接检测 NO 自由基、组织穿透、可体内测量；但需自旋捕获剂、定量复杂 |

**应用提示**：血液中 NO 半衰期极短，临床多测 NOx（Griess）或呼气 NO（哮喘、气道炎症监测）；研究级更常用化学发光与 EPR 获取瞬时真实 NO。

**方法学陷阱**：Griess 法无法区分亚硝酸盐与硝酸盐来源（饮食硝酸盐、肠菌、肾排泄均影响 NOx），需禁硝酸盐饮食后采样并加硝酸还原酶；化学发光需严格除氧与防止样品自发氧化；EPR 的 spin trap 选择与定量曲线建立是主要误差来源。**三种方法测得的都不是同一对象**——Griess 测代谢累积、化学发光测即时 NO、EPR 测自由基本体，解读结果时必须标明检测目标。

## 6. 证据分级与开放问题

### 证据分级

| 层级 | 内容 | 证据类型 |
|---|---|---|
| A（确证） | NOS 三种亚型结构与两步催化机制；sGC/cGMP/PKG 通路；NO 为 EDRF | 结构生物学、酶学、1998 诺贝尔奖 |
| B（强） | eNOS 解偶联与内皮功能障碍的因果；ONOO⁻ 病理作用 | 动物模型、临床观察（高血压/糖尿病） |
| C（中等） | S-亚硝基化蛋白组在衰老中的系统性作用；NO 与代谢的临床获益 | 蛋白质组学、部分 RCT |

### 开放问题

1. **剂量-效应边界**：生理与病理 NO 的确切浓度阈值尚无法在体内精确界定。
2. **eNOS 解偶联的精细调控**：BH4 代谢、氧化还原态的时空调控机制未完全阐明。
3. **S-亚硝基化蛋白组与衰老**：NO 代码在衰老中的系统性变化及其因果作用待明。
4. **NO 通路治疗窗**：如何在保持生理 NO 的同时避免 iNOS 高输出——即"双向调控"策略尚无定论。

## 7. 与 NAD+/SIRT1 长寿网络的耦合

NO 并非孤立信号：NAD+/SIRT1 去乙酰化激活 eNOS → NO 生成↑；NO 又经 cGMP/AMPK 通路上调 SIRT1 → 构成长寿正反馈环（详见 04）。内皮 NO 生物利用度下降是血管衰老的早期标志，也是连接代谢、免疫与血管健康的中枢枢纽。
