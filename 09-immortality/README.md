# 09 · 永生药专题 Immortality Quest

> **专题定位**：从整个知识库寻找"永生药突破口"的综合研究。不贩卖永生幻想，而是把"永生"拆解为**可评估的科学问题**——定义、候选、机制、路线图四层递进。
> 主线衔接：本专题与知识库全部 8 大板块交叉引用（NO 通路 · NAD⁺/SIRT1 · 12 大衰老标志 · 前沿抗衰），是知识库的"决策层"。

## 📚 目录

- [01-永生的科学定义与可行性框架](01-immortality-framework.md)
  - "永生"是什么：生物学永生（死亡率不随龄上升）vs 文化永生 vs 医学延寿
  - 为什么我们会衰老：12 大标志 + 程序性/损伤性理论 + 表观信息丢失理论
  - 寿命极限之争：115 岁墙 vs 可突破派（5 亿美金赌局）
  - 核心洞见：永生药 = 多靶点工程，不是单一药物

- [02-永生药候选突破口：六大路径横向对比](02-breakthrough-candidates.md)
  - 评估框架：逆转深度/证据强度/临床进度/安全性/可规模化/主线协同 六维打分
  - 六大候选：表观重编程（31/40，唯一实测逆转）、Senolytics（27）、mTOR/AMPK（27）、端粒酶（21）、NAD⁺/线粒体、基因治疗/染色质
  - 核心判断：**表观重编程最接近"永生药"**（ER-100 已进人体 I 期）；真永生 = 组合拳

- [03-死亡机制与寿命极限](03-death-mechanism.md)
  - 三种死亡：意外 / 程序性 / 衰老性（Gompertz 定律）
  - 经典衰老理论：突变累积 / 拮抗多效性 / 一次性体细胞 / 程序性衰老
  - 寿命极限：Dong 2016 的 115 岁上限 vs 超级百岁老人
  - 核心洞见：衰老是"软件故障+硬件磨损"双轨 → 永生药须双轨并进

- [04-永生药研发路线图](04-roadmap.md)
  - 四阶段：0-5 年（生活方式+老药再定位）→ 5-15 年（ER-100/Senolytics/AI）→ 15-30 年（全身逆转+组合）→ 30 年+（生物学永生理论）
  - 个人"长寿处方"三梯队：现在做 / 优化十年 / 押注未来
  - 开放问题：可及性公平 / 身份连续性 / 资源分配

## 🎯 专题核心结论

1. **永生药不是一种药，而是一个"组合干预持续改写死亡率曲线"的工程**
2. **表观重编程是目前唯一实测能"逆转"生物年龄的路径**（OSK→TET→去甲基化→时钟回拨），ER-100 人体试验（2026.3）是分水岭
3. **现实目标**：健康寿命逼近 ~120 岁极限、压缩失能期；"生物学永生"是远期开放命题
