# 代谢衰老：胰岛素抵抗、营养感应失调与长寿 Metabolic Aging

> 代谢衰老指随龄出现的全身代谢重构：胰岛素敏感性下降、脂质代谢紊乱、线粒体功能减退，以及 AMPK/mTOR 营养感应网络的失衡。它既是衰老的后果，也是驱动因素——代谢失调通过促进炎症、表观漂移与器官损伤，加速其他衰老标志，是多种老年慢性病（2 型糖尿病、心血管病、NAFLD、肌少症）的共同上游。本篇章按"信号通路 → 组织代谢 → 干预策略"展开。

---

## 1. 胰岛素信号通路与胰岛素抵抗

### 1.1 胰岛素信号全链条

胰岛素经胰岛素受体（IR）启动信号，经典通路为 IRS-1/PI3K/Akt：

```
胰岛素 ──► IR (酪氨酸激酶自磷酸化)
             │
             ▼
        IRS-1/2 (Tyr 磷酸化)
             │
             ▼
        PI3K (p85/p110) ──► PIP2 → PIP3
                                │
                                ▼
                            PDK1 → Akt (Thr308)
                              │  mTORC2 → Akt (Ser473)
                              ▼
                     ┌────────┴────────┐
                     ▼                 ▼
                GLUT4 转位            FoxO1 出核
              (AS160/TBC1D4)        (糖异生基因↓)
                     │
                     ▼
               葡萄糖摄取↑
```

- **IRS-1**：IR 下游首个接头蛋白，其 Tyr 磷酸化招募 PI3K；**Ser 磷酸化（Ser307/Ser312 等）则是胰岛素抵抗的核心开关**——被 JNK、IKKβ（炎症）、mTOR/S6K（过度营养）、PKC（脂毒性）磷酸化后，IRS-1 与 IR 解离、降解，信号中断。
- **PI3K/Akt**：Akt 磷酸化 AS160/TBC1D4，解除对 Rab GTPase 的抑制，驱动 **GLUT4** 囊泡转位至质膜——这是胰岛素刺激骨骼肌/脂肪摄取葡萄糖的限速步骤。
- **Akt 的另一臂**：磷酸化 FoxO1 使其滞留胞质，抑制肝糖异生基因（PEPCK、G6Pase）表达，是胰岛素"降糖"的另一机制。

### 1.2 胰岛素抵抗的发生机制

| 驱动因素 | 分子事件 | 结果 |
|---|---|---|
| 炎症（TNF-α、IL-6） | JNK/IKKβ 激活 → IRS-1 Ser 磷酸化 | 信号中断 |
| 脂毒性（DAG/神经酰胺） | PKCθ/ε 激活 → IRS-1 Ser 磷酸化 | 信号中断 |
| 内质网应激 | PERK/JNK 激活 | 信号中断 |
| 线粒体 ROS | 磷酸酶（PTEN/PTP1B）活性改变 | 负调控增强 |
| 高糖/过度营养 | mTOR/S6K 负反馈磷酸化 IRS-1 | 信号中断 |

**关键量化**：正常人胰岛素刺激下骨骼肌葡萄糖摄取约增加 5–10 倍；胰岛素抵抗者（如 2 型糖尿病一级亲属）此增幅可降至 2–3 倍。**高胰岛素-正葡萄糖钳夹（hyperinsulinemic-euglycemic clamp）**是测量胰岛素敏感性的金标准，M 值（mg/kg/min）随龄与肥胖显著下降。

## 2. 脂代谢与脂肪组织衰老

### 2.1 脂肪组织随龄重塑

- **分布改变**：皮下脂肪减少、内脏脂肪与异位脂肪增加——内脏脂肪（VAT）的脂肪细胞更大、更易释放游离脂肪酸（FFA）与促炎因子。
- **脂肪细胞衰老**：衰老脂肪细胞（p16/SA-β-gal 阳性）分泌 SASP（IL-6、TNF-α、MCP-1），招募巨噬细胞（M1 极化），局部炎症驱动全身胰岛素抵抗；senolytics（清除衰老细胞）在动物中改善代谢表型。
- **脂解失控**：随龄脂肪组织对胰岛素抑制脂解的敏感性下降 → 血浆 FFA 升高 → 异位沉积。

### 2.2 异位沉积与脂毒性

```
皮下脂肪储存能力↓ / 脂解↑
        │
        ▼
血浆 FFA ↑ ──► 骨骼肌 DAG/神经酰胺↑ ──► PKCθ ──► IRS-1 Ser-P ──► 胰岛素抵抗
        │
        ├─► 肝脏 DAG↑ ──► PKCε ──► IRS-2 抑制 ──► 肝糖输出↑ (NAFLD)
        │
        └─► β细胞脂质↑ ──► 脂凋亡/功能受损 ──► 胰岛素分泌↓
```

**脂毒性分子**：**二酰甘油（DAG）**经 PKCθ/ε 磷酸化 IRS 的 Ser 位点，是肌肉与肝脏胰岛素抵抗的公认介质；**神经酰胺（ceramide）**激活 PP2A/PKCζ，抑制 Akt 并诱导 β 细胞凋亡；氧化 LDL 与游离胆固醇损伤血管与胰岛。

## 3. AMPK–mTOR 营养感应

### 3.1 AMPK：能量匮乏传感器

AMPK 是异源三聚体（α 催化亚基 + β + γ 调节亚基），γ 亚基含 AMP/ADP 结合位点：
- **激活**：AMP/ATP 比值升高（能量匮乏）→ AMP 结合 γ 亚基 → 构象改变 + 上游激酶 LKB1（或 CaMKKβ）磷酸化 α 亚基 **Thr172** → 激活。
- **下游效应**：磷酸化并抑制合成代谢（ACC1/2 → 脂肪酸合成↓、mTORC1 抑制）；激活分解代谢（ULK1 启动自噬、PGC-1α 上调线粒体生物发生、GLUT4 转位↑）。
- **随龄变化**：多个组织中 AMPK 活性随龄下降（上游 LKB1 信号减弱、慢性炎症抑制），与代谢灵活性丧失一致。

### 3.2 mTORC1：合成代谢主开关

- **激活**：氨基酸（亮氨酸经 Sestrin2/GATOR2 → Rag GTPase）、生长因子（PI3K/Akt → TSC2 抑制）、能量充足（AMPK 失活）。
- **下游**：S6K1/4E-BP1（蛋白合成↑）、SREBP1（脂质合成↑）、抑制自噬。
- **随龄变化**：mTORC1 活性随龄升高或失调（尤其组织特异性），驱动 SASP、蛋白稳态崩溃；**雷帕霉素抑制 mTORC1 延长多种模式生物寿命**（小鼠 9–14%，2012 年 NIA ITP 研究证实）。

```
      能量匮乏         营养充足/生长因子
         │                  │
         ▼                  ▼
       AMPK ──────────────► 抑制 ──► mTORC1
         │                        │
         ├─► 自噬↑                ├─► 蛋白合成↑
         ├─► PGC-1α↑             ├─► 脂质合成↑
         └─► ACC 抑制(脂肪合成↓)  └─► 自噬↓
```

**平衡要点**：AMPK 与 mTORC1 互为拮抗。衰老时"AMPK↓ + mTORC1↑"的组合推动合成代谢过剩、自噬不足、炎症与胰岛素抵抗——恢复平衡是代谢抗衰的核心策略（详见第 6 节）。

## 4. 代谢灵活性

代谢灵活性（metabolic flexibility）指机体在**糖氧化与脂肪氧化之间快速切换**的能力，是代谢健康的核心指标：
- **正常态**：进食后糖氧化为主（胰岛素↑ 抑制脂肪氧化）、空腹/运动时切换为脂肪氧化（FFA↑）。
- **衰老/肥胖态**：切换能力下降——无论空腹还是进食，机体都倾向于氧化糖（"糖依赖"），脂肪氧化能力受损，表现为呼吸商（RQ）昼夜波动减小、脂肪氧化率下降。

**分子基础**：脂肪酸氧化限速酶（CPT1 经丙二酰-CoA 抑制）调控受损；线粒体含量与质量下降（PGC-1α 下调）；底物竞争（Randle 循环：脂肪酸氧化抑制葡萄糖氧化）失衡。

```
代谢灵活（健康）：  进食 ──► 糖氧化为主 ──► 空腹 ──► 脂肪氧化为主
代谢僵化（衰老）：  进食 ──► 糖氧化 ──► 空腹 ──► 仍依赖糖（脂肪氧化受损）
```

**测量**：间接测热法（呼吸商）、高胰岛素钳夹 + 底物示踪、运动前后 FFA 动力学。干预：运动训练、低碳/生酮、间歇性禁食均可部分恢复代谢灵活性。

## 5. 线粒体代谢与 ROS

- **TCA 循环**：乙酰-CoA 进入三羧酸循环（柠檬酸合酶、异柠檬酸脱氢酶、α-KG 脱氢酶、琥珀酸脱氢酶等），产生 NADH/FADH₂ 与代谢中间体（α-KG 同时是表观遗传酶底物）。
- **氧化磷酸化**：NADH/FADH₂ 经电子传递链（复合物 I–IV）泵出质子，ATP 合酶（复合物 V）利用质子梯度合成 ATP——每分子葡萄糖完全氧化净产约 30–32 分子 ATP。
- **ROS 生成**：电子漏主要发生在复合物 I 与 III（1–4% 的氧被单电子还原为超氧），衰老时漏出比例升高；ROS 损伤 mtDNA、蛋白与脂质，构成"线粒体衰老"正反馈。
- **代谢与衰老的联系**：线粒体功能障碍 → 能量供应不足（肌少症、脑功能下降）+ ROS 升高 + 代谢中间体失衡（乙酰-CoA、α-KG 变化影响表观遗传），是代谢衰老与生物年龄加速的中介（详见 04 篇线粒体专题）。

## 5.1 代谢衰老与 NO 通路：双向恶化的分子桥梁

代谢紊乱与 NO 生物利用度下降在分子层面深度耦合，构成"代谢-血管"恶性循环：

- **胰岛素抵抗 → NO 下降**：胰岛素经 PI3K/Akt 磷酸化 eNOS-Ser1177 促进 NO 生成（见 [01-no-cardiovascular](01-no-cardiovascular.md)）。胰岛素抵抗时该支路受损，NO 生成减少、内皮素-1 增加——"选择性胰岛素抵抗"使血管舒缩失衡，这是糖尿病/代谢综合征患者内皮功能障碍的直接机制。
- **高血糖 → eNOS 解偶联**：高糖通过 PKC 激活、AGEs 生成、氧化应激使 BH4 氧化，eNOS 转为产超氧（解偶联），NO 进一步减少——"糖毒性"与"NO 耗竭"互为表里。
- **脂毒性 → 精氨酸酶上调**：内脏脂肪释放的 TNF-α/IL-6 上调精氨酸酶（与 eNOS 争抢 L-精氨酸）、抑制 DDAH（ADMA 降解），血浆 ADMA 升高 1.5–2 倍，直接抑制 eNOS。
- **NO 下降 → 代谢恶化**：NO 是骨骼肌葡萄糖摄取的促进信号（经 AMPK/GLUT4 转位），NO 不足削弱运动诱导的代谢适应；NO 还调控脂肪组织血流（影响脂解与底物转运）与棕色脂肪产热（UCP1 依赖 NO 信号）。

**临床意义**：改善代谢（减重、运动、控糖）与恢复 NO（膳食硝酸盐、运动、戒烟）互为放大器——"代谢健康"与"血管年轻"是同一硬币的两面。这也解释了为何地中海饮食/运动干预能同时改善胰岛素敏感性、FMD 与血压（详见 [07-interventions/03-nutrition.md](../07-interventions/03-nutrition.md)）。

## 6. 禁食与生酮

### 6.0 代谢衰老的"营养感应失调"全景

AMPK/mTOR 失衡并非孤立事件，而是营养感应网络（nutrient sensing network）整体失调的一部分。该网络还包括：**SIRT1**（NAD⁺ 依赖的去乙酰化酶，感知能量状态）、**胰岛素/IGF-1 信号**（感知生长因子）、**FGF21**（肝脏分泌的代谢应激激素）、**AMPK/mTORC1**（感知能量与氨基酸）。衰老时这五条通路协同漂移：

| 通路 | 衰老方向 | 后果 |
|---|---|---|
| AMPK | 活性↓ | 自噬↓、线粒体更新↓ |
| mTORC1 | 活性↑ | 蛋白合成过剩、自噬↓、SASP↑ |
| SIRT1 | 活性↓（NAD⁺ 下降） | 表观漂移、线粒体功能↓ |
| 胰岛素/IGF-1 | 敏感性↓（抵抗） | 代谢僵化、炎症↑ |
| FGF21 | 升高（代偿） | 代谢应激信号（肌肉萎缩风险） |

**"营养感应再校准"**（nutrient sensing recalibration）因此成为代谢抗衰的核心策略：通过禁食/热量限制/运动压低 mTORC1、激活 AMPK/SIRT1，模拟"饥馑状态"的代谢信号——这是热量限制延寿假说的分子基础，也是"断食-运动"组合优于单一干预的逻辑。

### 6.1 间歇性禁食 / 热量限制

- **机制**：禁食 → AMP/ATP↑ → AMPK 激活 → 抑制 mTORC1、启动自噬、上调 PGC-1α；同时胰岛素下降、胰高血糖素上升，动员脂肪。
- **证据**：热量限制（CR）在酵母、线虫、果蝇、小鼠、猴（部分研究）中延长寿命；人体 RCT（CALERIE 系列）显示 CR 2 年改善代谢指标、降低衰老相关生物标志，但"CR 延长人类寿命"尚无直接证据。
- **间歇性禁食（IF）**：16:8、5:2 等方案在 RCT 中改善体重、胰岛素敏感性、血压与炎症，获益部分独立于热量摄入。

### 6.2 生酮与 β-羟基丁酸

生酮饮食（极低碳水）使肝脏生成酮体：**β-羟基丁酸（BHB）**与乙酰乙酸、丙酮。BHB 的作用远超燃料：

- **能量底物**：大脑在糖缺乏时改用 BHB（经 MCT1 转运、线粒体氧化），改善神经代谢。
- **信号分子**：**抑制组蛋白去乙酰化酶（HDAC1/3）**——BHB 是内源性 HDAC 抑制剂，升高组蛋白乙酰化、激活应激响应基因（如 FoxO3a、MT2）表达，是"生酮抗衰"的分子核心。
- **GPCR 配体**：激活 HCAR2（GPR109A），抑制脂肪分解、抗炎。
- **证据**：动物研究显示生酮/酮酯改善认知、代谢与寿命相关通路；人体 RCT 改善胰岛素敏感性、炎症标志物，但长期安全性（血脂、肾结石）仍需验证。

```
禁食/低碳 ──► 肝糖原↓ → 脂肪动员 → 肝 β-氧化 → 酮体(BHB)
                                                    │
                          ┌─────────────────────────┼──────────────┐
                          ▼                         ▼              ▼
                     HDAC 抑制                HCAR2 激活        能量底物
                  (组蛋白乙酰化↑)             (抗炎/脂解↓)      (脑/肌肉)
                          │
                          ▼
                FoxO3a/MT2 等应激基因↑
```

## 7. 药物干预：二甲双胍与 GLP-1

### 7.1 二甲双胍（Metformin）

- **机制**：抑制线粒体复合物 I（轻度）→ AMP/ATP↑ → **AMPK 激活**；另经 PEN2 靶点抑制溶酶体 v-ATPase 激活 AMPK；改善肝糖输出、肠糖摄取与肠道菌群。
- **抗衰证据**：流行病学（糖尿病患者的死亡/癌症风险低于预期）与动物研究（线虫、小鼠寿命延长，机制依赖 AMPK）支持"二甲双胍可能延缓衰老"；**TAME 试验**（Targeting Aging with Metformin，非糖尿病人群、多中心 RCT）正在进行，是验证人类抗衰疗效的关键研究——结果尚未公布。
- **已知副作用**：胃肠道反应、维生素 B12 缺乏（长期）、乳酸酸中毒（罕见）。

### 7.2 GLP-1 受体激动剂

- **机制**：GLP-1 是肠促胰岛素，促进胰岛素分泌（葡萄糖依赖）、抑制胰高血糖素、延缓胃排空、中枢性抑制食欲——经 GLP-1R 激活 cAMP/PKA。
- **证据**：司美格鲁肽等显著减重（RCT：平均减重 10–15%）、改善心血管结局（SELECT 试验：主要不良心血管事件 ↓20%）与肾脏结局；减重带来的代谢改善间接改善胰岛素抵抗与炎症。
- **抗衰潜力**：通过减重、抗炎、改善 β 细胞功能间接延缓代谢衰老；直接抗衰证据尚不足，长期安全性（肌肉量流失、胃肠道事件）需关注。

## 7.3 代谢衰老的临床评估：从"体检"到"代谢年龄"

代谢衰老没有单一金标准，临床评估依赖组合指标，按证据强度分层：

- **胰岛素敏感性（金标准）**：高胰岛素-正葡萄糖钳夹（M 值）——研究金标准，操作复杂；替代指标：HOMA-IR（空腹血糖×胰岛素/22.5，筛查用）、OGTT 动态曲线（2 小时血糖与胰岛素反应）。
- **体成分与脂肪分布**：DEXA/生物电阻抗测内脏脂肪（VAT）与肌肉量；腰围/腰臀比是廉价替代。**"代谢肥胖但体重正常"（MONW）人群尤其需要体成分评估**——体重正常但内脏脂肪高者，代谢风险与肥胖者相当。
- **血脂全谱**：甘油三酯、HDL-C、非 HDL-C、ApoB——ApoB 是致动脉粥样硬化颗粒数的最直接指标，比 LDL-C 更能反映心血管代谢风险。
- **炎症与器官负荷**：hsCRP（慢性炎症）、ALT/AST（肝脂肪变）、肌酐/eGFR（肾）、尿酸（代谢综合征组分）——多指标异常提示"代谢综合征"聚集。
- **代谢年龄概念**：基于上述指标的"代谢年龄"（代谢灵活性、VO₂max、内脏脂肪综合评分）可作为生物学年龄的代谢维度，与表观时钟（见 [02-aging-clocks](../01-foundations/02-aging-clocks.md)）互补。

**筛查意义**：代谢衰老的早期信号（内脏脂肪增加、HOMA-IR 升高、ApoB 升高）往往在血糖异常前 5–10 年出现——**"代谢年龄"超前于疾病诊断是干预的黄金窗口**。这也是 40 岁后年度体检应包含上述指标组合的原因。

## 8. 代谢时钟：DunedinPACE

**DunedinPACE**（Dunedin Pace of Aging Calculated from the Epigenome，2022，Belsky 团队）是新一代"衰老速率"时钟：

- **构建**：追踪 Dunedin 出生队列 954 人 20 年（26–45 岁）的 19 项器官/代谢功能指标（BMI、血压、HbA1c、肺功能、牙周、肾功能、炎症标志物等），用纵向斜率定义每人"衰老速率"；再用血液 DNA 甲基化拟合，最终用 **173 个 CpG 位点** 输出"每时序年龄年对应的生物衰老年数"（PACE）。
- **与传统时钟的区别**：Horvath/Hannum 输出"年龄"（DNAmAge），DunedinPACE 输出"**速率**"——单位时间生物衰老的倍数，对干预更敏感、与功能衰退的相关性更强。
- **验证**：PACE 高者与更快的功能衰退、慢性病发病、死亡风险相关（每 1 SD → 全因死亡 HR≈1.4–1.5）；可检测生活方式干预（运动、减重）的短期效果，是评估代谢抗衰干预的理想终点之一。
- **局限**：基于单一新西兰出生队列构建，泛化性待验证；CpG 位点功能意义未知（读数而非机制）；对极短时间窗的响应需要验证。

**关键文献**：Belsky DW et al. *eLife* 2022;11:e73420.（DunedinPACE）／ Calorie Restriction 人体 RCT：Ravussin E et al. *Cell Metab* 2015;22(3):427–437.（CALERIE 2）／ 雷帕霉素 ITP：Harrison DE et al. *Nature* 2009;460:392–395.／ Epel ES et al. *PNAS* 2004（端粒与压力）／ Newman JC, Verdin E. *Science* 2017;356:493–494.（BHB 综述）

## 8.1 代谢器官的衰老时钟

除血液表观时钟外，器官级代谢衰老亦可量化：**肝脏**（NAFLD 进展、肝纤维化风险评分）、**胰腺**（β 细胞功能衰退，HOMA-β 随龄下降）、**骨骼肌**（肌少症，握力/步速为临床替代指标）、**脂肪组织**（内脏/皮下比、SASP 标志物）。OrganAge（2023，*Nature*）用器官特异血浆蛋白建立各器官年龄，其中代谢相关器官（胰腺、肌肉、脂肪）加速与 2 型糖尿病、肌少症风险独立相关。代谢时钟的临床意义在于：**在疾病发生前数年识别"代谢衰老加速"个体**，为生活方式/药物干预提供窗口——这也是 DunedinPACE 进入临床试验终点设计的核心理由。

## 8.2 代谢衰老与肌少症、认知衰退的"代谢-器官轴"

代谢衰老的后果不止于血糖与血脂，它通过"代谢-器官轴"放大全身衰老：

- **肌少症（sarcopenia）**：肌肉是最大的代谢器官（占体重 40%，静息耗能占 20%）。代谢衰老与肌少症互为因果——胰岛素抵抗降低肌肉蛋白合成（mTORC1 信号异常）、线粒体功能下降削弱肌肉能量供应、慢性炎症促进肌肉蛋白分解。**"肌肉减少→代谢更差→肌肉更少"的恶性循环**是老年衰弱的核心路径。握力/步速是临床筛查指标（亚洲肌少症工作组 AWGS 标准），DEXA 肌肉量测定确诊；干预核心是**阻力训练+足量蛋白（1.2–1.5 g/kg/天）**，补充亮氨酸/维生素 D 有辅助证据。
- **2 型糖尿病**：随龄发病率上升（65 岁以上约 20–30%），且老年糖尿病与肌少症、认知衰退、心血管病高度共存（"老年糖尿病综合征"）。血糖控制目标需个体化（避免过度降糖导致低血糖与跌倒）。
- **认知衰退**：大脑虽小（占体重 2%）却消耗全身 20% 葡萄糖——**大脑是"代谢依赖"器官**。胰岛素抵抗与阿尔茨海默病风险相关（部分研究称 AD 为"3 型糖尿病"）；代谢紊乱（高血糖、血脂异常、炎症）通过血脑屏障损伤、tau 磷酸化、β-淀粉样蛋白清除障碍参与神经退行。改善代谢（运动、地中海饮食、控制血糖）是认知保护的可执行策略（详见 [07-interventions/03-nutrition.md](../07-interventions/03-nutrition.md)）。
- **NAFLD 与肝衰老**：非酒精性脂肪肝随龄进展（50 岁以上约 30–40%），肝脂肪变→脂肪性肝炎→纤维化→肝硬化是"肝衰老"的连续谱；肝脏又是代谢中枢（糖异生、脂代谢、药物代谢），肝功能下降放大全身代谢紊乱——"保肝=保代谢"。

**临床启示**：代谢衰老的干预应"多器官协同"——单靠降糖药或单靠运动都只能部分覆盖；**"阻力训练+蛋白+有氧运动+地中海饮食+代谢监测"的组合**同时改善肌肉、肝脏、胰腺与大脑代谢，是性价比最高的代谢抗衰处方（详见 [07-interventions/01-daily-checklist.md](../07-interventions/01-daily-checklist.md)）。

## 9.1 代谢抗衰的实践路径：从证据到行动

综合本章机制与证据，代谢抗衰的可执行路径可按"证据强度×可及性"分层：

**第一层（证据最强，立即执行）**
- **运动**：有氧（每周 150 分钟以上）+ 阻力训练（每周 2–3 次）——同时改善胰岛素敏感性、线粒体功能、肌肉量与代谢灵活性，是代谢抗衰的基石（详见 [07-interventions/02-exercise.md](../07-interventions/02-exercise.md)）。
- **饮食模式**：地中海饮食/抗炎饮食 + 控糖（减少精制碳水与游离糖）——改善血脂、血糖、炎症；深色蔬菜提供膳食硝酸盐同步支持 NO 通路。
- **体重管理**：减重 5–10%（若超重）即可显著改善胰岛素敏感性（内脏脂肪减少是关键）。

**第二层（证据中等，可优化）**
- **间歇性禁食**（16:8 或 5:2）：激活 AMPK/自噬，改善代谢标志物——但需保证蛋白质摄入与肌肉量维持，老年人群慎用极端方案。
- **补充剂（谨慎）**：鱼油（甘油三酯）、维生素 D（缺乏者）、镁——证据等级 B/C，勿过度依赖。
- **二甲双胍**（有代谢指征者，处方）：AMPK 激活，TAME 试验结果将提供抗衰证据。

**第三层（前沿监测）**
- **代谢指标年度监测**：HOMA-IR、ApoB、hsCRP、内脏脂肪、VO₂max——用数据指导调整。
- **GLP-1 类药物**（肥胖/心血管高风险者）：显著减重与心血管获益，但需医生评估肌肉流失风险。

**核心原则**：代谢衰老的干预没有"魔法药"，**"运动+饮食+体重+监测"的组合拳**是证据最充分的路径；药物（二甲双胍/GLP-1）是组合的补充而非替代。代谢健康是抗衰的"地基"——没有代谢健康，重编程、Senolytics 等前沿干预的获益也难以落地（呼应 [09-immortality/04-roadmap](../09-immortality/04-roadmap.md) 中"阶段一：已就绪的干预"）。

## 10. 开放问题

1. 代谢紊乱与衰老孰因孰果——代谢失调是衰老驱动还是结果？
2. 最优禁食方案与窗口（CR vs IF vs 生酮，个体化差异）。
3. 二甲双胍能否真正延缓人类生物衰老（等待 TAME 结果）。
4. 恢复 AMPK/mTOR 平衡能否逆转已发生的代谢损伤，还是只能预防？
5. 代谢时钟（DunedinPACE）能否作为临床级抗衰终点。
6. 脂毒性损伤（尤其 β 细胞与肝脏）的可逆性边界。
