# 02 膳食硝酸盐与 NO

> 核心观点：膳食硝酸盐是人体 NO 合成的**非酶促旁路**——不依赖 eNOS、不依赖氧分压，在缺血、缺氧与酸性环境中反而更活跃。一份甜菜根汁即可在 2–3 小时内显著升高血浆亚硝酸盐并降低血压。这使其成为"NO 生物利用度下降"（见 01 篇）最具可操作性的营养干预。

## 0. 历史与概念框架

膳食硝酸盐的生理意义经历了"毒物→药物"的观念反转。20 世纪中叶，硝酸盐/亚硝酸盐仅被视作食品添加剂与潜在致癌物（亚硝胺）；1994 年 Benjamin 等发现胃内可非酶促生成 NO，1990 年代末 Lundberg 团队提出"硝酸盐-亚硝酸盐-NO 通路"假说，2000 年代起大量 RCT 证实其降压与运动增效作用。今天这一通路被视为人体 NO 稳态的第二支柱，与 eNOS 通路互为补充：

```text
                        ┌─ 酶促通路: L-精氨酸 → eNOS → NO (需 O₂, 需 BH4)
人体 NO 生成的两条通路 ─┤
                        └─ 非酶促旁路: NO₃⁻ → NO₂⁻ → NO (缺氧/酸性更活跃)
```

前者由剪切应力、激素、药物（他汀等）驱动，后者由饮食与口腔菌群驱动。二者共享下游的 sGC/cGMP 信号（见 01 篇第 1 节），因此膳食干预的靶点本质是"为共享下游提供更多 NO 前体"。

## 1. 硝酸盐–亚硝酸盐–NO 通路：肠道以外的人体循环

经典的 L-精氨酸/eNOS 通路依赖氧气与辅因子，在缺氧时效率骤降。膳食硝酸盐通路恰好互补：

```text
膳食硝酸盐 NO3⁻ (蔬菜/甜菜根)
   │  肠道吸收 (小肠, 几乎完全吸收, 生物利用度 ~100%)
   ▼
血浆 NO3⁻ → 唾液腺 (腮腺/颌下腺) 主动浓缩
   │  唾液中 NO3⁻ 浓度达血浆的 10-20 倍
   ▼
口腔菌群还原: NO3⁻ → NO2⁻  (硝酸盐还原酶, 关键步骤!)
   │  主要菌种: 罗氏菌属 Rothia (R. mucilaginosa / R. dentocariosa)、
   │            奈瑟菌属 Neisseria、韦荣球菌 Veillonella、放线菌 Actinomyces
   ▼
吞咽 → 胃酸环境: NO2⁻ + H⁺ → HNO2 → NO↑  (非酶促还原, 胃内 NO 浓度可达 ppm 级)
   │
   ▼
进入循环的组织亚硝酸盐还原酶 (缺氧/低 pH 时激活):
   ├─ 脱氧血红蛋白 (deoxyHb)  → NO + 高铁血红蛋白 (亚硝酸盐还原酶活性)
   ├─ 黄嘌呤氧化酶 (XO)       → NO (兼产 O2⁻)
   ├─ 脱氧肌红蛋白 (心肌/骨骼肌)
   ├─ 醛氧化酶 / 细胞色素 P450 / eNOS (缺氧时亦可还原亚硝酸盐)
   └─ 线粒体电子传递链复合体 III
   ▼
NO → sGC → cGMP → 血管舒张 (机制见 01 篇)
```

**关键环节是口腔**：唾液腺将血浆硝酸盐浓缩 10–20 倍进入唾液，口腔共生菌（罗氏菌属、奈瑟菌属为主）将其还原为亚硝酸盐。**用漱口水或抗生素杀灭口腔菌群后，血浆亚硝酸盐升高与降压效应几乎完全消失**——这是该通路最著名的因果证据。胃酸进一步将亚硝酸盐非酶促转化为 NO（胃内高浓度 NO 同时具有杀灭病原菌的防御意义）。

**通路的动力学特征**：①硝酸盐在小肠近端几乎完全吸收（生物利用度接近 100%），未吸收部分进入结肠被肠道菌群利用；②一次摄入后血浆亚硝酸盐约 2–3 小时达峰，亚硝酸盐的循环半衰期仅约 20–30 分钟，因此**剂量依赖的持续性补充（而非单次大剂量）**才能维持稳态；③该通路不受 eNOS 抑制剂（L-NAME）影响，可独立于酶促通路工作——这解释了为何在 eNOS 功能受损的老年与心血管病人群中，膳食硝酸盐仍能有效供 NO（见 01 篇第 6 节）。

## 2. 甜菜根：硝酸盐的天然载体

| 成分 | 含量（每 100 g 生甜菜根） | 说明 |
|---|---|---|
| 硝酸盐 | 约 110–250 mg（典型 150 mg 上下） | 因土壤施肥、品种差异大；有机种植通常更高 |
| 甜菜红素（betalain） | 约 40–100 mg（甜菜苷 betanin 为主） | 水溶性红色色素，具抗氧化、抗炎活性 |
| 膳食纤维 | 约 2–3 g | 果胶为主，有助肠道菌群（部分菌株亦含硝酸盐还原酶） |
| 叶酸/钾/锰 | 叶酸约 80–110 µg | 每 100 g 提供约 20% 日需 |

**实用换算**：250 mL 商业化浓缩甜菜根汁（如 Beet It）含硝酸盐约 400–500 mg；中等大小甜菜根（约 150 g）含约 200–300 mg。摄入后血浆亚硝酸盐在 2–3 小时达峰，血压效应持续 3–6 小时甚至更长。

## 3. 临床证据

### 3.1 血压

- 多项随机对照试验显示，250 mL 甜菜根汁（含约 400–500 mg 硝酸盐）摄入后 2.5–3 小时，收缩压下降 **4–10 mmHg**、舒张压下降 2–5 mmHg，效应在摄入后 3–6 小时持续。
- 荟萃分析（Siervo 等，Hypertension 2013）：纳入 16 项试验，硝酸盐补充使收缩压平均下降 **4.4 mmHg**（95% CI 0.5–8.3）。
- 机制：亚硝酸盐在低氧组织还原为 NO，扩张阻力血管；血压正常者与高血压前期者均有获益，以高血压前期人群效应更明显。

### 3.2 运动表现

- 荟萃分析显示硝酸盐补充可使**耐力运动表现（计时赛/力竭时间）提升 10–15%**（典型效应 2–4% 功率输出增益；部分研究更高）。
- 机制：①降低肌肉氧耗（线粒体呼吸效率↑，P/O 比值优化）；②改善骨骼肌血流与收缩耦联；③提高快肌纤维的钙处理效率。
- 效应存在个体差异：基线 NO 水平低者（老年人、心血管疾病者）获益更大；优秀运动员基线高者效应减弱。

### 3.3 剂量效应：2026 年 RCT 证据

| 剂量 | 主要效应 |
|---|---|
| 200 mg 硝酸盐 | 无明显效应（低于阈值） |
| **400 mg** | **血流介导舒张（FMD）显著改善**（内皮功能） |
| **800 mg** | **血压显著下降**（血管张力效应） |

该剂量-效应研究（2026 年发表的随机对照试验）提示：内皮功能与血压的敏感剂量不同——改善内皮功能所需剂量较低（约 400 mg），降低血压可能需要更高剂量（约 800 mg）。这对补充策略有直接指导意义：**目标是"内皮健康"还是"降压"，剂量策略应不同**。

### 3.4 老年人群

- 老年人 NO 通路下降（见 01 篇第 6 节），是硝酸盐补充获益最大的群体：多项研究显示老年受试者 FMD 改善与血压下降幅度大于年轻受试者。
- 对轻度认知障碍老年人群的小型试验还观察到脑血流（尤其额叶白质）改善。

### 3.5 证据分级

| 证据 | 内容 | 等级 |
|---|---|---|
| 漱口水阻断试验 | 抗菌漱口水使血浆亚硝酸盐与降压效应消失 | A（机制确证） |
| 血压 RCT 荟萃 | SBP 降 4.4 mmHg（16 项试验） | A |
| 运动表现荟萃 | 计时赛提升 10–15% | A |
| 2026 剂量效应 RCT | 400 mg 管 FMD，800 mg 管血压 | B（单一试验，待复制） |
| 老年脑血流研究 | 小型、样本有限 | C |

## 4. 影响效应的因素

| 因素 | 机制 | 对 NO 通路的影响 |
|---|---|---|
| 抗菌漱口水 | 杀灭口腔硝酸盐还原菌（罗氏菌/奈瑟菌） | 血浆亚硝酸盐↓ ~60%，降压效应消失 |
| 抗生素 | 广谱抗生素扰动口腔/肠道菌群 | 同样削弱硝酸盐还原 |
| 质子泵抑制剂/抑酸药 | 胃酸不足 → 非酶促还原减弱（胃内 NO 生成↓） | 削弱胃部还原环节（循环亚硝酸盐影响较小） |
| 吸烟 | 烟草燃烧产生 CO 竞争结合 sGC 血红素；吸烟者口腔菌群构成改变 | NO 敏感性↓，硝酸盐效应减弱 |
| 咀嚼与唾液分泌 | 充分咀嚼促进唾液硝酸盐浓缩 | 分泌不足则还原量↓ |
| 口腔菌群个体差异 | 罗氏菌丰度因人而异（与年龄、饮食相关） | 个体反应差异大的重要来源 |
| 咖啡因/多酚 | 黄嘌呤氧化酶抑制剂（别嘌醇类）或茶多酚可能干扰亚硝酸盐还原 | 证据不一，影响较小 |

## 5. 安全性

### 5.1 亚硝胺风险（理论担忧，实际低危）

- 亚硝酸盐在特定条件下（高温、酸性、与胺类共存）可形成 N-亚硝胺（致癌物）。
- **关键辨析**：膳食硝酸盐的主要来源是蔬菜，蔬菜同时富含维生素 C 与多酚，二者**抑制**亚硝胺生成；肉类加工中亚硝酸盐的亚硝胺风险与硝酸盐蔬菜不可同日而语。流行病学研究未见蔬菜硝酸盐摄入与癌症风险增加相关，部分研究甚至显示消化道癌症风险降低。
- 世界卫生组织对硝酸盐的 ADI（每日允许摄入量）为 3.7 mg/kg 体重（以硝酸根计）；以 70 kg 成人计约 260 mg/日——**单份甜菜根汁（400–500 mg）即超 ADI**，但该 ADI 主要基于亚硝酸盐毒性设定，对蔬菜来源硝酸盐的适用性存争议，多数毒理学与流行病学证据支持蔬菜硝酸盐的获益-风险比为正。

### 5.2 高铁血红蛋白血症（临床罕见）

- 过量亚硝酸盐可将血红蛋白氧化为高铁血红蛋白（MetHb），丧失携氧能力。
- 成人正常饮食摄入几乎不会发生（需急性、大剂量暴露，如污染井水或误服工业亚硝酸盐）；婴幼儿（<6 个月）胃酸低、MetHb 还原酶活性不成熟，为易感人群——**6 月龄以下婴儿应避免硝酸盐含量高的蔬菜汁**。

### 5.3 其他

- 甜菜根汁含草酸，肾结石（草酸钙型）患者需注意。
- 降压药使用者可能出现叠加降压效应，应监测血压。
- **剂量毒理学**：硝酸盐急性毒性极低（大鼠 LD50 约 3–4 g/kg）；临床补充剂量（数百 mg）远低于中毒剂量。真正需要警惕的是亚硝酸盐急性中毒（成人致死量约 2–4 g），但膳食途径亚硝酸盐生成量被口腔菌群还原速率与胃酸消耗所限制，几乎不可能达到中毒水平。欧洲食品安全局（EFSA）2023 年重新评估认为，蔬菜来源硝酸盐摄入对一般人群不构成健康风险。

## 5.4 特殊人群注意事项

| 人群 | 风险 | 建议 |
|---|---|---|
| 6 月龄以下婴儿 | 高铁血红蛋白血症易感（MetHb 还原酶不成熟、胃酸低） | 避免高硝酸盐蔬菜汁/辅食 |
| 孕妇 | 理论上 MetHb 可跨胎盘，但蔬菜硝酸盐未见不良妊娠结局证据 | 维持正常蔬菜摄入 |
| 服用 PDE5 抑制剂者 | 与 NO 供体叠加 → 低血压风险 | 避免同日内大剂量补充 |
| 慢性肾病/高钾血症 | 甜菜根含钾较高（约 300 mg/100 g） | 限量并监测血钾 |
| 草酸钙肾结石 | 甜菜根草酸含量高 | 限制摄入、充分饮水 |

## 6. 与其他硝酸盐食物的对比

| 食物 | 硝酸盐含量（mg/100 g） | 特点 |
|---|---|---|
| 芝麻菜（arugula/rocket） | 250–450（最高档） | 十字花科，兼含硫代葡萄糖苷 |
| 菠菜 | 150–300 | 兼含草酸，焯水可部分去除 |
| 芹菜 | 100–250 | 兼含芹菜素（黄酮） |
| 甜菜根 | 110–250 | 兼含甜菜红素，市面上有标准化浓缩汁产品 |
| 莴苣 | 100–200 | 日常叶菜 |
| 胡萝卜 | 50–100 | 中等 |
| 土豆 | 50–100 | 中等 |

**实用建议**：无需执着于单一"超级食物"——每天 200–400 g 绿叶蔬菜（芝麻菜、菠菜、莴苣等）即可提供 300–1000 mg 硝酸盐，超过多数临床试验剂量。甜菜根的优势在于标准化浓缩产品（剂量可控、研究证据充分）。

## 7. 开放问题

1. **长期补充的安全性终点**：数月至数年的硝酸盐补充尚无大规模硬终点（心血管事件/癌症）试验，长期安全性依赖推断。
2. **口腔菌群的可塑性**：能否通过益生菌/饮食工程定向富集罗氏菌与奈瑟菌，使"硝酸盐还原能力"成为可训练的表型？
3. **剂量-效应精细刻画**：2026 年 RCT 的"400 mg 管内皮 / 800 mg 管血压"分离现象需独立复制，并探明其机制（是否涉及不同血管床的 NO 敏感性差异）。
4. **与药物的相互作用**：硝酸盐补充与他汀、ACEI 联用是否叠加获益？与 PDE5 抑制剂（西地那非）联用是否有低血压风险？
5. **运动表现效应的个体化**：如何通过基线 FMD/亚硝酸盐水平预测"有反应者"？
