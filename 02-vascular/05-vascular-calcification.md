# 05 血管钙化与僵硬：动脉中层钙化与骨-血管轴

> 核心观点：血管钙化（Vascular Calcification）不是钙磷的"被动沉积"，而是血管平滑肌细胞（VSMC）主动转分化为成骨样细胞、在血管壁内异位成骨的"主动调控"过程。动脉中膜钙化使大动脉僵硬、顺应性丧失，是"血管老化"的结构基础。钙化受促钙因子与抑钙因子（MGP、胎球蛋白A、焦磷酸盐、骨桥蛋白、OPG）的精密平衡调控，而这一平衡在衰老、糖尿病、慢性肾病（CKD）中被系统性打破。本章梳理钙化分型、成骨转分化全链条机制、钙磷代谢轴、动脉僵硬测量、与 NO 通路的互作，以及从维生素 K2、镁、磷酸盐结合剂到 SNF472、SGLT2 抑制剂的干预矩阵。本篇为 NO 心血管保护机制（详见 01-no-cardiovascular.md）的姊妹篇，聚焦"内皮功能障碍之后的血管结构衰老"。

## 1. 核心概念

血管钙化是磷酸钙（主要为羟基磷灰石 Ca₁₀(PO₄)₆(OH)₂）结晶在血管壁的异位沉积。过去 30 年最重要的概念转变是：钙化从"被动的矿物沉积"被重新定义为"主动的、受调控的、类骨化过程"——VSMC 在特定刺激下丧失收缩表型标志物（α-SMA、SM22α、myocardin），上调成骨转录因子与骨基质蛋白，如同"成骨细胞"一般分泌矿化基质囊泡。

按解剖位置分为两类：**内膜钙化**（intimal calcification）与动脉粥样硬化斑块相关，出现在内膜层，钙化结节嵌入脂质坏死核心；**中膜钙化**（medial calcification / Mönckeberg 硬化）出现在中膜弹性板层之间，与斑块无必然联系，多见于糖尿病、CKD、高龄。两者分子机制高度重叠但起点不同——前者始于脂质炎症，后者更多由矿物质代谢紊乱驱动。中膜钙化直接使大动脉僵硬、顺应性下降，是"血管老化"（vascular aging）的核心结构表型。

血管僵硬（arterial stiffness）使主动脉缓冲功能丧失：脉搏波反射提前、中心动脉收缩压与脉压增大、左心室后负荷增加、冠状动脉灌注压下降。脉搏波速度（PWV）是无创评估僵硬的金标准，随年龄单调升高。骨-血管轴（bone-vascular axis）揭示骨质疏松与血管钙化的共病耦联：二者共享成骨/破骨转录程序与 OPG/RANKL 系统。血管钙化与僵硬既是衰老结局，又反向加速器官衰老，是理解长寿必须掌握的血管主题。

## 2. 分子机制全链条：从刺激到异位骨化

### 2.1 触发信号：什么"启动"VSMC 成骨转分化

正常 VSMC 处于收缩表型（contractile phenotype），依赖 myocardin/SRF 维持分化。钙化起始的关键是表型转换（phenotypic switch）被促钙刺激打开：

```text
促钙刺激（启动信号）
   ├─ 高磷血症 / 高钙血症（CKD, 衰老）
   ├─ 炎症因子: TNF-α, IL-6, IL-1β（NLRP3→IL-1β 级联）
   ├─ 氧化应激 / AGEs-RAGE 信号（糖尿病）
   ├─ 骨形态发生蛋白 BMP2/BMP4
   ├─ Wnt/β-catenin 异常激活
   ├─ 弹性蛋白降解产物（elastin 肽, 趋化单核细胞）
   └─ 剪切应力丧失 / 血流紊乱（内皮信号缺失）
          │
          ▼
VSMC 表型转换（收缩型 → 成骨样 / 合成型）
   ├─ 下调: α-SMA, SM22α, SM-MHC, myocardin
   └─ 上调: Runx2/Cbfa1, MSX2, SOX9, Osterix(Osx)
          │
          ▼
成骨程序激活 → 分泌骨基质蛋白 (ALP, OPN, OC, Col I)
   ├─ 细胞外基质重塑 → 钙结合蛋白富集
   ├─ 释放矿化基质囊泡 (matrix vesicles)
   └─ 抑制因子的局部耗竭 → 羟基磷灰石结晶成核与生长
```

### 2.2 成骨转录因子核心：Runx2/Cbfa1 与 MSX2

**Runx2（又称 Cbfa1）**是成骨分化的"主开关"转录因子，是 VSMC 钙化的核心驱动。在生理状态下 VSMC 表达极低，但高磷、炎症、氧化应激、BMP2 可显著上调。Runx2 激活下游骨基质基因：碱性磷酸酶（ALP）、I 型胶原（COL1A1）、骨桥蛋白（OPN/Spp1）、骨钙素（OCN）等。Runx2 的磷酸化与核转位受 MAPK/ERK 与 p38 通路调控——高磷通过 PKCα→ERK1/2→Runx2 磷酸化（Ser319/Ser340 位点）实现。

**MSX2** 与 Runx2 协同：MSX2 激活 Wnt 通路相关基因并诱导 Runx2 表达；MSX2/β-catenin 复合物参与成骨程序放大。此外 **Osterix (Sp7)** 是 Runx2 下游的次级转录因子，共同构成"成骨转录级联"。这些因子的激活与 VSMC 收缩表型基因的下调是"一体两面"——myocardin 抑制 Runx2 表达，二者存在拮抗。

### 2.3 信号通路：BMP2、Wnt/β-catenin、以及钙化-炎症放大环

**BMP 通路**：BMP2/4 与 VSMC 表面 BMPR 结合，经 Smad1/5/8 磷酸化转位入核，与 Runx2 协同诱导成骨。衰老与炎症微环境中 BMP2 表达升高。BMP 信号受 Noggin、Gremlin 拮抗（抑钙保护）。

**Wnt/β-catenin 通路**：Wnt 配体激活后抑制 β-catenin 降解复合物（Axin/APC/GSK3β），β-catenin 入核与 TCF/LEF 结合，诱导 Runx2、cyclin D1 等。β-catenin 是"促钙"与"促增殖"的双重节点。

**炎症-钙化放大环**：NLRP3 炎性小体激活→IL-1β 释放→驱动 VSMC 成骨并招募巨噬细胞；巨噬细胞分泌 TNF-α、IL-6 进一步强化 Runx2 信号，形成正反馈。高磷本身也能激活 NLRP3，使矿物质紊乱与炎症相互强化。

```text
高磷 / BMP2 / 炎症 / 衰老
   ▼
PKCα→ERK1/2 → Runx2-P (Ser319/340) ← β-catenin/TCF (Wnt)
   │                                  ↑
   ▼                     BMP2→Smad1/5/8
ALP ↑, OPN ↑, COL1A1 ↑, OCN ↑
   ▼
钙化基质囊泡释放 → 局部 Ca²⁺·PO₄³⁻ 过饱和
   ▼
羟基磷灰石结晶成核 → 结晶生长 → 血管钙化
```

### 2.4 抑制因子系统：谁在"踩刹车"

生理状态钙化被一组内源性抑制因子严格控制，其缺失或失活是钙化的必要条件：

| 抑制因子 | 本质 | 抑制机制 | 失活/缺失后果 |
|---|---|---|---|
| **MGP**（基质 Gla 蛋白） | 维生素 K 依赖性 γ-羧化蛋白 | 需 VKORC1 催化 γ-羧化激活，羧化型 MGP 结合并螯合 BMP2、中和晶体 | MGP 敲除小鼠 8 周内广泛动脉+软骨钙化、早死（Luo 1997 Nature） |
| **胎球蛋白-A**（fetuin-A） | 肝脏分泌的循环糖蛋白 | 结合钙磷胶体形成"钙蛋白颗粒"（calciprotein particles），维持钙磷可溶 | 胎球蛋白-A 敲除小鼠在钙磷负荷下严重钙化 |
| **焦磷酸盐（PPi）** | 小分子代谢物 | 竞争性结合羟基磷灰石生长面，抑制结晶成核与延伸 | ENPP1 或 ANK 缺陷→低 PPi→婴儿期广泛钙化（GACI 综合征） |
| **骨桥蛋白（OPN）** | 磷酸化酸性糖蛋白 | 吸附晶体表面、抑制生长，并调节免疫 | OPN 敲除小鼠钙化加重 |
| **OPG**（骨保护素） | RANKL 诱饵受体 | 中和 RANKL，抑制破骨；OPG-/- 动物动脉钙化 | OPG-/- 小鼠主动脉中膜钙化、骨质疏松 |
| **Klotho** | 跨膜蛋白 | 维持 FGF23 敏感性、抗磷、抗氧化 | Klotho-/- 小鼠加速衰老、血管钙化 |

**关键酶与辅因子**：MGP 的 γ-羧化依赖维生素 K 还原酶 VKORC1（华法林靶点）与 γ-谷氨酰羧化酶（GGCX）。**华法林（维生素 K 拮抗剂）使用者钙化风险显著升高**，即从反面证实该通路的重要性。维生素 K 充足→MGP 羧化型占优→抑制钙化；维生素 K 缺乏/华法林→未羧化 MGP（uc-MGP）失活→钙化去刹车。

### 2.5 钙磷代谢轴：FGF23/Klotho 与高磷血症驱动

矿物质代谢紊乱是 CKD 钙化的核心驱动，也是理解"钙化为何是衰老代谢标志"的枢纽：

```text
肾脏功能↓（CKD / 衰老）
   ▼
磷潴留 → 血磷↑ (高磷血症)
   ▼
成骨细胞/骨细胞 分泌 FGF23 ↑（磷利尿激素）
   ├─ 作用于肾: 抑制 NaPi-IIa 重吸收 → 磷排泄↑
   └─ 作用于甲状旁腺: 抑制 PTH
   │
   ├─ FGF23 信号依赖 Klotho（肾高表达）作为共受体
   ├─ 衰老/Klotho 下调 → FGF23 抵抗 → 磷排不出 → 血磷维持高
   ▼
血磷↑ → 磷与钙离子 乘积(Ca×P)↑ → 过饱和
   ▼
高磷直接驱动 VSMC 成骨转分化（经 PIT-1 磷转运体进入细胞）
   ▼
血管钙化
```

**PIT-1（SLC20A1）**：VSMC 表面的磷转运体，高磷通过 PIT-1 内流激活 ERK1/2→Runx2，是"高磷→钙化"的直接分子桥。FGF23 本身升高是 CKD 早期（GFR 尚未明显下降时）即出现的代偿信号，**血 FGF23 升高独立预测 CKD 患者心血管事件与死亡**。Klotho 随年龄与 CKD 进行性下调，被认为是衰老的关键调节子——Klotho 过表达延长小鼠寿命，Klotho 缺陷则加速血管钙化与衰老（详见 01-foundations 衰老标志篇）。

### 2.6 弹性蛋白降解：僵硬的结构基础

动脉中膜弹性蛋白（elastin）提供被动弹性回缩。衰老与钙化中，弹性蛋白被**基质金属蛋白酶（MMP-2/9）**与弹性蛋白酶（elastase）降解，产生弹性蛋白片段（elastin-derived peptides, EDP）。EDP 具有趋化与促炎活性：招募单核/巨噬细胞、激活 VSMC 迁移与成骨。弹性蛋白降解导致两个后果：①弹性纤维断裂→中膜失去回缩力→顺应性下降→僵硬；②断裂弹性层成为钙化沉积的模板位点（钙化常沿弹性板层分布，中膜钙化正是此特征）。钙化与弹性降解形成恶性循环：钙化增加管壁刚性→局部机械应力改变→进一步降解。

### 2.7 基质囊泡与矿化：结晶的最后一步

成骨样 VSMC 释放 **矿化基质囊泡（matrix vesicles）**——富含膜联蛋白（Annexin A2/A5/A6）、PIT-1、ALP 的细胞外囊泡。ALP 水解焦磷酸盐（PPi）并提高局部磷酸盐浓度，是促矿化的关键酶；而 ANKH/ENPP1 产生的 PPi 则抑制矿化。**ALP/PPi 比值**决定囊泡内结晶趋势——钙化时 ALP 升高、PPi 下降。基质囊泡锚定于弹性板层与胶原上，局部 Ca²⁺/PO₄³⁻ 达到过饱和后羟基磷灰石成核、生长、聚合成宏观钙化灶。镁在此环节通过替代钙离子嵌入晶格、改变晶格结构，抑制结晶成核与生长速率。

## 3. 血管僵硬与测量：PWV 作为血管衰老指标

### 3.1 PWV 原理与标准

脉搏波沿动脉壁传播的速度遵循 Moens-Korteweg 方程：PWV² = E·h / (2ρ·r)，其中 E 为弹性模量、h 为管壁厚度、r 为管腔内径、ρ 为血液密度。**动脉越硬，PWV 越快**。临床金标准为**颈-股动脉脉搏波速度（cfPWV）**——用压平眼压计测量颈动脉与股动脉两点的脉搏传导时间，除以两点距离。

| 指标 | 正常值/阈值 | 意义 |
|---|---|---|
| cfPWV | 健康成人 <10 m/s；≥10 m/s 判为僵硬（ESC/ESH 2018 高血压指南亚临床器官损害标准） | 独立预测心血管事件 |
| 中心动脉压/脉压 | 脉压>60 mmHg 提示僵硬 | 反映主动脉缓冲功能丧失 |
| 增强指数 AIx | 反射波增益 | 反映反射波时机 |
| CAC 积分（Agatston） | 0=无钙化；1-100 轻度；101-300 中度；>300 重度 | 冠脉钙化量化，见 §4 |

cfPWV 随年龄单调升高，30-80 岁健康人群约从 6-7 m/s 升至 11-13 m/s；高血压、糖尿病、CKD 使各年龄段 PWV 显著上移。**cfPWV 每升高 1 m/s，心血管事件风险约增加 14-15%（荟萃分析，log-linear）**，是独立于血压的血管衰老标志物。

### 3.2 CAC 与动脉粥样硬化钙化

**冠状动脉钙化积分（CAC）**由 Agatston 提出，用心脏 CT 量化冠脉钙化。CAC=0 表示近 10 年心血管事件风险极低（MESA 队列约 10 年事件率<1-3%），是"阴性筛查"的有力工具；CAC≥100 提示显著风险，≥300 高危，可重新分层他汀适用人群（2018 AHA/ACC 胆固醇指南推荐 CAC 用于中危人群风险再分类，CAC=0 可考虑暂缓他汀）。CAC 是动脉粥样硬化负荷的直接成像标志——它把"血管钙化"从实验室概念转化为临床风险分层工具，也让"钙化程度"成为抗衰干预的可量化终点。

## 4. 证据分级

| 现象/结论 | 证据等级 | 关键证据 |
|---|---|---|
| cfPWV 是心血管事件的独立预测因子 | A（强，多队列+荟萃） | 颈股 PWV 每 +1 m/s →事件风险↑~15%；ESC/ESH 指南纳入亚临床靶器官损害 |
| CAC=0 预示低风险；CAC 分层预测事件 | A（RCT 再分析+MESA） | 2018 AHA/ACC 指南将 CAC 用于风险再分类 |
| MGP 敲除小鼠广泛动脉钙化、早死 | A（基因模型） | Luo 1997 Nature 386:78-81 |
| 华法林（维生素K拮抗）增加钙化 | B（观察性一致） | 华法林使用者中膜钙化、钙化防御风险↑ |
| MK-7 改善绝经后女性 cfPWV | B（RCT，样本244） | Knapen 2015 Thromb Haemost，180µg/d×3年，cfPWV 改善 P=0.04 |
| MK-7 延缓 CAC 进展 | B（RCT，样本180） | VitaK-CAC 试验（JAMA Cardiol），360µg/d×24月，CAC 进展↓~29% |
| 透析人群 K2 RCT 无一致硬终点获益 | C（结果不一） | 部分透析 K2 试验未显改善；机制受多种混杂限制 |
| 镁延缓 CKD 患者 CAC 进展 | B/C（小样本 RCT） | Sakaguchi 2019 JASN 30:1073；镁氧化物 420mg，predialysis CKD |
| SNF472（羟基磷灰石结晶抑制剂）延缓透析患者钙化 | A（RCT，血液透析） | Raggi 2020 Circulation 141:728（CaLIPSO）；CAC 容积进展显著↓ |
| 高磷/高 FGF23 与 CKD 钙化、死亡相关 | A（前瞻队列） | FGF23 独立预测 CKD 心血管事件与死亡 |
| VSMC 成骨转分化（Runx2 等） | A（机制研究，多重验证） | 细胞/动物模型一致证实 Runx2、MSX2、BMP2 驱动 |
| eNOS 缺陷/NO 缺乏加重钙化 | B（动物模型） | eNOS-/- 或 L-NAME 处理动物钙化加重（见 §6） |

**等级标注**：A=人体 RCT 或多队列荟萃/确证基因模型；B=单一或小样本 RCT/观察性一致；C=机制研究或结果不一。钙化领域多数干预证据停留在 B/C 级——这是"血管钙化能否真正逆转"尚未有定论的原因。

## 5. 临床/实验证据细节

### 5.1 衰老与 CKD 中的钙化加速

透析患者冠状动脉钙化显著加速，中位 CAC 进展率可达每年数十至数百 Agatston 单位。CKD 患者心血管死亡率是同年龄普通人群的 10-20 倍，血管钙化是关键驱动之一。透析人群中约 60-70% 存在显著冠脉钙化。糖尿病与 CKD 叠加时中膜钙化尤为突出——**糖尿病常表现为弥漫性中膜钙化（Mönckeberg 硬化）**，典型影像为下肢动脉的"火车轨道"样钙化线。

### 5.2 维生素 K2（MK-7）干预

- **Knapen 2015（Thromb Haemost 113:1135）**：244 名健康绝经后女性，随机双盲，180µg/d MK-7 或安慰剂 3 年。MK-7 组 cfPWV 显著改善（P=0.04），未羧化 MGP（uc-MGP）下降（提示 MGP 羧化增强）；骨密度骨流失也减缓。这是 K2 改善动脉僵硬最常被引用的 RCT。
- **VitaK-CAC 试验（JAMA Cardiology）**：180 名 CAC 50-400 的冠心病患者，随机 360µg/d MK-7 或安慰剂 24 个月。结果 MK-7 组 CAC 评分进展比安慰剂组慢约 29%，钙质量进展慢约 42%。这是首个"健康相对人群"显示 K2 延缓 CAC 进展的 RCT，机制上以 MGP 羧化增强为合理解释。
- **透析人群 K2 试验**：多项随机试验未显示一致硬终点获益，因透析人群钙化驱动因素复杂（磷潴留、尿毒症毒素、炎症叠加），单一维生素 K 补充难以扭转全局。结论：K2 在"矿物质代谢相对稳定"人群更可能获益；终末期肾病需综合干预。

### 5.3 镁

镁抑制羟基磷灰石成核与生长（替代 Ca²⁺ 嵌入晶格、改变晶格结构）。**Sakaguchi 2019（JASN 30:1073）**：predialysis CKD 患者随机接受镁氧化物（420mg/d）或安慰剂，镁组 CAC 进展显著减缓，且未显著升高血镁风险。镁的作用位点覆盖抑制结晶+抑制成骨转分化（镁还抑制 Runx2/ALP 上调），是 CKD 钙化的可执行干预。

### 5.4 磷酸盐管理与 SNF472

- **磷结合剂**：CKD 中控制血磷（磷结合剂：碳酸钙、司维拉姆、碳酸镧）可减缓钙化进展；严格血磷控制的队列 CAC 变化更低（毛慧娟综述引述）。
- **SNF472（肌醇六磷酸六钠）**：选择性结合羟基磷灰石生长面、阻断结晶延伸。**CaLIPSO 试验（Raggi 2020, Circulation 141:728-739）**：血液透析患者静脉 SNF472（300mg/600mg 每次透析）或安慰剂。SNF472 显著延缓 CAC 容积进展（600mg 组约 -34%），且未影响骨密度/骨代谢指标——这是"直接阻断结晶"策略的临床验证，SNF472 后获 FDA 批准用于钙化防御（calciphylaxis）。它证明：即使无法清除已有钙化，**阻断结晶延伸本身即可延缓钙化进展**。

### 5.5 SGLT2 抑制剂

SGLT2 抑制剂（卡格列净、恩格列净）通过独立于降糖的机制减轻血管钙化：抑制 NLRP3 炎性小体、经 AMPK 激活 Nrf2/HO-1 抗炎通路、改善内皮功能、降低动脉僵硬。DAPA-HF/EMPEROR 等试验显示其心血管硬终点获益部分与血管/内皮改善相关。作为代谢-血管交叉干预，SGLT2 抑制剂是"抗衰代谢药"的重要组成（详见 04-drugs 代谢篇）。

### 5.6 骨-血管轴与 OPG/RANKL

骨质疏松与动脉钙化流行病学共现：低 BMD 人群 CAC 更高。机制上，骨吸收释放的钙磷入血促进血管钙化；血管内成骨样细胞与骨细胞共享 Runx2/OPG-RANKL 程序。**OPG（骨保护素）是 RANKL 的诱饵受体**：OPG-/- 小鼠同时出现骨质疏松与主动脉中膜钙化，提示骨与血管钙化共享调控中枢。双膦酸盐对血管钙化的影响证据不一致（部分观察性显示可能延缓，但因骨代谢广泛作用，作为血管钙化适应症路径较长）。雌激素缺乏（绝经）同时加速骨丢失与血管僵硬——骨-血管轴为"女性绝经后心血管风险升高"提供机制解释。

## 6. 与 NO / NAD+ / 长寿网络联系

### 6.1 NO 抑制成骨转分化

内皮源性 NO 是钙化的内源性抑制信号，机制涵盖多个层面：

```text
eNOS → NO
   │
   ├─→ cGMP/PKG → 抑制 Runx2 表达与活性（维持 VSMC 收缩表型）
   ├─→ 抑制 NF-κB → 下调促炎细胞因子 → 削弱炎症-钙化放大环
   ├─→ 抗氧化（清除 O2⁻）→ 保护 BH4 → 维持 eNOS 偶联（抗解偶联）
   ├─→ 抑制 VSMC 增殖/迁移（PDGF 信号）→ 降低成骨样细胞池
   └─→ 维持内皮完整性/剪切应力信号 → 阻止钙化起始环境
```

**NO 缺乏 → 钙化加重**：eNOS 敲除小鼠或 NOS 抑制剂（L-NAME）处理动物血管钙化加重；eNOS-/- 叠加钙负荷（高磷、维生素D）时中膜钙化显著恶化。反过来，**补充 NO 供体或激活 PKG 可抑制 VSMC 成骨分化、下调 Runx2**——机制研究表明 cGMP/PKG 通路是 NO 抗钙化的主执行者（经抑制 MAPK/ERK→Runx2）。

**内皮功能障碍—钙化恶性循环**：衰老与氧化应激导致 eNOS 解偶联、NO 生物利用度下降（详见 01-no-cardiovascular.md §5），这一方面直接解除 NO 对成骨的抑制，另一方面使血管壁进入慢性低度炎症状态（NF-κB 活化、黏附分子上调），为钙化提供炎症土壤。钙化后的僵硬血管又降低剪切应力敏感区域的 NO 生成，进一步恶化内皮功能——形成"NO 下降→钙化→僵硬→NO 更少"的自强化环路。因此，**恢复 NO 通路（运动、膳食硝酸盐、修复 eNOS 偶联）不仅是抗粥样硬化，也是抗钙化/抗僵硬的策略**。

### 6.2 与 NAD+/SIRT 及衰老标志的联系

- **Klotho 与 NAD+**：Klotho 表达下降伴随 NAD+ 代谢紊乱；SIRT1 激动剂（NAD+ 前体）可部分改善血管衰老。Klotho 同时是 FGF23 共受体与抗衰老蛋白，是"钙磷代谢轴"与"长寿网络"的交汇点（详见 01-foundations）。
- **衰老细胞（senescence）**：血管壁衰老细胞（内皮、VSMC）通过 SASP 分泌促炎因子（IL-6、TNF-α、MCP-1）驱动 VSMC 成骨；清除衰老细胞（senolytics）在动物模型中减轻血管钙化与僵硬（详见 04-drugs/03-senolytics.md）。
- **12 大衰老标志**：血管钙化横跨"细胞衰老"（SASP 驱动成骨）、"细胞外基质改变"（弹性蛋白降解、AGEs 交联）、"线粒体功能障碍"（氧化应激→eNOS 解偶联）、"慢性炎症"（NLRP3）多个衰老标志维度，是衰老标志在器官层面的整合体现。
- **弹性蛋白与 AGEs**：AGEs 交联弹性蛋白/胶原直接增加僵硬，且 AGE-RAGE 信号促进 VSMC 成骨——"糖化→僵硬→钙化"是糖尿病加速血管老化的结构链条。

## 8. 开放问题与争议

1. **血管钙化能否真正逆转？** 现有证据多为"延缓进展"，而非"清除已有钙化"（VitaK-CAC、SNF472 均是减缓进展）。钙化是否本质不可逆（如同骨的矿化），还是可通过抑制骨吸收、降磷、激活特定通路实现脱钙，尚无定论。部分动物模型显示抑制成骨可减少新钙化，但对既有结晶的再吸收缺乏可靠证据。

2. **K2 的最佳剂量与疗程**：从 180µg 到 360µg 甚至更高，尚无比对 RCT 确定最优剂量；与维生素 D、钙、镁的联合最优组合不明。华法林使用者补 K 是否抵消抗凝、在何种平衡下获益，需谨慎。

3. **降低 PWV 是否必然转化为临床获益**：PWV 是独立危险因素，但"改善 PWV 的治疗"尚未在硬终点（心梗/卒中/死亡）试验中系统证实（PWV 多为替代终点）。需警惕"指标改善≠临床获益"的替代终点陷阱。

4. **CAC 的"矛盾"**：钙化既是斑块成熟的标志（斑块从易损转向纤维化钙化有时反而稳定），又是动脉粥样硬化负荷的指标。**高度钙化的斑块可能比微钙化的不稳定斑块"更安全"**——微钙化与斑块破裂相关。因此"消除所有钙化"未必是最优目标，钙化类型（微钙化 vs 大钙化）比总量更关键。

5. **衰老细胞的确切角色**：senolytics 减轻血管钙化主要来自动物模型，人体中血管壁衰老细胞对钙化的贡献程度与清除策略的安全性尚未明确。

6. **糖尿病中膜钙化的驱动特异性**：为何糖尿病钙化偏好中膜、且与"糖尿病足/神经病变"伴行，其独立于高血糖与 AGEs 的驱动（如胰岛素抵抗、脂联素下降）需更多机制研究。
