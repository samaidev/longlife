## 合成路线分析

⚠️ 官方工艺未公开（专利仅公开结构定义与活性数据）。以下为基于药物化学逻辑的逆合成分析。

### 逆合成拆解

```
目标分子
  ├─ 断点1（酰胺键）：咪唑B-羧酸 + 4-(4-甲基哌嗪-1-基)苯胺
  │                  （HATU/EDCI 酰胺偶联）
  └─ 断点2（C-C 键）：咪唑A-硼酸酯 + 溴代咪唑B
                     （Suzuki-Miyaura 偶联）
```

### 合理路线（三步逻辑）

**Step 1：构建咪唑 A（1-异丙基-5-(4-氟苯基)咪唑）**
- 方法 A：Radziszewski 多组分缩合（4-氟苯甲醛 + 异丙胺 + 乙二醛）
- 方法 B（更可控）：4-氟苯乙酮 α-溴代 → 甲酰胺环合 → N-烷基化（2-碘丙烷/K₂CO₃）

**Step 2：构建咪唑 B（5-溴-1H-咪唑-4-羧酸乙酯）**
- 咪唑-4-羧酸乙酯（商业可得）+ NBS 溴代（C5 位优先）

**Step 3：Suzuki 偶联（A C2 × B C5）**
- 咪唑 A：n-BuLi（-78°C，THF）C2 锂化 → iPrO-Bpin 捕获 → 硼酸酯
- 偶联：Pd(dppf)Cl₂ + K₂CO₃ + DMF/H₂O，80-100°C

**Step 4：酯水解（LiOH/THF/H₂O）**

**Step 5：酰胺化（HATU/DIPEA，接 4-(4-甲基哌嗪-1-基)苯胺）**

**Step 6：纯化确证**
- 硅胶柱层析（DCM/MeOH 梯度）或反相 HPLC
- ¹H NMR / ¹³C NMR / HRMS（[M+H]⁺ = 488.2453）

### 合成难点

1. 双咪唑 C-C 偶联区域选择性（咪唑 2/4/5 位反应活性差异）
2. 咪唑 B 的 1H 干扰偶联（需 SEM/Ts 保护基）
3. 咪唑 C2 锂化选择性（vs C4/C5）
4. 临床级纯度（99.9%+）的结晶工艺

### 现实建议

- 科研用直接购买（MCE HY-160623 / Selleck E1944，99%+ 纯度，千元级）
- 自制成本（试剂+时间+设备）远超购买
- 有价值的方向是**骨架跃迁**（换取代基/杂环做新分子库筛选）
