# Senolytic 药物：选择性清除衰老细胞

## 一、核心概念：细胞衰老与"僵尸细胞"

细胞衰老（cellular senescence）是细胞在应激——DNA 损伤、端粒缩短、癌基因激活、氧化应激、表观遗传紊乱——下进入的**不可逆增殖停滞**状态。衰老细胞不再分裂，却依然保持代谢活性，并大量分泌以炎性细胞因子、趋化因子、生长因子和基质金属蛋白酶为核心的分泌组，即**衰老相关分泌表型（SASP）**。这些"僵尸细胞"通过 SASP 毒化局部微环境，招募免疫细胞、破坏组织稳态、促进纤维化与肿瘤微环境形成，是"炎性衰老（inflammaging）"与多器官功能衰退的重要来源。

衰老的触发路径主要有三条：**复制性衰老**（端粒缩短触发 DNA 损伤应答 DDR）、**应激诱导早衰**（电离辐射、活性氧、化学损伤）与**癌基因诱导衰老 OIS**（RAS 等癌基因过度激活）。三条路径汇聚于共同的效应器：p53/p21 与 p16^INK4a/RB 两条肿瘤抑制轴。

衰老细胞的分子身份通常由以下标志物界定：

| 标志物 | 类型 | 作用 |
|---|---|---|
| **p16^INK4a** | CDK 抑制剂（CDKN2A 编码） | 抑制 CDK4/6，维持 RB 磷酸化抑制态，锁定 G1 停滞；随年龄在多种组织指数性积累，是最可靠的衰老生物标志物 |
| **p21^CIP1/WAF1** | CDK 抑制剂（CDKN1A 编码） | p53 下游效应分子，介导 DNA 损伤诱导的衰老；在衰老早期短暂升高，维持衰老表型 |
| **p53** | 转录因子 | 感应 DNA 损伤（ATM/ATR → Chk1/2 级联），上调 p21 与促凋亡因子；p53 失活可绕过衰老屏障 |
| **SASP 因子** | 分泌组 | IL-6、IL-1α/β、TNF-α、CXCL8(IL-8)、MCP-1、MMP-3/9、PAI-1、IGFBP、VEGF、GROα 等 |

SASP 的核心调控是 **NF-κB 与 C/EBPβ** 转录复合物，其上游由 DNA 损伤应答（ATM/ATR）与 p38MAPK 许可；IL-1α 通过自分泌环路放大 NF-κB 激活。SASP 的效应是**细胞非自主的**——即衰老细胞对周围组织的损伤不依赖其自身增殖，而是通过分泌组"传染"衰老（旁分泌衰老）、募集炎症细胞、破坏干细胞龛与细胞外基质。

衰老细胞能在组织中长期存活，依赖一组**衰老细胞抗凋亡通路（SCAPs）**——包括 BCL-2 家族抗凋亡蛋白（BCL-2、BCL-xL、BCL-w）、PI3K/Akt 轴、p53/p21/丝氨酸蛋白酶抑制物网络、HIF-1α、HSP90 与 EphB/酪氨酸激酶信号。正常增殖细胞不依赖这些通路生存，这构成了 Senolytics"选择性杀伤"的药理学基础。

## 二、Senolytic 概念与设计逻辑

**Senolytic（衰老细胞清除剂）**指能**选择性诱导衰老细胞凋亡**、而对正常增殖细胞低毒的化合物。其逻辑链条为：

```
衰老细胞依赖 SCAPs 存活（BCL-xL↑/Akt↑/Src↑）
        │
        ▼
Senolytic 抑制 SCAPs ──► 衰老细胞失去存活优势 ──► 凋亡/免疫清除
        │
        ▼
SASP 源头被移除 ──► 慢性炎症↓、组织再生↑、纤维化↓
```

与"抑制 SASP 但保留细胞"的 senomorphic 策略不同，senolytic 是**脉冲式短程给药**——因为正常细胞也会因短暂药物暴露受损，疗程设计为"打几枪就跑"（如 D+Q 每月 3 天），靠机体随后自然再积累、再清除。这一"间歇轰炸"策略在动物实验中已被证明足以维持长期获益。

**发现历史**：senolytic 概念由 Mayo Clinic 的 James Kirkland 与 Tamara Tchkonia 团队在 2015 年前后系统提出。他们采用"假设驱动的表型筛选"：先鉴定衰老细胞的 SCAPs，再逐一用现有药物库打击这些通路，先后筛出达沙替尼+槲皮素组合（Zhu 2015, *Aging Cell*）与 navitoclax（Zhu 2015；Chang 2016）。这一"老药新用"路线大大加速了临床转化——所有进入人体试验的 senolytic 均已是上市或深度开发过的分子，安全性档案相对完整。2020 年代出现第二代方向：**PROTAC 介导的 BCL-xL 降解**（如 DT2216，选择性降解 BCL-xL 蛋白而保留 BCL-2，减轻血小板毒性）、**FOXO4-p53 干扰肽**（阻断 FOXO4 对 p53 的隔离，选择性触发衰老细胞凋亡）与**GalNAc 偶联递送**（靶向肝/肾实质细胞）等，均处于临床前或早期临床阶段。

## 三、主要药物分子与机制

### 3.1 达沙替尼 + 槲皮素（D+Q）——黄金组合

- **达沙替尼（Dasatinib）**：C22H26ClN7O2S，分子量 488.0，氨基噻唑类多靶点酪氨酸激酶抑制剂，FDA 批准用于慢性髓系白血病。其 senolytic 活性来自对 **Src 家族激酶（SRC/YES/FYN/LCK）与 EphB 受体**的抑制——衰老脂肪祖细胞、内皮细胞依赖 Src 通路存活。值得注意的是，达沙替尼对衰老成纤维细胞（IMR90）无明显毒性，却能高效清除衰老脂肪祖细胞，体现其细胞类型选择性。
- **槲皮素（Quercetin）**：C15H10O7，分子量 302.2，3,3',4',5,7-五羟基黄酮（黄酮醇类），天然存在于洋葱、苹果皮、茶、荞麦中。抑制 **PI3K/Akt、BCL-2 家族抗凋亡蛋白与 p53 下游通路**，靶向衰老内皮细胞与上皮细胞；同时具有抗氧化与抗炎活性，生物利用度低（约 1%）是其天然局限，但肠道蓄积可能贡献部分效应。

两者**协同**：D+Q 联用可同时阻断多条 SCAPs（BCL-xL/BCL-2 家族 + PI3K/Akt + Src/EphB），在多种衰老细胞类型中产生比单药更强的杀伤。D+Q 诱导的凋亡依赖衰老细胞线粒体外膜通透化（MOMP）与促凋亡蛋白（BAX/BAK）的释放；正常细胞因抗凋亡储备充足而存活。

### 3.2 Fisetin（漆黄素）

C15H10O6，分子量 286.2，3,3',4',7-四羟基黄酮，草莓、苹果、柿、黄瓜中含量高。通过抑制 **PI3K/Akt、mTOR 及多种激酶**发挥 senolytic 作用，对衰老成纤维细胞、人脂肪组织外植体的杀伤效率常优于 D+Q。与 D+Q 相比其药代性质更优、可口服、毒性更低，是少数进入人体试验的天然 senolytic。

### 3.3 Navitoclax（ABT-263）

C47H55ClF3N5O6S3，分子量 974.6，**BCL-2/BCL-xL/BCL-w 三重 BH3 模拟物**。衰老细胞（尤其内皮细胞、成纤维细胞）高度依赖 BCL-xL 维持线粒体完整性；Navitoclax 竞争性占据 BH3 结合口袋，释放促凋亡蛋白 BIM/BAX，引发线粒体外膜通透化与 caspase 激活。动物研究显示其可清除辐射诱导的衰老细胞、恢复造血干细胞功能、缓解动脉粥样硬化与骨关节炎。但**血小板与中性粒细胞前体同样依赖 BCL-xL**，导致剂量限制性的血小板减少与中性粒细胞减少，严重限制了其抗衰开发（作为抗癌药仍在推进）。

### 3.4 UBX0101 与 Unity 管线

Unity Biotechnology 开发的 **MDM2/p53 抑制剂**（nutlin 类似物）。逻辑：衰老细胞中 p53 活性被 MDM2 过度抑制而不足以触发凋亡；解除 MDM2 对 p53 的抑制 → p53 稳定 → 衰老细胞凋亡。UBX0101 曾以**关节腔单次注射**（0.5/2 mg）治疗膝骨关节炎进入 II 期临床，但**主要终点（第 12 周 WOMAC 疼痛评分）未达标**，公司中止该管线。这一失败凸显"senolytic 减少衰老细胞"与"临床症状改善"之间的转化鸿沟：软骨中衰老细胞比例低、给药窗口短、疼痛评估对结构获益不敏感，均可能是原因。Unity 后续转向 **UBX1325（BCL-xL 抑制剂）** 治疗糖尿病黄斑水肿/湿性 AMD，进入 II 期。

### 3.5 其他在研 senolytic

- **17-DMAG 与格尔德霉素类**：HSP90 抑制剂，破坏衰老细胞对 HSP90 的存活依赖；
- **强心苷类（地高辛、哇巴因）**：抑制 Na⁺/K⁺-ATPase，干扰衰老细胞酸性微环境稳态；
- **姜黄素类似物、ABT-737、Bcl-xL 降解剂（PROTAC）** 等均在临床前阶段。

## 四、动物证据（关键数据）

| 研究 | 干预 | 主要结果 |
|---|---|---|
| Baker 2011, *Nature* 479:232 | INK-ATTAC 转基因小鼠（AP20187 诱导清除 p16^+ 细胞） | 延迟白内障、肌肉萎缩、脂肪组织退化等衰老相关表型 |
| Baker 2016, *Nature* 530:184 | INK-ATTAC 终生清除 | **雄性中位寿命延长约 25%**，健康期延长；12 月龄（相当于人约 60 岁）起干预仍显著改善健康期 |
| Xu 2018, *Nat Med* 24:1246 | 老年鼠 D+Q 间歇给药（20 月龄起，每月 3 天） | 改善握力、跑步耐力；**治疗后生存率提高 36%，死亡风险降至对照的 65%** |
| Yousefzadeh 2018, *EBioMedicine* 36:18 | Fisetin 晚年给药 | 减少衰老细胞负荷与年龄相关病理，**延长中位与最大寿命** |
| Farr 2017, *Nat Med* 23:1072 | 老年鼠 D+Q 治疗骨关节炎模型 | 减少软骨衰老细胞、减轻 OA 疼痛与软骨破坏 |

Baker 2016 的意义在于证明"自然积累的衰老细胞本身是寿命的缩短因素"：清除它们不仅能推迟疾病，还能直接延长寿命。Xu 2018 则证明**晚年（已衰老）干预依然有效**，且间歇给药足以起效——这为人体脉冲式方案提供了直接依据。此外，衰老细胞移植实验（Xu 2018）显示：把少量衰老细胞移植入年轻小鼠膝关节即可导致全身功能下降，而 D+Q 清除后功能恢复——确立了衰老细胞与功能障碍的因果链。

## 五、人体证据（初步但振奋）

- **Hickson 2019, *EBioMedicine* 47:446（糖尿病肾病 DKD）**：14 例患者口服 D（100 mg）+ Q（1000 mg）连续 3 天。治疗后脂肪组织活检中 **p16^INK4a/p21 阳性细胞显著减少**，循环 SASP 因子（IL-1α、IL-6、MMP-9）下降，单次疗程耐受良好。
- **Justice 2019, *EBioMedicine* 47:482（特发性肺纤维化 IPF）**：D+Q 治疗改善患者**身体功能**（6 分钟步行距离、坐站测试、4 米步速），为"清除衰老细胞→临床功能获益"提供了首个前瞻性人体证据。
- **轻度阿尔茨海默病 I 期（2023, *Nat Med* 系列）**：开放标签 D+Q 探索性试验显示可行性与初步安全性信号，脑脊液/血浆衰老与炎症标志物变化待更大样本确认。
- **Fisetin 试点（Mayo Clinic，NCT03675724 系列，AFAR 资助）**：老年受试者口服 Fisetin（20 mg/kg/日，每月连续数日），初步报告脂肪组织衰老标志物（p16、p21、IL-6）下降、耐受性良好。
- **COVID-19 探索（2020–2021）**：重症 COVID 患者使用 D+Q 的小型试验提示炎症标志物下降，但样本量小、结论受限。

所有人体数据目前均为小样本、短期、以生物标志物或功能替代终点为主，**尚无确证临床终点的大型 RCT**。解读时需注意：脂肪组织活检的 p16^INK4a 阳性细胞计数存在取样误差与异质性，循环 SASP 因子受急性炎症干扰，功能终点（步速、握力）有练习效应——生物标志物到临床获益的外推仍需谨慎。

## 六、副作用与安全性

| 药物 | 主要不良反应 | 机制 |
|---|---|---|
| Navitoclax | **血小板减少、中性粒细胞减少**（剂量限制性） | 血小板/粒系前体依赖 BCL-xL 生存（on-target 毒性；血小板半衰期短、无核，无法代偿） |
| D+Q | 短暂胃肠道不适、轻度转氨酶升高、一过性挫伤倾向、眶周水肿 | Src 抑制影响血小板功能；槲皮素高剂量潜在肝毒性 |
| Fisetin | 目前人体数据耐受良好；高剂量黄酮类有潜在肾/肝毒性担忧 | 剂量依赖 |

此外存在**理论风险**：① 清除衰老细胞可能削弱其生理功能——伤口愈合中衰老细胞限制过度纤维化、肿瘤抑制屏障（p16/p53 刹车）、胚胎发育重塑、组织修复；② 反复清除对免疫监视系统的长期扰动；③ 衰老细胞在肿瘤微环境中的双刃剑角色（既有促肿瘤 SASP，也有被免疫系统清除后的抗肿瘤效应）。

## 七、与 Senomorphic 对比

| 维度 | Senolytic | Senomorphic |
|---|---|---|
| 目标 | 清除衰老细胞（诱导凋亡） | 保留细胞、抑制 SASP |
| 靶点 | SCAPs（BCL-2 家族、PI3K/Akt、Src、MDM2、HSP90） | SASP 信号节点（TNIK、mTOR、NF-κB、JAK-STAT、p38） |
| 给药模式 | 脉冲式短程（如每月 3 天） | 长期持续给药 |
| 起效速度 | 快（细胞直接死亡） | 慢（分泌表型逐步抑制） |
| 安全性窗口 | 较窄（需精确靶向衰老细胞） | 较宽 |
| 生理功能保留 | 可能损失衰老细胞的有益功能 | 保留 |
| 代表药物 | D+Q、Fisetin、Navitoclax、UBX0101 | Rentosertib、雷帕霉素、二甲双胍、鲁索替尼 |

两者互补：**先 senolytic 脉冲清负荷，再 senomorphic 长期压制残余 SASP**，是当前最有前景的联合策略。动物实验（如 D+Q 与雷帕霉素联用）已初步支持协同获益。

## 八、证据分级表

| 级别 | 证据 | 结论强度 |
|---|---|---|
| I（机制） | SCAPs 依赖性与选择性凋亡（细胞实验，多种 senolytic 独立验证） | 强 |
| II（动物） | Baker/Xu/Yousefzadeh/Farr 等多项独立队列 | 强（延寿效应可重复） |
| III（人体早研） | D+Q IPF/DKD、Fisetin 衰弱、AD 可行性试验 | 中等（小样本、替代终点） |
| IV（人体 RCT） | 大型终点试验 | 尚无 |

## 九、开放问题

1. **长期安全性**：反复脉冲清除对免疫系统、造血、伤口愈合的长期影响未知；
2. **再积累动力学**：衰老细胞清除后以多快速度再积累？理想给药频率（每月？每季？）未定；
3. **靶点广度**：现有 senolytic 主要覆盖内皮/脂肪/成纤维细胞，神经、心肌、肝细胞中衰老细胞清除不足；
4. **临床终点缺口**：缺乏以疾病发生/死亡为终点的大型 RCT；
5. **生物标志物**：循环 SASP 组学、外周血 p16^INK4a 阳性 T 细胞比例、p16 甲基化等用于疗效监测与剂量指导的标准化；
6. **免疫清除环节**：衰老细胞通过上调 HLA-E/PD-L1 逃避免疫监视，senolytic 与免疫检查点调节的组合值得探索；
7. **与 senomorphic/其他抗衰干预（NAD⁺、雷帕霉素）的组合次序与协同剂量**。
