> **专题定位**：10-structures（分子结构深潜）第 15 篇——解剖 Nrf2（NF-E2 相关因子 2）与其负调控蛋白 KEAP1 的三维结构，理解"氧化应激如何打开抗氧化程序"、KEAP1 的"铰链-门闩"双重扣留机制、以及它在抗衰中的"抗氧化主开关"角色。这是知识库抗氧化主线（[02-vascular/04-mitochondria.md](../02-vascular/04-mitochondria.md)）与炎症衰老（[03-immunity/02-inflammaging.md](../03-immunity/02-inflammaging.md)）的结构底座,与 NF-κB(炎症开关)构成"氧化-炎症"对照。

## 0. 结构速览

**一句话**：Nrf2 是细胞抗氧化/解毒反应的"主开关"转录因子——激活时上调 200+ 保护基因（抗氧化酶、解毒酶、修复蛋白）。静息时被 KEAP1"扣留"在胞质并持续泛素化降解（半衰期 ~20 分钟）;氧化应激时 KEAP1 的半胱氨酸被修饰 → Nrf2 释放入核 → 开启保护程序——"氧化应激是警报,拉响警报的是 KEAP1 上的硫醇开关"。

```text
Nrf2 结构:  N端 Neh2(含DLG/ETGE基序) — Neh4/5(转录激活) — Neh1(bZIP/DNA结合) — Neh3 — C端
                    │
   KEAP1 结构:  N端 BTB(二聚化) — IVR(含反应性Cys) — DGR/Kelch(6叶β螺旋桨, 结合Nrf2)
                    │
   扣留机制: KEAP1二聚体 用两个Kelch域 分别抓住 Nrf2的 ETGE(铰链,高亲和) + DLG(门闩,低亲和)
```

**三大结构特征**（决定其功能的原子基础）：
1. **KEAP1 的 Kelch 域**：6 叶 β 螺旋桨结构,顶部有一个结合口袋——"6 片扇叶的抓取器";
2. **Nrf2 的 ETGE/DLG 双基序**：两个 Keap1 结合位点（高亲和 ETGE + 低亲和 DLG）——"双锚点";
3. **IVR 域的反应性半胱氨酸**：KEAP1 的多个反应性 Cys（C151/C273/C288 等）是"氧化传感器"——"硫醇开关"。

**核心调控机制**：

```text
静息: Nrf2(ETGE+DLG 双锚) ──KEAP1──► 泛素化 → 蛋白酶体降解(半衰期~20min)
        │
氧化应激: KEAP1 Cys 被修饰 → 构象变化 → DLG"门闩"松开
        │
   Nrf2 释放(ETGE 仍挂着=铰链) → 新合成 Nrf2 逃逸 → 入核 → 开启 200+ 保护基因
```

## 1. 为什么 Nrf2/KEAP1 结构重要

Nrf2 是细胞抗氧化防御的"总指挥",也是抗衰研究的热门靶点:

- **"抗氧化主开关"**：Nrf2 激活 → 上调 SOD、过氧化氢酶、谷胱甘肽合成酶（GCL）、HO-1、NQO1 等 200+ 保护基因——"一个开关,开启整个抗氧化生产线";
- **抗衰证据**：Nrf2 活性随龄下降 → 抗氧化能力减弱 → 氧化损伤累积;Nrf2 激活剂（萝卜硫素等）在动物中改善衰老表型——"修好抗氧化主开关,氧化损伤就少";
- **与炎症的对话**：Nrf2 抑制 NF-κB（炎症开关）——"抗氧化与抗炎是同一个硬币的两面";
- **与线粒体**：Nrf2 调控线粒体 ROS 清除（SOD2 等）——"发电厂的消防队";
- **中药联系**：很多中药抗氧化成分（黄芪、姜黄素、白藜芦醇）经 Nrf2 通路——"中医'益气活血'的分子机制之一"（呼应 [06-tcm/01-yiqi-huoxue.md](../06-tcm/01-yiqi-huoxue.md)）;
- **药理学价值**：萝卜硫素（西兰花）、富马酸二甲酯（DMF, 已批准治多发性硬化）、CDDO 类都是 Nrf2 激活剂——"激活主开关的药物已在临床"。

**结构研究的三个关键问题**：
1. KEAP1 如何"抓住"Nrf2 并扣在胞质？（双锚扣留）
2. 氧化应激如何"松开"扣留？（Cys 开关）
3. 为什么需要"双基序"（ETGE+DLG）设计？（铰链-门闩机制）

这些问题在 2FLU（Kelch+ETGE, 2006）、3WN7（Kelch+DLGex, 2014）等结构中得到回答。

## 2. Nrf2/KEAP1 的结构解剖

### 2.1 Nrf2 的 Neh2 域（被扣留的"把手"）

- 位置：Nrf2 N 端（~1-100 残基）;
- 组成：含两个 KEAP1 结合基序——**ETGE**（高亲和, ~10 nM）与 **DLG**（低亲和, ~100-1000 nM）——"两个把手,一个紧一个松";
- 结构：ETGE 基序形成两个反平行 β 链 + 两个 β 转角（2FLU 揭示）——"把手是 β 发夹结构";
- 关键残基：ETGE 的谷氨酸（E）与 KEAP1 的保守残基形成多个氢键——"谷氨酸是锚点的手指";
- DLGex（3WN7 扩展定义）：DLG 基序实际比经典定义更长,含螺旋结构——"门闩比想象的长"。

### 2.2 KEAP1 的 Kelch 域（抓取器）

- 位置：KEAP1 C 端（~330-624）;
- 结构：**6 叶 β 螺旋桨**（six-bladed β-propeller）——"6 片扇叶组成一个圆盘";
- 顶部口袋：螺旋桨的顶面有一个结合口袋（含保守残基）——"扇叶中央的抓手";
- 结合：ETGE 的 β 发夹插入口袋,谷氨酸与口袋内保守残基（Ser/Arg/Tyr 等）形成氢键网络——"谷氨酸的手指,抓住口袋的壁";
- 高分辨率（2FLU, 1.5 Å）：口袋的原子细节清晰——"看见抓手的每个指节"。

### 2.3 KEAP1 的 BTB 域与 IVR 域

- **BTB 域**（N 端, ~60-180）：介导 KEAP1 二聚化（两个 KEAP1 形成二聚体）——"两个抓取器背靠背";
- **IVR 域**（中间, ~180-330）：含**反应性半胱氨酸**（C151/C273/C288 等）——"氧化传感器";
- 二聚体结构：两个 KEAP1 的 BTB 域二聚化 → 两个 Kelch 域并排 → 同时抓住一个 Nrf2 的两个基序（ETGE+DLG）——"两只手抓住一个 Nrf2 的两个把手";
- Cys 的分布：C151 在 BTB/IVR 交界,C273/C288 在 IVR 内部——"传感器分散安装"。

## 3. 铰链-门闩机制：从结构到化学

### 3.00 "双把手"的工程智慧：为什么 ETGE+DLG 是最优设计

上一节讲了双基序,这一节深入理解**为什么进化选择了"两个把手"而不是"一个紧把手"**。这是一个精妙的"工程"问题:

**方案一:一个高亲和把手（只有 ETGE）。** 氧化应激时,要让 Nrf2 从 KEAP1 上释放,必须打破 ETGE-Kelch 的结合——但 ETGE 亲和力高达 ~10 nM,打破它需要极强的应激。而且"一旦打破就全释放"——大量 Nrf2 涌入细胞核,抗氧化基因全量启动——"要么全开,要么全关,不可控"。更糟的是:打破 ETGE 结合需要 KEAP1 构象大幅变化,而 Cys 修饰可能不足以做到——"高亲和把手太牢,开关转不动"。

**方案二:两个把手（ETGE 铰链 + DLG 门闩）。** 氧化应激只需要打破**低亲和**的 DLG（~100-1000 nM）——"松开的成本低"——而 ETGE 保留——"人还挂在门上"。后果:**泛素化效率大降**（需要两个锚点都结合才能高效泛素化）,但旧 Nrf2 还没完全逃脱——**新合成的 Nrf2 抓住"门半开"的窗口逃逸入核**——"增量放行,不是倾泻"。

**"增量放行"为什么好?** ①快速（门闩松开即开始放行）;②可控（放行速度 = 新合成速度,不是存量倾泻）;③可逆（应激消除,新 KEAP1 合成,门闩复位）——**"细胞要的不是'全开',而是'可调的开'""**。

**结构细节（2FLU + 3WN7 合读）**：ETGE 的 β 发夹深插 Kelch 口袋（谷氨酸氢键网络锚定）;DLGex 的螺旋结构浅贴口袋（结合弱、易脱离）——**"铰链深插、门闩浅贴,一深一浅,开关可调"**。

### 3.0 一个原子一个原子地看：为什么需要"双把手"

很多人会问:KEAP1 扣 Nrf2,一个结合位点不够吗?为什么要有 ETGE（高亲和）和 DLG（低亲和）两个?答案在"开关的速度与可逆性":

**如果只有一个高亲和锚点（ETGE）**：Nrf2 被扣得死死的,氧化应激时"松开"需要完全破坏 ETGE 结合——太慢、太彻底（一旦松开,大量 Nrf2 涌出,反应过度）。**"一锤子买卖,不好控制"**。

**两个锚点的"铰链-门闩"设计**：
- **ETGE = 铰链（hinge）**：高亲和（~10 nM）,氧化应激时**不松开**——Nrf2 始终"挂在"KEAP1 上（保持空间位置）——"门还挂在门框上";
- **DLG = 门闩（latch）**：低亲和（~100-1000 nM）,氧化应激时**先松开**——DLG 脱离 KEAP1 后,Nrf2 的 Neh2 域"只挂一个点"→ 泛素化效率大降 → 新合成 Nrf2 逃逸入核——"门闩开了,门半开,新的人能溜进去"。

**为什么"半开"是最优解?** 因为细胞需要**快速但可控**的响应:门闩松开 → Nrf2 逃逸 → 抗氧化程序开启;但 ETGE 还挂着 → 旧 Nrf2 仍在降解中 → 响应是"增量式"的（新合成的才逃逸）——**"不是全开,而是'开闸放水'（增量放行）"**。这比"全开"更可控,避免抗氧化过度。

### 3.1 氧化应激如何"松开"门闩（Cys 开关）

氧化应激 → KEAP1 的 IVR 域半胱氨酸被修饰（氧化/烷化）→ 构象变化 → DLG 结合被破坏（但 ETGE 保留）→ 门闩松开:

```text
氧化应激(ROS/亲电物) → KEAP1 Cys151/273/288 被修饰
    → IVR/BTB 构象变化 → Kelch 域相对位移
    → DLG(门闩) 脱离, ETGE(铰链) 保留
    → 新合成 Nrf2 逃逸 → 入核 → 200+ 保护基因
```

- **Cys 修饰类型**：氧化（-SOH/-SO₂H）、烷化（亲电物如萝卜硫素）、亚硝基化——"传感器能感知多种应激";
- **构象变化的结构证据**：Cys 修饰 → IVR 的螺旋/环重排 → 影响 BTB-Kelch 的相对位置——"传感器触发的机械运动";
- **C151 的特殊地位**：C151 是多种亲电激活剂（SFN、CDDO）的靶点——"主传感器";
- **"硫醇开关"的化学**：Cys 的硫醇（-SH）在氧化环境被修饰 → 改变蛋白构象——"一根硫醇键,决定一个开关"。

### 3.2 "感知-响应"的结构逻辑

- **感知端**（KEAP1 Cys）：直接接触氧化应激——"传感器装在最前线";
- **执行端**（Nrf2 转录）：间接响应（需 KEAP1 释放 + 入核 + 转录）——"执行在后方";
- **中间放大**：1 个 KEAP1 修饰 → 释放多个 Nrf2 → 开启 200+ 基因——"信号放大 200 倍";
- **可逆性**：应激消除后,新 KEAP1 合成 → 重新扣住 Nrf2 → 回到静息——"开关自动回位"（与 NF-κB 的 IκB 负反馈类似）。

## 4. Nrf2 激活剂：从结构到药物

### 4.1 已知激活剂的靶点

- **亲电激活剂**（萝卜硫素 SFN、姜黄素、CDDO 类）：直接修饰 KEAP1 的 Cys151/273/288——"用化学钥匙拧开 Cys 开关";
- **竞争性抑制剂**（研究中的肽/小分子）：占据 Kelch 口袋,阻断 Nrf2 结合——"用假把手占住抓取器";
- **KEAP1-Nrf2 蛋白-蛋白互作抑制剂**（PPI 抑制剂）：靶向 ETGE/DLG 结合口袋——"堵住锚点"（新一代药物方向）;
- **临床实例**：富马酸二甲酯（DMF, Tecfidera）——已批准治疗多发性硬化,机制含 Nrf2 激活——"主开关激活剂已进药房"。

### 4.2 激活剂的抗衰应用

- **萝卜硫素**：西兰花芽提取物,激活 Nrf2 → 抗氧化/抗炎——"吃西兰花芽,开抗氧化开关"（动物证据充分,人体证据积累中）;
- **CDDO 类**：强效 Nrf2 激活剂（动物延寿研究）——"强开关,强效果,但需注意剂量";
- **姜黄素**：弱激活 Nrf2（多种机制）——"温和开关";
- **运动**：运动诱导适度氧化应激 → Nrf2 激活 → 抗氧化适应——"让开关自己开,而不是靠药";
- **"适度激活"原则**：Nrf2 过度激活（持续）有风险（癌细胞利用 Nrf2 抗氧化逃逸）——"开关开太大,癌细胞也受益"（呼应 [13-p53-structure.md](13-p53-structure.md) 的"适度"主题）。

## 5. Nrf2 与衰老：结构视角的"抗氧化主开关衰退"

### 5.1 衰老时 Nrf2 活性下降

- **表达/活性下降**：老年组织 Nrf2 蛋白水平/活性下降 → 抗氧化基因表达减弱——"主开关老化";
- **KEAP1 变化**：KEAP1 表达可能升高（部分组织）→ 更严的扣留——"门闩更紧";
- **表观改变**：Nrf2 靶基因启动子的表观修饰（高甲基化）随龄 → 即使 Nrf2 入核也难激活——"开关开了,线路老化";
- **后果**：抗氧化能力↓ → 氧化损伤累积 → 加速衰老（线粒体/蛋白/DNA 损伤）——"消防队下班,火灾频发"。

### 5.2 "修开关"的抗衰策略

- **激活 Nrf2**（萝卜硫素/DMF/运动）：恢复抗氧化能力——"重新打开消防队";
- **减少氧化应激**（抗氧化生活方式）：少报警 → KEAP1 少被消耗 → Nrf2 系统更健康——"少着火,消防队不累";
- **与炎症联动**：Nrf2 激活 → 抑制 NF-κB → 抗炎——"抗氧化和抗炎一起修";
- **"适度"原则**：Nrf2 激活要"间歇/适度"（避免持续过度激活的促癌风险）——"开关间歇开,别长开"。

### 5.3 与中药"益气活血"的联系

- 黄芪（黄芪多糖）、三七、姜黄等中药成分被报道激活 Nrf2——"益气活血的部分机制 = 开抗氧化开关";
- 结构视角：这些成分多为亲电物/酚类（含可修饰 Cys 或激活 Nrf2 的基团）——"中药的化学指纹,对准了 Cys 开关";
- 科学意义：为"益气活血-抗氧化-抗衰"提供分子结构依据——"中医智慧,结构验证"（呼应 [06-tcm/01-yiqi-huoxue.md](../06-tcm/01-yiqi-huoxue.md)）。

## 7. 与知识库主线联系

### 7.0 "抗氧化主开关" vs "炎症主开关"：Nrf2 与 NF-κB 的阴阳

NF-κB（[14-nfkb-structure.md](14-nfkb-structure.md)）是炎症"主开关",Nrf2 是抗氧化"主开关"——两者构成"氧化-炎症"的阴阳对:

| 维度 | Nrf2（抗氧化开关） | NF-κB（炎症开关） |
|---|---|---|
| 触发 | 氧化应激（Cys 修饰） | 炎症信号（TNF/IL-1/LPS） |
| 扣留 | KEAP1（双锚铰链-门闩） | IκB（锚蛋白重复） |
| 释放 | KEAP1 Cys 修饰 → 门闩松 | IκB 磷酸化降解 |
| 靶基因 | 抗氧化/解毒（200+） | 炎症因子（400+） |
| 衰老趋势 | 活性↓ | 活性↑ |
| 互作 | Nrf2 抑制 NF-κB | — |

**"阴阳失衡"即衰老**：衰老时抗氧化开关"关小"（Nrf2↓）+ 炎症开关"开大"（NF-κB↑）→ 氧化-炎症恶性循环——**"灭火队下班,火灾警报乱响"**。抗衰策略:开大 Nrf2 + 关小 NF-κB（"修灭火队 + 关警报"）。

**结构对照的价值**：两个开关都用"扣留-释放"设计（KEAP1/IκB 都是"胞质扣押"）,但机制不同（Cys 修饰 vs 磷酸化）——"同样的设计哲学,不同的触发化学"。理解两者的结构,才能设计"双开关联动"的抗衰干预。

### 7.00 "硫醇开关"vs"磷酸化开关"：两种化学,同一哲学

深入一步看两个开关的"触发化学"差异,能理解衰老干预的不同路径:

**Nrf2 的"硫醇开关"（化学感知）。** KEAP1 的 Cys 直接与氧化应激"分子对分子"——ROS/亲电物修饰硫醇,不需要信号通路,响应极快（分钟级）——**"化学直接感知,不需中间人"**。这适合应对"氧化应激"这种化学事件——"火警探测器直接感应烟雾"。

**NF-κB 的"磷酸化开关"（信号感知）。** IKK 磷酸化 IκB 需要完整的信号级联（受体→接头→激酶）——慢一些（小时级）但更"可调"（信号强度→磷酸化程度）——**"信号网络感知,层层传导"**。这适合应对"炎症因子"这种生物信号——"警报中心接电话"。

**"两种化学"的抗衰意义**：
- 激活 Nrf2（硫醇开关）可以直接用"化学钥匙"（萝卜硫素等亲电物）——"直接拧开关";
- 抑制 NF-κB（磷酸化开关）需要"信号干预"（抗炎药/生活方式）——"影响信号链";
- **组合策略**：萝卜硫素（开 Nrf2）+ 抗炎生活方式（关 NF-κB）= "双开关联动"——"拧开灭火队开关 + 关小警报"。

**结构生物学的洞察**：两个主开关的"触发化学"不同,意味着**干预手段必须匹配触发机制**——"化学开关用化学钥匙,信号开关用信号干预"。这是"从结构到策略"的又一例证。

### 7.1 主线篇目对话

- **线粒体/ROS**（[04-mitochondria](../02-vascular/04-mitochondria.md)）：Nrf2 清除线粒体 ROS——"发电厂的消防队";
- **炎症衰老**（[02-inflammaging](../03-immunity/02-inflammaging.md)）：Nrf2 抑制 NF-κB——"抗氧化开关压着炎症开关";
- **复合物 I**（[12-complex1-structure.md](12-complex1-structure.md)）：复合物 I 漏电（ROS）→ Nrf2 激活——"漏电触发消防队";
- **NF-κB 结构**（[14-nfkb-structure.md](14-nfkb-structure.md)）：氧化-炎症阴阳对;
- **中药益气活血**（[01-yiqi-huoxue](../06-tcm/01-yiqi-huoxue.md)）：中药成分激活 Nrf2——"中医智慧的结构验证";
- **p53 结构**（[13-p53-structure.md](13-p53-structure.md)）：Nrf2 与 p53 有互作（Nrf2 影响 p53 稳定性）——"抗氧化开关与命运判决官的对话"。

### 7.2 氧化-炎症-免疫的三重联动

Nrf2 不仅与 NF-κB 构成"阴阳",还连接免疫衰老——三条线在此交汇:

**Nrf2-免疫轴。** Nrf2 调控巨噬细胞 M1/M2 极化（促进 M2 抗炎）、T 细胞存活——"抗氧化开关影响免疫平衡"（呼应 [03-macrophage-polar.md](../03-immunity/03-macrophage-polar.md)）;

**NF-κB-免疫轴。** NF-κB 驱动促炎 M1、T 细胞活化——"炎症开关推动免疫激活";

**三重联动。** Nrf2↓ + NF-κB↑ → 巨噬细胞偏向 M1（促炎）→ 免疫衰老加速 → 炎症更多——"抗氧化关小、炎症开大、免疫偏向促炎——三环相扣的衰老加速器"。

**结构视角的干预入口**：①激活 Nrf2（开抗氧化）→ 间接抑制 NF-κB + 促进 M2;②抗炎（关 NF-κB）→ 减少 M1;③维持免疫平衡（胸腺/生活方式）——"三个入口,同一个目标:打破氧化-炎症-免疫的恶性循环"。**"结构知识让'全身抗衰'有了分子级的抓手"**（呼应 [03-macrophage-polar.md](../03-immunity/03-macrophage-polar.md) 与 [05-thymus-tcells.md](../03-immunity/05-thymus-tcells.md)）。

## 8. 结构-衰老"五问"总结

| 问题 | 结构答案 |
|---|---|
| KEAP1 怎么抓住 Nrf2？ | 二聚体的两个 Kelch 域抓住 Nrf2 的 ETGE（铰链）+ DLG（门闩） |
| 为什么需要双基序？ | 门闩松→增量释放（可控）,铰链留→旧 Nrf2 仍降解（不过度） |
| 氧化应激怎么打开开关？ | KEAP1 Cys151/273/288 修饰 → 构象变化 → DLG 松、ETGE 留 |
| 为什么 Nrf2 活性随龄下降？ | 表达↓ + KEAP1 变化 + 表观沉默——"开关老化" |
| 怎么抗衰？ | 适度激活 Nrf2（SFN/DMF/运动）+ 减少氧化应激——"修消防队,少着火" |

**五问之外的结构直觉**：Nrf2/KEAP1 的故事还揭示了"传感器"设计的普遍原则——**"感知应激的传感器,必须装在应激最常发生的地方"**。KEAP1 的 Cys 开关装在胞质（氧化应激的现场）,NF-κB 的传感器（受体/激酶）装在细胞表面（炎症信号的入口）——**"传感器装在前线,响应器放在后方"**。衰老时,传感器（Cys）被反复"磨损"（氧化修饰累积）、响应器（Nrf2 转录）衰减——**"传感器钝了,响应器慢了,防御系统就老了"**。这提醒我们:抗衰不只是"补充抗氧化剂",更是**"保养传感器的灵敏度"**——适度应激（运动）保持传感器敏锐,过度应激（慢性氧化）磨钝传感器——"适度用,传感器才耐用"。

### 9.00 "双面 Nrf2"：为什么过度激活也危险

与 p53 一样,Nrf2 也是"双刃剑"——结构视角能看清"过度"的风险:

**癌细胞"劫持"Nrf2。** 约 30% 的肺癌/头颈癌携带 KEAP1/Nrf2 突变（KEAP1 失活或 Nrf2 稳定突变）→ Nrf2 持续激活 → 癌细胞抗氧化能力增强 → 抵抗化疗/放疗——"癌细胞把消防队变成自己的保镖"。结构上,突变破坏 KEAP1-Nrf2 结合（ETGE/DLG 界面突变）——"把手断了,扣不住"。

**"持续激活" vs "适度激活"。** 持续激活 Nrf2（突变/长期强激活剂）→ 促癌风险;间歇/适度激活（运动、饮食、短程激活剂）→ 保护——"消防队该待命时待命,该出动时出动,不能24小时喷水"。

**"开关的剂量学"。** 结构生物学提示:KEAP1 的 Cys 修饰程度决定 Nrf2 释放量——"轻度修饰→少量释放（适度保护）,深度修饰→大量释放（过度）"。**理想的 Nrf2 激活是"轻拧开关",不是"拆掉开关"**——"适度应激（运动/蔬食）轻拧,强效药物（CDDO）重拧需谨慎"。

**抗衰启示**：Nrf2 激活要"适度+间歇",配合癌症筛查——"开消防队,也要防火灾（癌症）"。这再次印证 10-structures 专题的"适度"主题（p53/NF-κB/Nrf2 三大开关都是"适度最好"）——**"衰老干预的本质,是让所有开关回到年轻时的'适度'状态"**。

### 9.1 结构生物学如何"看清"开关设计

Nrf2/KEAP1 是 10-structures 专题第 15 篇,也是"细胞防御开关"系列的收官——回顾这个系列（NF-κB 炎症开关、p53 命运开关、Nrf2 抗氧化开关）,一个清晰的"开关设计谱系"浮现:

**"扣留-释放"是通用设计。** KEAP1 扣 Nrf2（Cys 修饰释放）、IκB 扣 NF-κB（磷酸化释放）、MDM2 扣 p53（磷酸化释放）——三个开关都用"胞质扣押 + 修饰触发释放"——**"通用设计哲学:平时锁住,应激解锁"**。

**"触发化学"各不相同。** KEAP1 用硫醇（化学感知,快）;IκB 用磷酸化（信号感知,慢但可调）;MDM2 用磷酸化 + 泛素化（信号感知）——**"锁相同,钥匙不同"**。

**"释放后"的差异。** Nrf2 增量放行（铰链-门闩）;NF-κB 全量释放（IκB 降解即全开）;p53 分级响应（PTM 组合）——"放行方式决定响应的可控性"。

**抗衰启示（15 篇的方法论总结）**：10-structures 专题从 [01-NOS](01-nos-structures.md) 到 [15-Nrf2](15-nrf2-structure.md),覆盖了信号（NOS/sGC）、代谢（AMPK/mTOR/复合物 I）、表观（TET/DNMT1/SIRT1）、NAD⁺ 经济（SIRT1/CD38/PARP1/NAMPT）、端粒（TERT）、细胞命运（p53）、炎症（NF-κB）、抗氧化（Nrf2）——**"衰老的分子网络地图已经画出主干"**。每个分子的结构揭示了它"怎么工作",而系列合读揭示了"网络怎么运转"——**"从原子到网络,从结构到策略"**。
