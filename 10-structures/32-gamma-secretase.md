## 0. 结构速览

**一句话**：γ-分泌酶是"膜内蛋白酶"——在细胞膜内部切割跨膜蛋白（APP/Notch 等）。切割 APP 产生 Aβ 肽（AD 的"淀粉样斑块"成分）;切割 Notch 参与发育/癌症——"细胞膜的'水下剪刀': 在膜内切蛋白, 既造'好肽'（Notch 信号）也造'坏肽'（Aβ）"。

```text
γ-分泌酶结构:
  PS1(催化亚基, 天冬氨酸蛋白酶) — NCT(尼古丁受体, 底物识别) — APH-1(支架) — PEN-2(稳定)
                  │
  组装:  4个亚基 1:1:1:1 → 跨膜复合物(~170 kDa)
                  │
  催化:  PS1的2个天冬氨酸(D257/D385) → 天冬氨酸蛋白酶(膜内)
                  │
  底物:  APP(切割→Aβ) / Notch(切割→信号) / 其他跨膜蛋白
```

**三大结构特征**（决定其功能的原子基础）：
1. **PS1 催化亚基**：9 次跨膜, 两个天冬氨酸（D257/D385）形成催化位点——"剪刀的刃在膜内";
2. **NCT 胞外域**：大的胞外域, 识别底物胞外部分（"底物门卫"）——"剪刀的'认料口'";
3. **跨膜马蹄形排列**：PS1 的 TM 束形成"马蹄形", 活性位点在凹侧——"剪刀的'钳口'在膜内"。

**核心调控机制**：

```text
APP 加工(淀粉样通路):
  α-分泌酶切割 → sAPPα(正常, 不产生Aβ)
        │
  β-分泌酶(BACE1)切割 → sAPPβ + C99(跨膜片段)
        │
  γ-分泌酶切割 C99 → Aβ(38-43 aa) + AICD
        │
  AD:  Aβ42增多(易聚集) → 寡聚体/斑块 → 神经毒性
```

**一句话记忆**：γ-分泌酶是"膜内的 Aβ 剪刀"——PS1 提供刀刃（天冬氨酸）, NCT 认料, APH-1/PEN-2 组装——"在油里挖水塘, 水下剪跨膜蛋白"——"调它要精准（GSM）, 不要一刀切（GSI）"。

## 1. 为什么 γ-分泌酶结构重要

γ-分泌酶是 AD 研究的"核心靶点":

- **"Aβ 剪刀"**：γ-分泌酶切割 APP 产生 Aβ——AD 的"淀粉样斑块"来自 Aβ 聚集——"造'坏肽'的剪刀";
- **AD 遗传学**：大多数家族性 AD（FAD）突变位于 PS1（γ-分泌酶催化亚基）→ 改变 Aβ 切割（Aβ42↑）——"剪刀的'调校'变了, 造更多坏肽";
- **Notch 信号**：γ-分泌酶也切割 Notch（发育/细胞命运关键信号）→ 完全抑制 γ-分泌酶 → Notch 信号阻断 → 毒性（免疫/肠道）——"剪刀也造'好肽', 不能乱剪";
- **抗衰证据**：Aβ 聚集是 AD 核心病理;γ-分泌酶调节（Aβ42 降低）是 AD 治疗方向——"调节剪刀, 少造坏肽";
- **与蛋白质稳态对话**：Aβ 清除依赖溶酶体/自噬（[28-tfeb.md](28-tfeb.md)）;Aβ 聚集与蛋白质稳态崩溃相关——"坏肽堆积, 回收站失守";
- **药物靶点**：γ-分泌酶抑制剂/调节剂（GSI/GSM）——"剪刀的'刹车'和'调校'"（GSI 因 Notch 毒性失败, GSM 调节 Aβ42 是方向）。

**结构研究的三个关键问题**：
1. 膜内蛋白酶怎么在水环境切跨膜蛋白（催化的"水下"机制）？
2. PS1 的活性位点怎么工作（两个天冬氨酸）？
3. 底物特异性怎么实现（APP vs Notch 的选择）？

这些问题在 5A63（γ-分泌酶原子结构, 2015）、5FN5（构象态, 2015）等结构中得到回答。

## 2. γ-分泌酶的结构解剖

### 2.1 PS1 催化亚基——"水下剪刀"

- 位置：跨膜（9 次跨膜）;
- 结构：天冬氨酸蛋白酶折叠（膜内版本）——"剪刀的刃是'水下'的";
- 催化位点：两个天冬氨酸（D257/D385）在 TM6/TM7 → 形成催化二联体——"两片刀刃（天冬氨酸）";
- 5A63 的发现：PS1 的 TM2/TM6 高度柔性 → "塑料活性位点"（可适应不同底物）——"刀刃可以'微调'";
- AD 突变热点：FAD 突变集中在两个"四 TM 束"中心（TM 束 A/B）→ 影响底物切割——"突变改剪刀的'调校'"。

### 2.2 NCT 胞外域——"认料口"

- 位置：大的胞外域（~700 aa）+ 单次跨膜;
- 结构：大的 β-螺旋桨样结构域——"剪刀的'认料口'";
- 功能：识别底物胞外部分（"门卫"）→ 决定底物特异性/时序——"认料口决定'切什么'";
- 5A63 的发现：底物招募后 NCT 胞外域有构象变化（"大开口"）→ 允许底物进入——"认料口'张嘴'接料"。

### 2.3 APH-1/PEN-2——"支架与铆钉"

- APH-1：跨膜支架（7 次跨膜）→ 锚定 NCT 跨膜螺旋 + 支持 PS1 柔性构象——"剪刀的'框架'";
- PEN-2：小跨膜蛋白 → 稳定 PS1 成熟/组装——"剪刀的'铆钉'";
- 组装：PS1+NCT+APH-1+PEN-2（1:1:1:1）→ 功能性复合物——"四件套组装成剪刀"。

## 3. 膜内蛋白酶的分子逻辑：从结构到化学

### 3.00 "在油里挖水塘"的工程智慧：为什么 γ-分泌酶要"局部造水"

上一节讲了水腔,这一节深入理解**为什么膜内蛋白酶要'造水'而不是'改机制'**——这是"环境适应"的进化解:

**"天冬氨酸蛋白酶 = 水依赖"。** 天冬氨酸蛋白酶家族（胃蛋白酶、组织蛋白酶 D）都用"两个天冬氨酸 + 水分子"催化——γ-分泌酶继承了这套"催化遗产"（PS1 是天冬氨酸蛋白酶家族成员）→ 必须"有水才能切"——"老祖宗的机制不能改, 只能改造环境";

**"造水 = 局部亲水口袋"。** 膜内是疏水的（碳氢链）——γ-分泌酶在 TM 束之间"挖"一个亲水腔（极性残基衬里）→ 局部形成"水环境"——"在油里挖一口井, 井里有水就能切"——"不是把整个膜变水, 而是'局部造水'";

**"能量代价与获益"**：造水腔"贵"（需要稳定极性残基在膜内）→ 但换来"可以在膜内切"的能力 → 细胞膜上的蛋白（APP/Notch）不用"出来"就能被处理——"贵但值: 省了'把底物拉出膜'的功夫";

**"与可溶性蛋白酶的对照"**：胰蛋白酶（水环境）直接在水里切;γ-分泌酶（膜内）得"自带水"——"同样的催化化学（天冬氨酸+水）, 不同的环境适应（自带 vs 现成）"——"进化在'同样的刀'上加'造水'功能, 就换了个工作地点"。

### 3.10 "底物的'解螺旋'之谜"：怎么把跨膜螺旋拉直

γ-分泌酶切割底物前需要"解螺旋"——"把弹簧拉直再切"的分子机制:

**"α 螺旋 vs 伸展链"。** 跨膜底物（C99/Notch）在膜内是 α 螺旋（肽键藏在螺旋内部）→ 蛋白酶够不到肽键 → 必须"解螺旋"（螺旋→伸展）→ 肽键暴露——"弹簧不拉直, 剪刀够不到缝";

**"催化位点的'挤'进去"。** 底物从 TM 束的"侧开口"进入（5A63 显示活性位点在 TM 马蹄形凹侧）→ 螺旋被"挤"入亲水腔 → 局部解螺旋——"把弹簧压进'水塘', 弹簧在入口处被拉直";

**"'解螺旋'的能量代价"。** 破坏螺旋氢键"贵"（氢键稳定螺旋）→ 但 γ-分泌酶用"底物结合能"（NCT 识别 + PS1 口袋）支付——"用'抓得紧'换'拉得直'"——"底物结合的能量, 一部分用来'拉直'";

**"与蛋白酶体的'展开'对照"**（[20-proteasome.md](20-proteasome.md)）：蛋白酶体用 ATP 马达把底物"展开"（机械力）;γ-分泌酶用"结合能"解螺旋（无 ATP）——"一个用'电钻'（ATP 马达）, 一个用'巧劲'（结合能）"——"两种'展开底物'的策略: 机械 vs 化学"。

### 3.20 "Aβ 长度的'剪裁逻辑'"：为什么 γ 位点决定毒性

γ-分泌酶的过程性切割"剪出"不同长度 Aβ——"剪裁的'最后一刀'在哪, 决定毒性":

**"过程性切割的'步进'"。** γ-分泌酶先切 ε 位点（靠近膜内 C 端）→ 再沿底物"往回切"（ζ→γ）→ 每切一次"短一点"→ 产生 Aβ48/46/43/42/40/38 等——"剪刀'分段退着剪', 每刀短 3 个残基";

**"Aβ42 的'疏水性'"。** Aβ42 比 Aβ40 多 2 个疏水残基（IA）→ 更易聚集（更强的疏水作用）→ 寡聚体毒性↑——"多两格'胶水', 更易粘成团";

**"'切割位点偏移'的后果"。** FAD 突变（PS1）→ 切割提前终止（γ 位点偏移）→ Aβ42 比例↑→ 聚集↑——"剪刀'提前收刀', 多出 Aβ42"——"Aβ42/40 比 = '剪刀调校'的读数";

**"GSM 的'调校'逻辑"**。 γ-分泌酶调节剂（GSM）→ 让切割"更靠前"（γ 位点→Aβ38/40）→ Aβ42↓——"把剪刀'往回调', 少出长肽"——"GSM = 剪刀的'微调旋钮', 不拆剪刀（保留 Notch 功能）——这是目前最被看好的'精准调校'方向"。

**"抗衰启示"**：Aβ42 是"剪多了"的产物（易聚集）→ ①GSM 调节切割（Aβ42↓）;②BACE1 抑制（少送料）;③清除增强（自噬/溶酶体）——"调剪刀 + 少送料 + 勤清, 三管齐下压 Aβ 负担"。

很多人会问:蛋白酶一般在水环境工作,γ-分泌酶怎么在"膜内（疏水环境）"切割?答案在"天冬氨酸催化的'水下'设计":

**"天冬氨酸 = 水激活"。** 天冬氨酸蛋白酶催化需要"水分子"（一个天冬氨酸激活水, 水攻击肽键）——但膜内是疏水的（没有水）!γ-分泌酶的解决方案:**PS1 的活性位点在 TM 束之间形成一个"水腔"（亲水口袋）**——"在疏水的膜里挖一个'小水塘', 剪刀在水塘里工作"——"膜内催化 = 局部造水环境";

**"底物的'解螺旋'"。** 底物（C99/Notch）是跨膜 α 螺旋——γ-分泌酶切割前需"解螺旋"（螺旋展开）→ 肽键暴露给水腔——"把螺旋'拉直', 才能切"——"剪刀切的是'展开的肽链', 不是螺旋";

**"多位点切割（过程性）"。** γ-分泌酶沿底物"连续切割"（ε→ζ→γ 位点）→ 产生不同长度 Aβ（Aβ38-43）——"剪刀'分段剪', 每剪一次出一段"——"Aβ42 是'剪多了一次'的产物（毒性最强）";

**"与 20S 蛋白酶体的对照"**（[20-proteasome.md](20-proteasome.md)）：蛋白酶体在胞质（水环境）切"去折叠蛋白";γ-分泌酶在膜内（疏水）切"跨膜蛋白"——"两种'水下作业': 一个在水里, 一个在油里（局部造水）"——"膜内蛋白酶 = 在油里挖水塘干活"。

### 3.1 "APP 加工的'通路选择'"：α vs β vs γ

APP 加工的"三条路"决定 Aβ 产量——"剪刀的选择决定命运":

**"α-分泌酶通路（不产生 Aβ）"**：α-分泌酶在 Aβ 序列内切割 → sAPPα + C83 → γ 切割 C83 → p3（不聚集）——"好路: 不产生坏肽";

**"β-分泌酶通路（产生 Aβ）"**：BACE1 在 Aβ 序列 N 端切割 → sAPPβ + C99 → γ 切割 C99 → Aβ——"坏路: 产生坏肽";

**"γ-分泌酶的'最后一刀'"**：γ-分泌酶切 C99/C83 的 γ 位点 → 决定 Aβ 长度（Aβ40 vs Aβ42）→ Aβ42 更易聚集——"最后一刀的'位置'决定毒性";

**"AD 的'剪刀调校'"**：FAD 突变（PS1）→ γ 切割位点偏移 → Aβ42/Aβ40 比↑ → 聚集↑——"剪刀'调校'变了, 多切出 Aβ42"——"Aβ42/40 比 = AD 风险的关键指标"。

**"抗衰启示"**：①减少 Aβ 产生（β-分泌酶抑制/BACE1 抑制剂）或调节 γ 切割（GSM 降 Aβ42）→ 少造坏肽;②增强 Aβ 清除（溶酶体/自噬, [28-tfeb.md](28-tfeb.md)）→ 及时清走——"少造 + 勤清, 淀粉样负担才低"。

## 4. γ-分泌酶与衰老：结构视角的"剪刀失守"

### 4.1 AD 与衰老的 γ-分泌酶视角

- **Aβ 聚集随龄累积**：Aβ 产生（γ 切割）随龄变化 + 清除（自噬/溶酶体）随龄下降 → Aβ 累积——"造的多, 清的少, 堆积成斑";
- **"淀粉样级联假说"**：Aβ 寡聚体 → 突触毒性 → Tau 缠结 → 神经退行——"坏肽引发'多米诺'"（Aβ 是"上游扳机"）;
- **PS1 突变（FAD）**：早发 AD（~50 岁发病）→ γ 切割异常 → Aβ42↑——"剪刀先天'调校'错";
- **散发性 AD**：清除下降（自噬/溶酶体, [28-tfeb.md](28-tfeb.md)）+ 炎症（cGAS-STING, [30-cgas-sting.md](30-cgas-sting.md)）→ Aβ 累积——"后天'清道夫'失守"。

### 4.2 "修剪刀"的抗衰策略

- **γ-分泌酶调节剂（GSM）**：不抑制（保留 Notch 功能）只调节切割位点 → Aβ42↓/Aβ40↑——"微调剪刀, 不拆剪刀";
- **β-分泌酶抑制剂（BACE1 抑制剂）**：减少 C99 产生 → 少底物——"少给剪刀送料"（注意: 临床有剂量限制性毒性）;
- **Aβ 清除增强**：溶酶体/自噬（[28-tfeb.md](28-tfeb.md)）+ 运动 → 清走坏肽——"勤清垃圾";
- **抗炎**：抑制神经炎症（cGAS-STING/NF-κB）→ 减缓 Aβ 毒性——"灭火, 少损伤";
- **"适度"原则**：完全抑制 γ-分泌酶（GSI）→ Notch 毒性（肠道/免疫）→ 失败（临床试验教训）——"剪刀不能拆, 只能调"。

### 4.4 "神经退行与蛋白质稳态"：为什么 Aβ 堆积是'蛋白质组崩溃'的一环

Aβ 聚集不只是 AD 的孤立病理——它是"蛋白质稳态崩溃"在神经系统的一个表现:

**"'聚集倾向'的物理根源"。** Aβ 序列含"强疏水区"（C 端）+ "易 β 折叠"倾向 → 在浓度高/清除差时"自发聚集"——"有些肽天生'爱抱团', 环境差就成团";

**"'清除失守'的衰老背景"。** 自噬/溶酶体功能随龄下降（[28-tfeb.md](28-tfeb.md)）→ Aβ 清除↓ → 聚集↑——"垃圾清运变慢, 坏肽就堆起来";

**"'聚集与炎症'的恶性循环"。** Aβ 寡聚体 → 激活小胶质细胞 → 炎症（cGAS-STING/NF-κB, [30-cgas-sting.md](30-cgas-sting.md)）→ 炎症损伤神经元 → 更多聚集——"坏肽引发'炎症风暴', 风暴又伤神经元——循环放大";

**"'蛋白质稳态网络'的全景"。** Aβ 聚集只是"冰山一角"——Tau 缠结、α-突触核蛋白（帕金森）等都是"聚集病"（蛋白质构象病）——"AD/帕金森/ALS = 不同蛋白的'聚集病'家族"——"结构知识揭示: 神经退行病的共同'物理主题'是蛋白质聚集——抗衰的关键是'防聚集 + 勤清除'"。

### 4.5 "γ-分泌酶与 Notch"：好肽与坏肽的平衡

γ-分泌酶"一把剪刀切两个重要底物"——"好肽坏肽的平衡":

**"Notch 信号的功能"**：Notch 切割 → NICD（胞内域）→ 入核 → 转录 → 发育/干细胞/免疫/肠道——"Notch 是'发育和再生的开关'";

**"GSI 的'一刀切'教训"**：γ-分泌酶抑制剂（GSI）想"全抑制"（降 Aβ）→ 但 Notch 也被切 → 肠道/免疫毒性（临床试验失败, 2013 semagacestat 3 期）——"拆了剪刀, 好肽也没了——教训: 不能全拆";

**"GSM 的'选择性'智慧"**：调节剂（GSM）只调切割位点（Aβ42↓）不抑制整体 → Notch 保留——"只调'刀口', 不拆'剪刀'"——"选择性 = 治疗的生存线";

**"底物特异性的结构问题"**：γ-分泌酶怎么区分 APP 和 Notch（切的位置/产物不同）——NCT 胞外域 + PS1 口袋的底物识别（5A63/6IDF 等研究）——"认料口怎么'认料'——结构正在回答"。

**"抗衰启示"**：γ-分泌酶是"双刃剑"——"调它要'精准'（GSM 式）, 不要'一刀切'（GSI 式）——好肽要留, 坏肽要压——精准调校, 平衡为上, 这是结构知识给 γ-分泌酶干预的核心原则"。

### 6.0 "蛋白水解家族"的结构总览：32 篇的"剪刀"家族

**"三种'剪刀'的分工"**：蛋白酶体（胞质单体蛋白）+ γ-分泌酶（膜内跨膜蛋白）+ 溶酶体（酸性大件）——"细胞的三套'切割系统', 各管一类底物"——**"蛋白水解的'区室化': 不同环境（胞质/膜/溶酶体）配不同剪刀"**。

**"为什么需要三套剪刀"**：①胞质蛋白（寿命短/错误折叠）→ 蛋白酶体（快速, ATP 依赖）;②跨膜蛋白（膜内片段）→ γ-分泌酶（膜内切, 不用拉出膜）;③大件/细胞器/胞吞物 → 溶酶体（酸性, 大容量）——"每种'垃圾'的物理位置不同, 配不同的'垃圾处理机'"——"区室化 = 各司其职, 不串门";

**"'三套剪刀'的衰老状态"**：蛋白酶体活性↓（[20-proteasome.md](20-proteasome.md)）、自噬-溶酶体↓（[18-lc3-autophagy.md](18-lc3-autophagy.md)/[28-tfeb.md](28-tfeb.md)）、γ-分泌酶切割偏移（Aβ42↑）→ "三套系统都老化 → 蛋白水解整体衰退 → 聚集病风险↑"——"三把剪刀都钝, 蛋白质组就堵了";

**"'增强水解'的抗衰意义"**：激活蛋白酶体（Nrf2 等）、增强自噬（[27-ulk1.md](27-ulk1.md) 启动/禁食）、维持溶酶体酸化（[29-v-atpase.md](29-v-atpase.md)）→ "三套剪刀都磨快 → 聚集物清得动"——"水解系统 = 蛋白质组的'下水道', 通了下水道, 垃圾不堵"。

### 8.2 "γ-分泌酶研究的历史启示"：从生化学到结构生物学的 30 年

γ-分泌酶的结构研究史本身就是"生物化学如何走向原子级"的缩影:

**"1990s: 生化学时代"。** 发现 PS1 突变致 FAD（1995）→ 证明 PS1 是 γ-分泌酶催化亚基（1998-1999, 天冬氨酸突变失活）——"遗传学指路, 生化学定性";

**"2000s: 组装与抑制剂的'暗箱'"。** 鉴定 4 亚基组装（PS1/NCT/APH-1/PEN-2, 2003 前后）;开发 GSI/GSM 化合物——但"活性位点长什么样"不知道（膜蛋白结晶难）——"知道'是什么', 不知道'长什么样'";

**"2010s: 冷冻电镜的突破"。** 2015 年 5A63（3.4 Å）→ 首次看到 γ-分泌酶原子结构（PS1 的 TM 束、天冬氨酸、马蹄形排列）→ 从"暗箱"到"原子级"——"冷冻电镜革命: 膜蛋白结构不再是'禁区'";

**"'结构-疾病'的闭环"。** 5A63 把 FAD 突变"映射"到 PS1 结构（两个热点区, 四 TM 束中心）→ 解释突变怎么致病（影响底物进入/切割）——"从'突变在哪'到'突变怎么致病'——结构给了'为什么'";

**"抗衰启示"**：γ-分泌酶史是"分子结构级研究"的范例——"没有结构, 只能猜'怎么修';有了结构, 才能设计'精准修'（GSM 的合理设计）"——"结构生物学 = 把'黑箱'变成'图纸'——这是抗衰研究从'试错'到'设计'的关键"。

### 8.3 "Aβ 之外的视角"：γ-分泌酶与 Notch 在衰老中的作用

除了 Aβ,γ-分泌酶切割 Notch 的"衰老视角"同样值得看——"好肽在衰老中的角色":

**"Notch 与干细胞/再生"。** Notch 信号维持干细胞（肠道/肌肉/神经）→ 衰老时 Notch 信号变化 → 再生能力↓——"再生开关的'老化'";

**"'γ-分泌酶活性'随龄变化"。** 研究提示 γ-分泌酶活性/组装随龄改变 → 影响 APP 切割（Aβ 产生）和 Notch 切割（再生）→ "一把剪刀, 两个衰老相关功能都受影响";

**"'平衡'的衰老哲学"。** γ-分泌酶的故事教我们: 衰老干预常是"平衡艺术"（好肽要留, 坏肽要压）——"不是'消灭'某个分子, 而是'调好'它的输出——GSM 式'微调'优于 GSI 式'全拆'"——"分子结构知识让'微调'成为可能: 知道刀口在哪, 才能只调刀口"。
