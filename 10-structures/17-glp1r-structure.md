## 0. 结构速览

**一句话**：GLP-1 受体是"肠促胰素"信号的核心接收器——进食后肠道分泌 GLP-1,激活胰腺 β 细胞的 GLP-1R → 促胰岛素分泌（降糖）+ 抑制胰高血糖素 + 延缓胃排空 + 中枢抑制食欲——"吃饱的信号,身体的'减重开关'"。它的结构属于 **B 类 GPCR**（分泌素家族）——胞外域（ECD）"捕获"肽配体,跨膜域（TMD）"传导"信号到 Gs 蛋白——"两段式激活:先抓住,再传信"。

```text
GLP-1R 结构:  N端ECD(捕蝇草样) — 铰链 — 7次跨膜TMD — 胞内环(结合Gs) — C端
                  │
   配体结合:  GLP-1肽的C端 α螺旋 插入 ECD的疏水沟(抓住)
              GLP-1肽的N端 插入 TMD的胞外口袋(激活)
                  │
   信号传导:  TMD构象变化 → 胞内环打开 → Gs蛋白结合 → cAMP↑
```

**三大结构特征**（决定其功能的原子基础）：
1. **胞外域（ECD）"捕蝇草"**：两个叶瓣夹住 GLP-1 的 C 端螺旋——"先抓住猎物的尾巴";
2. **跨膜域（TMD）"激活口袋"**：GLP-1 的 N 端插入 7 次跨膜螺旋之间的口袋——"钥匙插进锁芯";
3. **胞内 Gs 结合面**：TMD 胞内端张开 → Gs 蛋白的 α5 螺旋插入——"信号传导的握手"。

**核心调控机制**：

```text
进食 → 肠道L细胞分泌 GLP-1 → 结合 GLP-1R(胰腺β细胞)
    → GLP-1R 激活 → Gs 招募 → 腺苷酸环化酶 → cAMP↑ → PKA 激活
    → 胰岛素分泌↑(葡萄糖依赖) + 胰高血糖素↓ + 胃排空↓ + 食欲↓
```

## 1. 为什么 GLP-1 受体结构重要

GLP-1 受体是当前代谢抗衰的"顶流靶点":

- **"减重神药"的靶点**：司美格鲁肽（Wegovy/Ozempic）、替尔泊肽（Tirzepatide, GLP-1/GIP 双激动）——"GLP-1 类药物已是全球最畅销药之一";
- **"代谢抗衰"的支点**：GLP-1R 激活 → 减重 + 降糖 + 心血管保护 + 可能的神经保护——"一个受体,多器官获益";
- **抗衰证据**：GLP-1 受体激动剂在动物/人体显示心血管/肾脏/认知获益,减重改善代谢衰老——"修代谢,就是修衰老的发动机";
- **与衰老的对话**：代谢衰老（胰岛素抵抗/肥胖）驱动全身衰老;GLP-1R 恢复代谢稳态——"修好代谢,全身受益";
- **结构-药物的桥梁**：司美格鲁肽等是 GLP-1 的"改造版"（脂肪酸修饰延长半衰期）——"结构改造决定药效";
- **B 类 GPCR 的代表**：GLP-1R 是 B 类 GPCR（分泌素家族）——"两段式激活"的教科书——"理解 GLP-1R,就理解了 B 类 GPCR 家族"。

**结构研究的三个关键问题**：
1. ECD 如何"捕获"GLP-1（捕蝇草的原子机制）？
2. 肽的 N 端如何"激活"TMD（钥匙插锁芯的机制）？
3. 偏倚激动（Gs vs β-arrestin）如何产生（不同药物的不同信号）？

这些问题在 6B3J（GLP-1R+偏倚激动剂+Gs, 2018）、6ORV（GLP-1R+非肽激动剂, 2020）等结构中得到回答。

## 2. GLP-1 受体的结构解剖

### 2.1 胞外域（ECD）——"捕蝇草"捕获器

- 位置：GLP-1R N 端（~1-140 残基）;
- 结构：**捕蝇草样（venus flytrap）** 折叠——两个叶瓣（lobe）夹着一个配体结合沟——"两片叶子夹住猎物";
- 配体结合：GLP-1 的 C 端 α 螺旋（残基 20-30）插入 ECD 的疏水沟——"猎物的尾巴被夹住";
- 关键接触：疏水残基（Leu/Val/Ile）+ 极性残基形成复合界面——"夹住的力量是疏水+氢键";
- 柔性铰链：ECD 与 TMD 之间的铰链区允许"闭合-张开"运动——"捕蝇草的开合关节";
- 结构-功能：ECD 主要提供"亲和力"（抓住配体）,但不直接激活——"抓住 ≠ 激活"。

### 2.2 跨膜域（TMD）——"锁芯"传导器

- 位置：GLP-1R 中段（~140-400 残基）;
- 结构：**7 次跨膜 α 螺旋**（TM1-TM7, 经典 GPCR 折叠）——"七根柱子撑起一个通道";
- 胞外口袋：TM1/TM2/TM6/TM7 围成的口袋——GLP-1 的 N 端（His7 等）插入——"钥匙的尖端插进锁芯";
- 激活构象：TM6 向外摆动 → 胞内端张开 → 暴露 Gs 结合面——"锁芯转动,门闩打开";
- 关键残基：TM6 的保守残基（P/R 等）参与激活——"锁芯的弹簧";
- 偏倚激动：不同激动剂使 TMD 产生不同的构象集合 → 偏向 Gs 或 β-arrestin——"同一把锁,不同钥匙转的角度不同"。

### 2.3 胞内 Gs 结合面——"握手"信号端

- 位置：TMD 胞内端 + 胞内环（ICL2/ICL3）;
- 结构：TMD 胞内端张开后,Gs 蛋白的 α5 螺旋插入——"手握手的'握手礼'";
- 信号：Gs 激活 → 腺苷酸环化酶 → cAMP↑ → PKA——"信号放大链的第一环";
- 6B3J 的细节：偏倚激动剂的 Gαs-α5 螺旋结合角度与 GLP-1 有 6° 差异——"手握手的方式微调,信号就不同"。

## 3. 两段式激活：从结构到化学

### 3.00 "捕蝇草"的工程智慧：为什么 ECD 是两片叶子

上一节讲了 ECD 抓住 C 端,这一节理解**为什么 B 类 GPCR 的配体结合域设计成"捕蝇草"**。这又是一个"工程"问题:

**方案一:没有 ECD,肽直接插 TMD。** 小分子 GPCR（如 β 肾上腺素受体）的配体直接进 TMD 口袋,但肽（30 个氨基酸）太大——"大钥匙没法直接插进小锁芯"。而且肽的 N 端和 C 端都有功能（C 端管结合、N 端管激活）——"钥匙两头都要用,不能整根塞进去"。

**方案二:ECD 先抓住,再引导插入。** ECD 的捕蝇草结构提供了"预结合平台"——①大界面（两片叶子夹住螺旋）提供高亲和力;②定向（把 N 端对准 TMD 口袋）;③柔性（铰链允许开合）。**"捕蝇草 = 高亲和 + 定向 + 柔性的三位一体设计"**——"先请客人进门（ECD 抓住）,再引导客人到会议室（N 端插入 TMD）"。

**为什么是"两片叶子"而不是"一片"?** 两片叶子夹住配体,接触面积大（>1000 Å²）→ 高亲和力（nM 级）——"两片叶子夹住,比一片叶子贴住更牢"。同时,两片叶子的开合（铰链运动）可以调节结合动力学——"叶子的开合速度,决定结合/解离的节奏"。

**"抓住 ≠ 激活"的生理意义**：ECD 提供亲和力但不激活——这让 GLP-1 类似物可以"抓住但慢慢激活"（缓释）;也让"拮抗剂"可以"抓住但不激活"（占位但不转锁芯）——"抓住和激活分离,药物设计就有两个独立旋钮"——这是 B 类 GPCR 药物设计的核心自由度。

**"两个旋钮"的实际应用**：旋钮一（亲和力旋钮）——改造 C 端/ECD 界面 → 调节"抓住"的牢固程度（决定药效持续时间的基础）;旋钮二（效力旋钮）——改造 N 端/TMD 界面 → 调节"激活"的强度（决定信号大小）。司美格鲁肽同时拧了两个旋钮:C 端脂肪酸（加长"抓住"）+ 抗 DPP-4 的 N 端（保住"激活"）——"两个旋钮一起拧,药效才能又长又强"——这是"结构到药房"最直接的一课,也是"结构改造决定临床命运"的生动例证。

### 3.0 一个原子一个原子地看：先抓住,再激活

**为什么 B 类 GPCR 要"两段式"?** 因为肽配体（GLP-1, 30 个氨基酸）比小分子（几百道尔顿）大得多——"大钥匙没法直接插进锁芯,要先校准方向"。两段式设计:

**第一段:ECD 抓住 C 端。** GLP-1 的 C 端螺旋（残基 20-30）与 ECD 结合——"校准方向,把 N 端对准锁芯"。这个结合是"预结合"——**"抓住 ≠ 激活,只是把钥匙对准锁孔"**。

**第二段:N 端插入 TMD。** GLP-1 的 N 端（His7/Glu9 等关键残基）插入 TMD 胞外口袋 → 触发 TM6 摆动 → 激活——"钥匙尖端转动锁芯"。N 端是"激活的关键",C 端是"结合的锚"——**"C 端负责抓住（亲和力）,N 端负责激活（效力）"**——"一个配体,两头分工"。

**"双位点"模型的证据**：截短的 GLP-1（去掉 C 端）亲和力大降但保留激活能力;去掉 N 端则激活能力丧失——"C 端管'抓',N 端管'开'"——这是 B 类 GPCR 的共同逻辑。

### 3.1 "偏倚激动"的结构逻辑：同一把锁,不同的钥匙

**什么是偏倚激动?** 同一个受体可以激活多条下游通路（Gs→cAMP、β-arrestin→内吞/其他信号）。不同配体偏向激活不同通路——"同一个开关,有的钥匙主要开灯,有的主要开风扇"。

**结构的解释（6B3J）**：偏倚激动剂（exendin-P5 类）结合后,TMD 的构象变化与 GLP-1 略有不同——Gαs-α5 螺旋的结合角度差 6°——"握手方式微调"——导致 Gs 激活效率不同。β-arrestin 的招募则依赖磷酸化条码（受体胞内域的磷酸化模式）——"不同的钥匙,写下不同的'磷酸化字条'"。

**药理学意义**：如果"减重+降糖"主要靠 Gs/cAMP,而"副作用"（恶心等）与 β-arrestin/其他通路相关,那么"Gs 偏倚激动剂"可能更好——"只开想要的灯,不吵到邻居"——这是下一代 GLP-1 药物的设计方向。

## 4. GLP-1 类药物：从结构到药房

### 4.1 司美格鲁肽的"结构改造"

- **GLP-1 的短板**：天然 GLP-1 半衰期仅 ~2 分钟（被 DPP-4 酶快速降解）——"天然钥匙太脆";
- **改造一：抗 DPP-4**：第 8 位丙氨酸换成 α-氨基丁酸 → 不被 DPP-4 切——"把易断的地方加固";
- **改造二：脂肪酸修饰**：第 26 位赖氨酸接上 C18 脂肪酸链 → 结合白蛋白 → 半衰期延长到 ~1 周——"给钥匙装上'白蛋白拖船',慢慢释放";
- **结果**：司美格鲁肽每周一次皮下注射——"结构改造把'分钟级'变成'周级'"。

### 4.2 从肽到小分子：口服 GLP-1 药物的结构挑战

- **为什么口服难?** 肽会被胃肠道消化,生物利用度极低——"钥匙在胃里就被嚼碎了";
- **非肽小分子（6ORV, TT-OAD2）**：小分子激动剂结合 TMD 胞外口袋（部分替代 N 端功能）——"不用钥匙头,直接拧锁芯";
- **6ORV 的发现**：TT-OAD2 伸出受体核心与脂质/去污剂互作 → 独特的激活动力学——"小分子有自己的'拧法'";
- **口服司美格鲁肽**：联合 SNAC（吸收增强剂）→ 口服可用——"给钥匙加'护盾'过胃";
- **未来**：口服小分子 GLP-1 激动剂（如 orforglipron, 礼来）——"彻底摆脱注射"。

### 4.3 双激动/三激动：GLP-1 之外

- **替尔泊肽（Tirzepatide）**：GLP-1/GIP 双受体激动——"两把钥匙,两个开关";
- **瑞他鲁肽（Retatrutide）**：GLP-1/GIP/GCG 三激动——"三个开关联动";
- **结构基础**：GIP 受体/GCG 受体与 GLP-1R 同属 B 类 GPCR,结构相似但口袋不同——"同一家族,不同锁芯"——多激动剂的设计需要"一把钥匙开多把锁"（嵌合肽设计）——"用嵌合肽的'混合齿形'开多个锁"。

## 5. GLP-1 与衰老：结构视角的"代谢抗衰"

### 5.1 代谢衰老与 GLP-1R

- **胰岛素抵抗随龄上升** → 代谢衰老（[03-metabolic-aging](../02-vascular/03-metabolic-aging.md)）→ 全身加速衰老;
- **GLP-1 分泌随龄下降**：老年 GLP-1 水平/敏感性下降——"吃饱的信号变弱";
- **GLP-1R 激活的"多器官获益"**：
  - 胰腺：促胰岛素（降糖）;
  - 肝脏：抑制糖异生（降糖）;
  - 胃：延缓排空（减重）;
  - 大脑：抑制食欲（减重）+ 可能的神经保护;
  - 心脏/血管：心血管保护（抗炎/改善内皮）;
  - 肾脏：保护肾功能。
- **"代谢抗衰"的逻辑**：肥胖/胰岛素抵抗驱动衰老（炎症、氧化、线粒体功能障碍）;GLP-1R 激活 → 减重+降糖+抗炎 → 打断代谢-衰老恶性循环——"修好代谢发动机,全身零件都受益"。

### 5.2 结构视角的"抗衰开关"再添一员

| 开关 | 触发 | 效应 | 衰老趋势 |
|---|---|---|---|
| GLP-1R | GLP-1（进食后） | 胰岛素↑/食欲↓/代谢修复 | 敏感性↓ |
| AMPK | 能量缺乏 | 分解代谢/自噬 | 活性↓ |
| mTOR | 营养充足 | 合成代谢/生长 | 过度激活 |
| FOXO3 | 营养缺乏/应激 | 生存程序 | 活性↓ |
| Nrf2 | 氧化应激 | 抗氧化 | 活性↓ |
| NF-κB | 炎症信号 | 炎症 | 活性↑ |

**"代谢开关群"的协调**：GLP-1R（饱食信号）、AMPK（能量饥饿信号）、mTOR（营养充足信号）、FOXO3（营养缺乏信号）——共同组成"代谢决策委员会"——**"GLP-1R 是'饱食'委员,AMPK/FOXO3 是'饥饿'委员,mTOR 是'生长'委员"**——衰老时委员会失衡（饱食信号钝、生长委员过度活跃）——"会议开歪了"。

### 5.20 "血糖-胰岛素-GLP-1"的三角：为什么 GLP-1R 是"聪明的降糖开关"

GLP-1R 最迷人的结构-生理特性是**"葡萄糖依赖的胰岛素分泌"**——血糖高时才促胰岛素,血糖正常/低时不促——"不把血糖降过头"。这个"聪明"的结构逻辑:

**GLP-1R 本身不感知血糖。** GLP-1R 只是"吃饱信号"的接收器——真正感知血糖的是 β 细胞的葡萄糖传感器（GLUT2/KATP 通道）——"GLP-1R 是'喇叭',葡萄糖是'油门'"。

**"油门+喇叭"的协同。** 高血糖时:葡萄糖代谢 → ATP↑ → KATP 关闭 → 膜去极化 → 胰岛素分泌（基础分泌）;GLP-1 激活 GLP-1R → cAMP/PKA → 增强分泌机制（放大分泌）——"血糖踩油门,GLP-1 加涡轮"。

**"低血糖保护"的结构-生理逻辑**：血糖正常/低时,葡萄糖代谢不提供"油门" → 即使 GLP-1 在,胰岛素分泌也不增加——"油门没踩,涡轮再大也不走"——这就是 GLP-1 类药物低血糖风险低的根本原因——"聪明开关:只在需要时加涡轮"。

**对比：磺脲类（传统降糖药）**：直接关闭 KATP 通道（不管血糖）→ 强制胰岛素分泌 → 低血糖风险高——"不踩油门也硬推车,容易翻车"。

**结构视角的抗衰启示**：GLP-1R 的设计哲学是"响应信号,不替代理性判断"——**"好的代谢干预不是绕过生理调控,而是放大生理调控的'正确部分'"**——这呼应 10-structures 专题反复出现的主题:"改外围、修负反馈、恢复节律"——"修开关,不是拆开关"。

### 5.3 "药 vs 生活方式"的结构思考

- **GLP-1 药物**：强力、直接、"外挂"——"给委员会配个强力新委员";
- **生活方式（饮食/运动）**：温和、间接、生理——"调整会议议程,让委员们自然归位";
- **结构启示**：GLP-1R 是"进食后"信号——**"药物模拟'吃好了'的信号,但生活方式（少吃/吃对）才是信号的自然来源"**——"药是拐杖,生活方式是腿"（呼应 [03-nutrition](../07-interventions/03-nutrition.md)）;
- **长期使用的问题**：停药反弹（食欲恢复）、肌肉流失（快速减重）、成本——"拐杖拿走,腿还没练好"。

## 7. 与知识库主线联系

### 7.0 "代谢抗衰"的主线闭环

10-structures 的代谢家族现在有五位成员——GLP-1R（饱食）、AMPK（饥饿）、mTOR（生长）、FOXO3（生存）、复合物 I（能量）:

**"代谢决策委员会"全景**：
- **进食后**：GLP-1R 激活（饱食信号）+ 胰岛素↑ → mTOR 开（合成）+ FOXO3 关——"吃饱了,长身体";
- **空腹/运动**：AMPK 激活（能量缺乏）→ mTOR 关 + FOXO3 开 + 复合物 I 效率调整——"饿了,修身体";
- **长期失衡**：持续过食 → mTOR 常开 + GLP-1R 钝化 + 胰岛素抵抗 → 代谢衰老——"委员会被'生长派'把持"。

**抗衰策略的结构逻辑**：恢复"饱食-饥饿"的节律（间歇性禁食/运动）→ 让 GLP-1R 恢复敏感 + AMPK/FOXO3 有上岗窗口——"让委员会重新开会,而不是被一派把持"。GLP-1 药物 = "外挂的饱食信号",生活方式 = "恢复内生节律"——**"最好的干预是恢复信号的自然节律,药物是节律恢复前的拐杖"**。

### 7.1 主线篇目对话

- **GLP-1 药物**（[08-glp1](../04-drugs/08-glp1.md)）：本篇是其结构底座——"从分子到药房";
- **二甲双胍/AMPK**（[07-metformin-ampk](../04-drugs/07-metformin-ampk.md)）：AMPK 与 GLP-1R 互补（饥饿 vs 饱食信号）——"一饿一饱,两个开关";
- **mTOR 结构**（[04-mtor-structure.md](04-mtor-structure.md)）：GLP-1R（饱食）→ 胰岛素 → mTOR——"饱食信号的下游是生长开关";
- **FOXO3 结构**（[16-foxo3-structure.md](16-foxo3-structure.md)）：GLP-1R 激活 → 胰岛素↑ → AKT → FOXO3 关——"饱食信号关生存程序";
- **代谢衰老**（[03-metabolic-aging](../02-vascular/03-metabolic-aging.md)）：GLP-1R 敏感性↓是代谢衰老的一环——"吃饱信号变钝,代谢衰老开始";
- **营养/禁食**（[03-nutrition](../07-interventions/03-nutrition.md)）：进食节律决定 GLP-1/胰岛素曲线——"怎么吃,决定开关怎么拨";
- **复合物 I**（[12-complex1-structure.md](12-complex1-structure.md)）：代谢修复 → 线粒体功能改善——"发动机修好,发电机也稳"。

## 8. 结构-衰老"五问"总结

| 问题 | 结构答案 |
|---|---|
| GLP-1R 怎么被激活？ | ECD 抓住 GLP-1 C 端（校准）,N 端插入 TMD（转锁芯）——两段式 |
| 为什么司美格鲁肽一周一次？ | 脂肪酸修饰 → 白蛋白结合 → 半衰期周级——"结构改造延长药效" |
| 偏倚激动怎么产生？ | 不同配体→不同 TMD 构象→Gs/β-arrestin 偏向（6° 差异） |
| 为什么 GLP-1 类药物"多器官获益"？ | GLP-1R 广布（胰/肝/胃/脑/心/肾）——"一个受体,多器官响应" |
| 怎么抗衰？ | 恢复进食节律（GLP-1R 敏感）+ 必要时药物辅助——"节律优先,药物拐杖" |

**五问之外的结构直觉**：GLP-1R 的故事揭示了"药物设计的终极问题"——**"我们到底是在'模拟生理',还是在'劫持生理'?"** 司美格鲁肽模拟 GLP-1（生理信号）→ "放大正确部分";但持续超生理剂量的激活,本质是"劫持饱食信号"——"用生理的钥匙,开超生理的门"。结构视角的清醒:**任何受体都不是孤立的开关,而是网络中的节点**——GLP-1R 激活的"多器官获益"背后,是"多器官副作用"的可能（恶心、肌肉流失、停药反弹）——"网络中的节点,牵一发动全身"。这提示:结构知识让我们"看得更清",也让我们"知道边界在哪"——**"最好的药物像最好的钥匙:开该开的门,不碰不该碰的门"**。

### 9.1 "代谢抗衰"的完整图景：17 篇结构的网络视角

GLP-1R 是 10-structures 专题第 17 篇,也是"代谢调控"系列的收官——现在可以画一张完整的"代谢-衰老结构网络":

**能量流**：复合物 I（[12-complex1-structure.md](12-complex1-structure.md)）产 ATP（发电）→ AMPK（[03-ampk-structure.md](03-ampk-structure.md)）感知能量（电表）→ mTOR（[04-mtor-structure.md](04-mtor-structure.md)）决定生长（油门）→ FOXO3（[16-foxo3-structure.md](16-foxo3-structure.md)）决定生存（刹车）→ GLP-1R（[17-glp1r-structure.md](17-glp1r-structure.md)）感知饱食（油箱表）——**"从发电到耗电,从吃饱到生存,一张图串起"**。

**NAD⁺ 流**：NAMPT（[10-nampt-structure.md](10-nampt-structure.md)）合成（造币）→ SIRT1（[06-sirt1-structure.md](06-sirt1-structure.md)）消耗（花钱）→ CD38/PARP1（[08-cd38-structure.md](08-cd38-structure.md)/[09-parp1-structure.md](09-parp1-structure.md)）竞争（抢钱）——"NAD⁺ 经济的四端闭环"。

**信号流**：NOS/sGC（[01-nos-structures.md](01-nos-structures.md)/[02-sgc-heme.md](02-sgc-heme.md)）NO 信号（信使）→ 炎症/抗氧化开关（[14-nfkb-structure.md](14-nfkb-structure.md)/[15-nrf2-structure.md](15-nrf2-structure.md)）→ 细胞命运（[13-p53-structure.md](13-p53-structure.md)）——"从信使到命运"。

**信息流**：TET/DNMT1（[05-tet-dna.md](05-tet-dna.md)/[07-dnmt1-structure.md](07-dnmt1-structure.md)）表观写入/擦除 → SIRT1 表观调音 → 端粒（[11-telomerase-structure.md](11-telomerase-structure.md)）时钟——"信息老化的一条链"。

**"结构网络"的方法论启示**：17 篇合读,看到的不是 17 个孤立的分子,而是一张**"代谢-信号-表观-命运"的四层网络**——**"衰老不是单一分子坏了,而是网络失衡了"**——抗衰策略也因此清晰:不针对单一靶点"死磕",而是**"恢复网络的动态平衡"**（节律、适度、多靶点）——"修网络,不修单点"。这也正是知识库"机制全链条/系统视角"理念在分子结构层面的完整落地——"从原子到网络,层层有据,环环相扣"。
