# 分子结构深潜 44：sEH（可溶性环氧化物水解酶）——"EET 经济的回收站"与血管保护的水闸

> **专题定位**：10-structures（分子结构深潜）第 44 篇——解剖可溶性环氧化物水解酶（sEH/EPHX2）的三维结构,理解"sEH 怎么把保护性 EET（环氧二十碳三烯酸）水解失活"、"尿素类抑制剂怎么堵住它",以及它在"AA 第三路（CYP→EET）-心血管保护-抗炎-衰老"中的"回收站"角色。cPLA2α（[43-cpla2.md](43-cpla2.md)）是"AA 总阀",LOX（[40-lox.md](40-lox.md)）/COX-2（[42-cox2.md](42-cox2.md)）是"炎症分路",而 sEH 是"保护分路（EET）的闸门"——抑制 sEH = 保护 EET = 护心血管/抗炎/降压,是"AA 经济"的"保护侧"收官。

## 1. 为什么重要：sEH 是"EET 经济"的回收站

sEH（EPHX2）是"可溶性环氧化物水解酶"——"EET（保护性脂质介质）'降解'的'总闸'":

- **"'EET 的'守护者'"**：AA 经 CYP 450 环氧酶 → EET（11,12-/14,15-EET 等）→ 扩血管/抗炎/抗血小板/促纤溶（保护性）——"第三路'产'保护'介质'（EET）——'护'心血管'信号'";
- **"'EET 的'降解'"**：sEH 把 EET 水解 → 邻二醇（DHET）→ EET 失活（保护消失）——"回收站'吞'保护'介质'（EET→DHET）——'闸门'关'保护'";
- **"'sEH 抑制'的'策略'"**：sEH 抑制剂（AUDA/TPPU 等）→ EET 升高 → 降压/抗炎/护心/镇痛（动物模型）→ "抗衰'新'靶点"——"关'回收站' → 保护'介质'（EET）'留住' → 心血管'获益'——'闸门'策略";
- **"'衰老'的'关联'"**：sEH 活性随龄/疾病↑（高血压/糖尿病）→ EET↓ → 血管/炎症失衡 → 衰老加速——"回收站'越收越猛'（sEH↑）→ 保护'越少'（EET↓）→ '血管衰老'——'闸门'失衡";
- **"'完整'的'AA 经济'"**：cPLA2α（总阀）→ LOX/COX（炎症路）+ CYP（保护路）→ sEH（保护路闸门）——"AA '三路' + '保护闸'——'经济'闭环（44 篇收官'AA 经济'）";

**"'与知识库'的'衔接'"**：sEH 是"AA 代谢网络"（[43-cpla2.md](43-cpla2.md) 总阀/[40-lox.md](40-lox.md)/[42-cox2.md](42-cox2.md) 炎症路）的"保护路闸门"——"知识库'脂质-血管'链条'补全'（保护路 CYP→EET→sEH 闸门）——44 篇把'AA 经济'叙事'完整闭环'"——"'炎症-保护'双面的'完整'结构叙事'收官'";

**结构速览（3I28/1VJ5, 人 sEH）**：sEH 是"同源二聚体"（域交换）——"N 端磷酸酶域（Mg²⁺, 功能未明）+ C 端环氧化物水解域（催化, α/β 水解酶折叠）"——"双域'二聚'（域交换, 互相'抱'）——C 端'水解'主'责'（EET）——活性位'Asp333 催化 + Tyr381/465 质子供体'——'深疏水通道'（容 EET）——尿素类抑制剂'卡'通道'（模拟过渡态）——'回收站'的'图纸'清楚"。

**"'双域'的'进化'猜想"**：sEH 的"水解酶域+磷酸酶域"融合 → "进化'拼装'（两酶'合体'）——'多任务'酶'进化'（融合基因）——'结构'看'进化'（域融合史）——'兼职'是'进化'的'偶然+选择'"。

**核心调控机制**：

```text
sEH 的"EET 回收-血管保护"链路:
  AA(cPLA2α 释放) → CYP450 环氧酶 → EET(保护性: 扩血管/抗炎/抗血小板)
       │
  sEH(EPHX2):  EET + H2O → DHET(失活)  [回收站]
       │
  保护:  EET↑ → 血管舒张/血压↓/炎症↓/血栓↓/纤溶↑
       │
  衰老:  sEH 活性↑(随龄/高血压/糖尿病) → EET↓ → 血管僵硬/血压↑/炎症↑
       │
  策略:  sEH 抑制剂(AUDA/TPPU) → EET↑ → 降压/抗炎/护心/抗衰(动物证据)
```

**一句话记忆**：sEH 是"EET 经济的回收站"——把保护性 EET 水解成失活的 DHET——"CYP 产'保护'（EET）→ sEH '回收'（水解失活）→ 保护'消失'——关'回收站'（sEH 抑制剂）→ EET '留住' → 扩血管/降压/抗炎——'保护闸门'——AA 经济'三路'（LOX 炎/COX 炎/CYP 护）+'回收站'（sEH）——'完整'闭环"。

## 2. 结构解剖：3I28/1VJ5 的"回收站"长什么样

### 2.0 一个原子一个原子地看：sEH 怎么"回收"EET

- **"'水解'的'化学'"**：sEH 把 EET 的"环氧环"（三元氧环）水解开 → 邻二醇（DHET）→ EET 失活——"环氧'开环'（水解）→ 二醇'产物'（DHET）——'回收'的'化学'";
- **"'催化'的'机制'"**：Asp333 亲核进攻环氧碳 → 烷基-酶中间体 → Tyr381/465 供质子 → 水水解 → 二醇释放——"Asp333 '进攻'（亲核）→ 中间体 → Tyr '供氢'（质子）→ '开环'——'三步'水解";
- **"'过渡态'的'稳定'"**：Tyr381/465 与底物环氧氧"氢键"→ 稳定过渡态 → 加速水解——"Tyr '氢键'稳住'过渡态' → 反应'加速'——'酶'的'催化'艺术";

**"'水解'的'产物'（DHET）"**：DHET（邻二醇）是"活性低"的代谢物 → 排出/再代谢 → EET 保护"终结"——"回收'产物'（DHET）'低活' → 保护'结束'——'回收站'的'产出'（失活物）";

**"'EET 的'来源'限制"**：CYP 环氧酶产 EET 是"限速"（sEH 只'回收'已'产出'的）→ 抑制 sEH "保" 而非"产"——"回收站'只'回收'（不产 EET）→ 关站'保'存量'（EET 半衰期↑）——'保存'策略（非'增产'）";

### 2.1 结构总览：双域二聚体的"分工"

- **"'C 端域'（催化, 主责）"**：α/β 水解酶折叠（中央 β-片+螺旋）→ 活性位（Asp333/Tyr381/465）→ 水解 EET——"C 端'水解'（主刀）——'回收'主力";
- **"'N 端域'（磷酸酶, 副业）"**：Mg²⁺ 依赖磷酸酶活性（水解磷酸酯）→ 生物学功能"未明"——"N 端'磷酸酶'（副业）——'兼职'（功能未明）";
- **"'域交换'的'二聚'"**：两个亚基"互相交换"N 端域 → 同源二聚体"锁扣"结构——"两个'人'互相'抱'（域交换）→ 二聚体'锁扣'——'交换'稳定'整体'";

**"'C 端域'的'细节'"**：1VJ5 显示 C 端域"α/β 水解酶折叠"（中央 β-片 + 周围 α-螺旋）+ 活性位"深通道"（Asp333/Tyr381/465）→ EET 水解——"β-片'骨架' + 螺旋'围墙' → 深通道'藏'活性位（Asp333）——'回收'的'厂房'";

**"'N 端域'的'细节'"**：N 端域含"Mg²⁺ 结合位"（磷酸酶活性）→ 15 Å 深裂缝（底物结合?）→ 功能未明——"Mg²⁺ '位'（磷酸酶）+ 深裂缝'（15 Å）→ '兼职'的'秘密'——'功能'待解"。

### 2.2 两个域的"结构对照"

| 域 | 位置 | 活性 | 功能 | 锚点 |
|---|---|---|---|---|
| C 端域 | 大（~350 残基） | 环氧化物水解 | EET→DHET（主责） | 3I28/1VJ5 |
| N 端域 | 小（~220 残基） | 磷酸酶（Mg²⁺） | 功能未明（副业） | 1VJ5 |

**"结构'启示'"**：sEH 是"双功能'兼职'酶"（水解酶+磷酸酶）——"一个'酶'两'活'（水解/磷酸酶）——'主'责'清楚'（EET 水解）, '副'业'待解'（磷酸酶功能）——'进化'的'拼凑'（域融合）——'结构'揭示'兼职'（N 端'意外'活性）";

**"'域交换'的'稳定性'"**：域交换二聚体"互锁"→ 比"面贴面"更"稳定"（抗解聚）→ 酶活性"持久"——"锁扣'比'贴面'稳（域交换）→ 酶'长寿'——'组装'影响'稳定性'——'二聚'的'策略'差异";

**"'抑制剂'的'选择性'"**：尿素类抑制剂对 sEH "高选择性"（vs 其他水解酶）→ 深通道+催化残基"特异"识别——"钥匙'只'开'回收站'（尿素类高选择）→ 副作用'小'——'选择性'的'结构'基础（深通道特异）"。

## 3. "EET→DHET"的分子逻辑：从结构到化学

### 3.0 一个原子一个原子地看：EET 怎么被"吞掉"

- **"'底物'的'形状'"**：EET（C20 环氧脂肪酸）→ 长链 + 环氧环（C11,12-/14,15 位）→ 疏水"长条"——"燃料'长条'（C20 环氧）——'疏水'长链";
- **"'通道'的'容纳'"**：sEH 活性位"深疏水通道"（~15 Å）→ 容纳 EET 长链（环氧环"对准"Asp333）——"深通道'吞'长条'（EET）→ 环氧'对准'Asp333——'形状'契合";
- **"'选择性'的'来源'"**：通道"疏水内衬"偏好"环氧脂肪酸"（EET 类）→ 其他底物"不友好"——"通道'挑'（疏水内衬）→ 环氧脂肪酸'优先'——'选择'（主要回收 EET）";

**"'区域'选择性'的'细节'"**：sEH 对 14,15-EET 偏好（>11,12->8,9-）→ 通道几何"适配"不同环氧位——"回收站'挑'位置（14,15 优先）→ 通道'几何'决定——'区域'选择（异构体偏好）";

**"'其他'环氧'底物'"**：sEH 也水解"环氧脂肪酸"（leukotoxin 等）→ 底物谱"广"→ "不止" EET——"回收站'收'多'种'环氧'（不止 EET）——'广谱'回收——'功能'不止'血管'"。

### 3.1 "尿素类抑制剂的'卡位'：怎么堵住回收站"

- **"'尿素'的'模仿'"**：尿素类抑制剂（AUDA/CIU/TPPU）的"尿素羰基"模拟 EET 环氧的"过渡态"→ 结合活性位——"抑制剂'模仿'过渡态'（尿素=环氧）→ '骗'过酶——'假底物'策略";
- **"'氢键'的'锚定'"**：抑制剂尿素羰基与 Tyr381/465"氢键"（同底物过渡态）→ 牢固结合 → 卡住通道——"Tyr '氢键'锁'抑制剂'（同催化）→ 卡'通道'——'锁死'回收站";
- **"'1VJ5 的'证据'"**：CIU（N-环己基-N'-碘苯基脲）结合人 sEH（2.35 Å）→ 尿素羰基与 Tyr381/465 氢键"清晰"→ 堵活性位——"结构'实拍'：CIU '卡'在活性位（Tyr 氢键）——'堵'回收站'的'原子'证据——'设计'更'强'抑制剂（3I28 优化）'基础'";

### 3.2 "sEH 与 LOX/COX/CYP 的'三路'：保护 vs 炎症"

- **"'炎症'路（LOX/COX）"**：AA → 白三烯（[40-lox.md](40-lox.md)）/前列腺素（[42-cox2.md](42-cox2.md)）→ 促炎——"两路'火'（LOX/COX）";
- **"'保护'路（CYP→EET）"**：AA → EET → 扩血管/抗炎——"一路'水'（CYP/EET）";
- **"'平衡'的'关键'"**：sEH 抑制 → EET↑（保护）→ 与 LOX/COX 炎症路"对抗"→ "平衡"倾斜保护侧——"关'回收站'（sEH↓）→ 保护'水'多（EET↑）→ 浇'火'（抗炎）——'三路'平衡'移'保护——'完整'AA 经济'策略'";

**"'三路'的'跷跷板'"**：抑 LOX/COX（炎症路）→ AA 更多"流向"CYP（保护路）→ EET↑;而 sEH 抑制"保" EET → "双管齐下"效果叠加——"灭火'路'（LOX/COX↓）→ AA '分流'保护'（CYP↑）→ EET↑ + 关站'保'EET——'协同'放大——'三路'跷跷板'利用'";

**"'AA 经济'的'完整'图景"**：cPLA2α（总阀）→ LOX（白三烯）/COX（前列腺素）[炎症] + CYP（EET）[保护] → sEH（闸门）→ "一阀'三路'一'闸'——'收支'平衡——'抗衰' = 调'阀'（适度）+ 灭'火'（炎症）+ 护'水'（EET）——'完整'经济'管理'——'闭环'思维"。

## 4. sEH 与衰老：结构视角的"过度回收"

### 4.1 sEH 的衰老/疾病证据

- **"sEH 活性随龄/疾病↑"**：高血压/糖尿病/肥胖 → sEH 表达/活性↑ → EET↓ → 血管/代谢失衡——"回收站'超载'（疾病 sEH↑）→ 保护'枯竭'（EET↓）——'血管衰老'关联";
- **"'高血压'"**：sEH 抑制 → EET↑ → 血管舒张 → 降压（多种动物模型）→ sEH 抑制剂"降压"证据——"关回收站'降压'（EET 扩血管）——'血压'调控'新'策略";
- **"'动脉粥样硬化/心衰'"**：sEH 抑制 → EET↑ → 抗炎/抗增殖 → 抗粥样硬化/护心（动物）→ 心衰保护——"回收站'关' → 保护'多'（EET 抗炎/护心）——'心血管'获益";
- **"'慢性炎症/疼痛'"**：sEH 抑制 → EET↑ → 抗炎（NF-κB↓/巨噬细胞↓）/镇痛（动物）→ 炎症/疼痛"缓解"——"保护'介质'（EET）抗炎'镇痛'——'回收站'抑制'双'获益";

**"'肾'保护"**：sEH 抑制 → EET↑ → 肾血流↑/蛋白尿↓（糖尿病肾病模型）→ "肾"保护——"关站'护肾'（EET 扩肾血管）——'肾'病'新'策略（糖尿病肾病）";

**"'肺'与'肝'"**：sEH 抑制 → EET↑ → 肺高压↓/肝纤维化↓（模型）→ 多器官"保护"——"关站'多'器官'保护'（肺/肝）——'EET'广谱'获益——'回收站'抑制'多效'"。

### 4.2 "sEH 的'抗衰'启示"

- **"'关回收站'的策略"**：sEH 抑制剂（TPPU 等, 临床前/早期临床）→ EET↑ → 降压/抗炎/护心 → 抗衰"潜力"——"关'回收站'（sEH 抑制剂）→ 保护'留住'（EET↑）→ '血管-炎症'双获益——'抗衰'新'方向'";
- **"'与炎症路'的'联合'"**：sEH 抑制（保护路↑）+ LOX/COX 抑制（炎症路↓）→ "双向'倾斜'"→ 抗炎更"全面"——"关回收站'（EET↑）+ 灭炎症路（LOX/COX↓）→ '双管'倾斜'保护'——'组合'策略'前景'";
- **"'生活方式'的'调节'"**：运动/omega-3 等 → 影响 EET/sEH 通路 → 间接"保护"——"运动'调'回收站'（间接）→ 保护'多'——'生活方式-酶'联动";

**"'omega-3'的'新'底物'"**：omega-3（EPA/DHA）经 CYP → 环氧 EPA/DHA（也保护性）→ sEH 也水解 → 抑制 sEH "保" 更多"保护介质"——"换'燃料'（omega-3 → 环氧 EPA/DHA）→ 关站'保'更多'（保护介质谱↑）——'膳食+药物'协同";

**"'sEH 抑制剂'的'现状'"**：TPPU 等进入临床前/早期临床（高血压/糖尿病肾病/疼痛）→ "人体"数据初现——"关站'药'（TPPU）'临床试'（高血压/肾病）→ '早期'数据——'前景'可期'但'待证"。

### 4.3 "sEH 的'双刃'：保护 vs 过度"

**"'保护'面"**：EET 扩血管/抗炎/抗血小板 → 心血管保护 → sEH 抑制"获益"——"保护'介质'（EET）→ '心血管'获益——关回收站'利好'";

**"'过度'面"**：EET 过高/长期抑制 → 影响"正常"血管功能（低血压？出血风险？抗血小板过度？）→ 安全性"待查"——"保护'过头'（EET 过高）→ 低血压/出血'风险'——'过度'的'担忧'";

**"'平衡'的'智慧'"**：适度 sEH 抑制（部分/间歇）→ EET 升高"恰到好处" → 保护"不伤"——"关回收站'适度'（部分抑制）→ 保护'足'不'过'——'剂量'艺术——'平衡'（保护 vs 安全）是'核心'";

**"'个体'的'差异'"**：sEH 基因多态（EPHX2 变异）→ 酶活性差异 → 个体"响应"不同——"回收站'效率'因人'异'（基因多态）→ 关站'效果'不同——'个体化'用药'前景'——'精准'关站";

**"'监测'的'工具'"**：血浆 EET/DHET 比值（sEH 活性"指纹"）→ 抗衰"监测"——"测'回收'率'（EET/DHET 比）→ 关站'效果'可见——'液体活检'（脂质组学）——'精准'干预'工具'"。

### 5.1 补充：sEH 研究的"时间线"

**"'1980s: sEH '发现'"**：可溶性环氧化物水解酶被鉴定（催化 EET 水解）→ "回收站'被发现'——'EET 失活'酶";

**"'2000-2010: 抑制剂'开发'"**：尿素类抑制剂（AUDA/CIU, 1VJ5 2005）优化（3I28 2009）→ 高效"关站"工具——"关站'药'（尿素类）——'强力'回收站'刹车'";

**"'2010-: 临床'推进'"**：TPPU 等进入临床前/早期临床（高血压/糖尿病肾病）→ "关站'疗法'（人）——'保护' EET '策略'迈向'临床'";

**"'2010s: 抗衰'关联'"**：sEH 在"衰老病"（高血压/动脉粥样硬化/阿尔茨海默）中的角色 → "回收站'超载'与'衰老病'——'关站'抗衰'证据'积累";

**"'2020s: 多'领域'扩展'"**：sEH 抑制在疼痛/神经保护/代谢/COVID 相关炎症等"扩展"研究 → "关站'多效'——'EET 保护'谱'扩大'——'回收站'靶点'升温'"。

## 7. 五问速答

| 问题 | 回答 |
|---|---|
| 谁？ | sEH（EPHX2）——可溶性环氧化物水解酶, 双域二聚体 |
| 干什么？ | EET + H2O → DHET（水解失活保护性 EET） |
| 怎么干？ | Asp333 亲核 + Tyr381/465 质子供体, 深疏水通道 |
| 为什么相关？ | sEH↑ → EET↓ → 高血压/炎症/血管衰老;sEH 抑制 → 保护 |
| 怎么干预？ | sEH 抑制剂（TPPU 等）+ 炎症路联合 + 适度平衡 |

**五问之外的结构直觉**：sEH 的故事揭示了"保护'介质'的'珍惜'"——**"'身体'产'保护'（EET）也不断'回收'（sEH）——'回收'太猛（sEH↑）→ 保护'枯竭'（EET↓）→ 疾病/衰老——所以'抗衰'要'珍惜'保护'介质'（关回收站）——这与'炎症'侧（LOX/COX）'灭火'互补——'AA 经济'的'完整'智慧：既'灭火'（炎症路）又'护水'（EET 路）——结构研究把'回收站'的'图纸'（Asp333/Tyr 催化 + 深通道 + 尿素卡位）看得一清二楚——'关站'的'钥匙'（抑制剂）'原子级'设计**"。抗衰启示: ①适度 sEH 抑制（EET↑）——"关站护水";②炎症路抑制（LOX/COX）——"双路灭火";③运动/omega-3（护 EET）——"生活护水";④平衡（剂量/安全）——"适度为王"。

**"'结构直觉'的'补充'二"**：sEH 的"尿素类抑制剂"是"过渡态模拟"的"教科书"——"抑制剂'长得像'反应的'过渡态'（尿素=环氧四面体中间体）→ '骗'过酶'高效'结合——'过渡态模拟'是'酶抑制'的'黄金'策略（不止 sEH: 蛋白酶抑制剂等）——'结构'揭示'过渡态'形状（Tyr 氢键锚点）→ '设计'更'像'的'钥匙'——'理性药物设计'的'典范'——'过渡态'是'酶的'软肋'——'模仿'即'制服'"。

**"'结构直觉'的'补充'三"**：sEH 的故事还揭示"'回收'的'生理'意义"——"'酶'不'白'存在：sEH '回收'EET 是'调节'（防止'过度'保护/维持'稳态'）——'回收'不是'坏', '过度回收'才'坏'——'平衡'的'酶学'视角——'抗衰'不是'完全'关站, 而是'调'到'合适'水平——'适度'是'酶学'的'智慧'——'回收站'也要'留'一'手'——'过犹不及', '酶学'亦然"。

## 8. 结构研究的关键问题与展望

**结构研究的三个关键问题**：
1. EET 怎么"进通道"并"对准"Asp333（底物识别）？
2. 尿素类抑制剂的"优化"空间（更强/更选择性, 3I28 基础）？
3. N 端磷酸酶域的"真实"功能（副业之谜）？

这些问题在 1VJ5（CIU 结合, 2.35 Å）/3I28（1.95 Å）等结构中得到回答——"两个 PDB, 一个'回收站'——'催化'（Asp333/Tyr）'卡位'（尿素）'看清'——'关站'的'原子'地图'完成'——'N 端'谜'待'解——'结构'奠基'药物'"。

**"'1VJ5 vs 3I28'的'互补'"**：1VJ5（含 CIU 抑制剂, 2.35 Å）给"卡位"细节;3I28（1.95 Å, 高分辨）给"整体"精度 → "一个'卡位'（1VJ5）+ 一个'高清'（3I28）→ '回收站'结构'双证'——'抑制剂设计'的'双基'（结合模式+高精度）"。

**未来方向**：
- 全长/膜结合态 sEH 结构（动态）;
- N 端磷酸酶功能的"结构-功能"破解;
- 更优 sEH 抑制剂（选择性/长效）的"理性设计";
- sEH 抑制 + 炎症路抑制的"组合"临床研究;
- "衰老动物"中 sEH 抑制的"直接"抗衰试验;

**"'组合'疗法的'前景'"**：sEH 抑制（EET↑）+ COX-2/LOX 抑制（炎症↓）+ 降压药 → "心血管-炎症"多靶方案——"关站'护水' + 灭火'炎症' + 降压'血管'——'多靶'组合——'心血管抗衰'综合'策略'";

**"'生物标志物'的'应用'"**：血浆 EET/DHET 比值 + 炎症标志物 → 抗衰"评估/监测"——"测'回收率'（EET/DHET）+ '炎症'（CRP）→ 抗衰'画像'——'精准'干预'导航'——'组学'驱动'抗衰'"。

**"'抗衰处方'总结"**：①适度 sEH 抑制（EET↑）——"关站护水";②炎症路抑制（LOX/COX, [40-lox.md](40-lox.md)/[42-cox2.md](42-cox2.md)）——"双路灭火";③运动/omega-3（护 EET）——"生活护水";④平衡（剂量/安全）——"适度为王"——"'四管齐下'：关站+灭火+护水+平衡——'AA 经济'完整管理——'保护闸门'（sEH）是 44 篇结构知识给'脂质-血管'的'收官智慧'——关站'护水', '回收'有'度'——'完整'的'AA 经济'收官——'一阀三路一闸', '收支'定'炎衰'——'护水'即'护'寿"。

**"'收官'寄语"**：44 篇 sEH 让"AA 经济"叙事结构级完整闭环——"从 cPLA2α（43 总阀）、LOX（40）/COX-2（42）炎症路到 sEH（44 保护闸）——'脂质-血管'的'炎症-保护'双面完整叙事完成——'回收站'（sEH）的'图纸'（Asp333/Tyr）'关站'的'钥匙'（尿素类抑制剂）——'保护闸门'是核心智慧——'结构级'收官——'灭火'（炎症路）+ '护水'（EET 路）的'平衡', 是'脂质抗衰'的'完整'之道——'一阀三路一闸', '平衡'定'衰'——'护水'即'护'生命——'回收'有'度'是'长寿'之'门'——'闸门'的'终章'——'护水'之'道'，'平衡'之'魂'"。
