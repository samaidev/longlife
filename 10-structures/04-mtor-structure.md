# 分子结构深潜 04：mTORC1——被"深埋活性位点"门控的生长总开关

> **专题定位**：10-structures（分子结构深潜）第 4 篇——解剖 mTORC1 的三维结构，理解"雷帕霉素如何抑制它"与"活性位点为何深埋"。这是知识库营养感应主线（[04-drugs/06-mtor-rapamycin.md](../04-drugs/06-mtor-rapamycin.md)）的结构基础，也是理解雷帕霉素抗衰机制（[09-immortality/02-breakthrough-candidates.md](../09-immortality/02-breakthrough-candidates.md) 中 27/40 分）的原子级视角。
> **关联篇目**：mTOR 通路见 [06-mtor-rapamycin](../04-drugs/06-mtor-rapamycin.md)；AMPK 结构见本专题 [03-ampk-structure.md](03-ampk-structure.md)；雷帕霉素延寿证据见 [06-mtor-rapamycin](../04-drugs/06-mtor-rapamycin.md) 第 4 节。

## 1. 核心概念：一个"藏在壳里的激酶"

mTOR（雷帕霉素靶蛋白）是 PIKK 家族（磷脂酰肌醇 3-激酶相关激酶）的丝氨酸/苏氨酸激酶（289 kDa），其结构设计围绕一个核心矛盾：**它必须感知大量上游信号（营养、能量、生长因子）并磷酸化多个底物，但它的催化活性位点却被"深埋"在蛋白内部**——这是 mTORC1 结构最独特的特征。

**"深埋活性位点"的意义**：

1. **限制底物进入**：不是所有蛋白都能接近活性位点——只有被 Raptor 正确"呈递"的底物（含 TOS 基序）才能进入；
2. **雷帕霉素的抑制逻辑**：FKBP12-雷帕霉素复合物结合在 FRB 域（活性位点"门口"），物理上挡住底物进入——"堵门"而非"堵酶"；
3. **激活突变的机制**：mTOR 激活突变（癌症相关）多位于"hold 住这些门控元件"的结构框架上——突变让"门"更易打开，而非直接增强催化。

## 2. 整体架构：mTORC1 复合物的组装

### 2.1 核心组成

| 亚基 | 功能 | 结构角色 |
|---|---|---|
| mTOR | 催化（PIKK 家族激酶） | 核心酶 + 支架 |
| Raptor | 底物识别（TOS 基序） | 底物呈递 + 支架 |
| mLST8（GβL） | 稳定催化域 | 与 mTOR 激酶域结合 |
| DEPTOR | 内源抑制 | 结合 mTOR，抑制活性 |
| PRAS40 | 内源抑制（底物竞争） | 结合 Raptor，竞争底物 |
| TTI1/TEL2 | 组装/稳定 | 复合物装配 |

### 2.2 整体形态（PDB 5FLC，5.9 Å cryo-EM）

mTORC1 呈"菱形/月牙"状二聚体架构：

```text
           ┌── 二聚体界面 ──┐
      mTOR(单体1)         mTOR(单体2)
      │    │              │    │
   Raptor(1)             Raptor(2)
      │                      │
    mLST8(1)               mLST8(2)
           └── 中央腔（含活性位点）──┘
```

- **mTOR 激酶域**位于复合物中央，两个单体的激酶域面对面形成**中央二聚体腔**；
- **Raptor** 像"手臂"一样环绕，其 N 端结构域（NTD）紧邻激酶活性位点——承担底物识别与呈递；
- **mLST8** 结合在激酶域的 C 叶（稳定催化构象）；
- **活性位点深埋**在中央腔深处，只有一条"通道"通往表面——这条通道就是底物和雷帕霉素的战场。

## 3. 激酶域结构：与经典激酶惊人相似的催化核心

### 3.1 催化残基（PDB 4JSN，3.2 Å）

**PDB 4JSN**（Yang 2013，*Nature*）是截短 mTOR（ΔN）+ mLST8 与 ATP 过渡态类似物（AMP-PNP）的共晶结构，揭示：

- **催化残基**：mTOR 的激酶域含经典三联催化残基——**Asp2338（催化碱基）、Asp2357（Mg²⁺ 配位）、His2340**，与蛋白激酶 A（PKA）的催化机制几乎一致（"催化机制与经典激酶惊人相似"——论文原文）；
- **ATP 结合**：腺嘌呤深埋于疏水口袋，磷酸基与 Mg²⁺/Lys 配位；
- **"内在活性构象"**：mTOR 激酶域处于**组成性活性构象**（不像许多激酶需要磷酸化激活环）——它的调控主要靠"门控"而非"开关"。

### 3.2 FRB 域：活性位点的"门卫"

**FRB（FKBP12-Rapamycin Binding）域**是 mTOR 上 ~100 aa 的插入结构域，位于激酶域表面、活性位点裂隙的"入口"处：

- **FRB 域像一个"门卫"**：它覆盖在活性位点裂隙上方，限制底物接近；
- **底物进入需要 FRB 配合**：FRB 的 rapamycin 结合位点本身参与底物对接——"FRB 域与底物相互作用以授予它们进入受限活性位点的权限"（Yang 2013）；
- **雷帕霉素的"钥匙"**：FKBP12-雷帕霉素复合物结合 FRB 域后，既直接阻断底物招募，又进一步压缩活性位点入口——**"雷帕霉素不是堵住催化口袋，而是堵住底物的门"**。

## 4. 雷帕霉素的抑制机制：原子级解读

### 4.1 FKBP12-雷帕霉素复合物的形成

雷帕霉素（大环内酯）在胞内先结合 **FKBP12**（FK506 结合蛋白 12，肽基脯氨酸异构酶），形成 FKBP12-雷帕霉素复合物——该复合物才是真正的"抑制剂"：

```text
雷帕霉素 ──(结合)──► FKBP12 ──► FKBP12-雷帕霉素复合物
                                      │
                                      ▼
                          结合 mTOR 的 FRB 域
                                      │
                                      ▼
              底物(S6K1/4E-BP1)无法接近活性位点
              + 活性位点入口进一步受限
                                      │
                                      ▼
                          mTORC1 激酶活性被抑制
```

### 4.1a 为什么雷帕霉素要"借道"FKBP12：前药策略的结构逻辑

一个常被忽略的结构问题：**雷帕霉素为什么不直接结合 mTOR，而要先生成 FKBP12-雷帕霉素复合物？** 答案藏在化学里：

**第一，结合面太小**。雷帕霉素（分子量 914 Da）单独与 FRB 域的接触面不足以形成高亲和结合——它需要 FKBP12 这个"扩音器"。FKBP12 本身是一个小蛋白（12 kDa），其疏水口袋（脯氨酸异构酶活性位点）恰好能容纳雷帕霉素的哌啶环；形成的 FKBP12-雷帕霉素复合物拥有**比雷帕霉素单分子大得多的结合表面**（雷帕霉素的三烯链 + FKBP12 的疏水面共同与 FRB 域作用），结合亲和力因此提升数个数量级——"复合物才有资格敲门"。

**第二，"夹心"式结合**。晶体结构显示雷帕霉素以"三明治"方式被夹在 FKBP12 与 FRB 域之间：雷帕霉素的哌啶酸环嵌进 FKBP12 的口袋，三烯链伸展嵌入 FRB 域的疏水裂隙——**雷帕霉素不是"配体"，而是两个蛋白之间的"胶水"**。这种"分子胶"（molecular glue）机制后来成为 PROTAC 等降解剂设计的灵感来源。

**第三，天然产物的进化智慧**。雷帕霉素由吸水链霉菌产生（放线菌的次级代谢物）——它天然就是"分子胶水"：链霉菌用它同时结合宿主 FKBP12 类似物与 TOR，抑制宿主生长（抗菌/抗真菌）。**"借道宿主蛋白实现高亲和抑制"是天然产物进化的精妙策略**，人类只是把它从抗生素改造成了免疫抑制剂、抗癌药与抗衰候选药。

**为什么 FRB 域突变（Ser2035Ile）导致耐药**：FRB 域的保守残基（Ser2035、Trp2101 等）构成雷帕霉素三烯链的结合槽；突变改变槽的几何，使 FKBP12-雷帕霉素复合物"扣不上"——"钥匙还在，锁芯换了"。

### 4.2 结合界面的原子细节（5FLC cryo-EM + 4JSN 晶体）

- **FKBP12-雷帕霉素结合在 FRB 域的一个疏水口袋**（FRB 域的 rapamycin 结合位点，含保守残基 Ser2035、Trp2101 等）；
- 雷帕霉素的**三烯链**嵌入 FRB 疏水裂隙，**哌啶酸环**与 FKBP12 相互作用——"三明治"式结合（雷帕霉素夹在 FKBP12 与 FRB 之间）；
- 结合后，FRB 域的构象"锁定"，**底物结合通道被物理封堵**；
- **变构而非竞争**：雷帕霉素不占据 ATP 口袋（那是 ATP 竞争型抑制剂如 Torin1 的位点）——所以它是"变构抑制"（堵门），Torin1 是"正构抑制"（堵口袋）。

### 4.3 为什么 4E-BP1 对雷帕霉素"部分抵抗"

这是雷帕霉素临床应用的关键结构细节：**雷帕霉素对 S6K1 的抑制完全，但对 4E-BP1 的抑制不完全**（4E-BP1 部分抵抗）：

- 4E-BP1 与 mTOR 的结合部分依赖 TOS 基序（Raptor 识别），但其磷酸化位点（Thr37/46、Ser65、Thr70）的空间位置使其在 FRB 被占据时仍能部分接近活性位点；
- 结构解释：4E-BP1 的底物结合模式与 S6K1 不同——4E-BP1 更"顽固"地抓住 mTOR，即使门被堵也能"挤"进去一部分；
- **功能意义**：雷帕霉素"不完全抑制 4E-BP1"解释了为何雷帕霉素是"部分 mTORC1 抑制"——这在抗衰中可能是优点（保留部分翻译功能、避免过度抑制）而非缺点（详见 [06-mtor-rapamycin](../04-drugs/06-mtor-rapamycin.md) 第 7 节"连续 vs 脉冲"讨论）。

## 5. 上游调控的结构逻辑：Rheb 与 Rag GTPase

mTORC1 的溶酶体表面激活（Rheb-GTP + Rag 异二聚体）涉及两个 GTPase 的"空间协作"：

### 5.1 Rheb：直接激活者

- Rheb 是 Ras 家族 GTPase，其 **Switch I/II 区域**在 GTP 结合时呈激活构象；
- Rheb-GTP 与 mTOR 激酶域的 N 叶结合，**稳定"开放"的底物通道构象**——"Rheb 把门推开"；
- TSC1/2 复合物（Rheb 的 GAP）使 Rheb 水解 GTP 为 GDP → Rheb 失活 → 门重新关闭——**TSC1/2 是"关门"的刹车**。

### 5.1a GTPase 开关的"分子时钟"：Rheb 与 Rag 如何协同

理解 mTORC1 的溶酶体激活，需要把握两个 GTPase 的"分子时钟"逻辑——它们各自走一个 GTP 结合/水解循环，但角色不同：

**Rheb 的"门闩"角色**：Rheb 结合 GTP 时（Rheb-GTP），其 Switch I/II 区域呈"闭合激活"构象，能插入 mTOR 激酶域 N 叶的疏水槽，稳定"底物通道开放"的构象。Rheb 的 GTP 水解速率极慢（内在 GTPase 活性低），一旦装载 GTP 就"赖在"激活态——**Rheb 是"常开型门闩"，只需 TSC1/2 把它"按下去"（GAP 激活 GTP 水解）才能关门**。TSC1/2 因此是 mTORC1 的"总闸"：生长因子信号经 Akt 磷酸化 TSC2 → TSC 失活 → Rheb 保持 GTP → 门保持开放。

**Rag 的"定位"角色**：RagA/B-RagC/D 异二聚体不像 Rheb 那样直接"推门"，而是决定 **mTORC1 是否"到场"**（溶酶体表面）。RagA/B 结合 GTP（RagC/D 结合 GDP）时，Rag 二聚体呈"招募态"——与溶酶体膜上的 Ragulator 复合物结合，把 mTORC1（经 Raptor 与 Rag 互作）拉到溶酶体表面。**氨基酸充足（亮氨酸经 Sestrin2→GATOR2）→ RagA/B 装载 GTP → mTORC1 上溶酶体 → 与 Rheb 会合**——"Rag 管到场、Rheb 管开门"。

**"双钥匙"逻辑**：mTORC1 激活需要"两个条件同时满足"——①生长因子/能量信号（决定 Rheb-GTP，门闩是否打开）；②氨基酸信号（决定 Rag-GTP，复合物是否到场）。**任一条件缺失，mTORC1 都无法激活**——这是"营养 + 生长因子双控"的结构设计（"双钥匙锁"），也是为什么雷帕霉素（堵门）与氨基酸饥饿（不到场）能协同抑制 mTORC1。

**溶酶体膜作为"信号平台"**：溶酶体表面聚集了 mTORC1 激活所需的所有元件（Ragulator、Rheb、v-ATPase 等）——溶酶体不只是"垃圾处理站"，更是"营养信号平台"（这是 2017 年后 mTOR 领域的范式转变，呼应 [04-mtor-rapamycin](../04-drugs/06-mtor-rapamycin.md) 的溶酶体通路讨论）。

### 5.2 Rag GTPase：溶酶体锚定

- RagA/B-RagC/D 异二聚体（GTP 装载状态决定活性）把 mTORC1 招募到溶酶体表面（经 Ragulator 复合物）；
- **空间逻辑**：mTORC1 必须"到达"溶酶体表面的 Rheb 才能被激活——Rag 决定"mTORC1 在不在场"，Rheb 决定"门开不开"；
- 氨基酸（亮氨酸经 Sestrin2/GATOR2）→ Rag 装载 GTP → mTORC1 上溶酶体——"氨基酸信号 = 让 mTORC1 到场"。

## 6. 结构视角的 mTORC1 调控整合

```text
            ┌── 氨基酸充足 ──► Rag-GTP ──► mTORC1 上溶酶体 ──┐
            │                                                 │
上游信号 ──► ├── 生长因子 ──► Akt ──► TSC2 抑制 ──► Rheb-GTP ──┼──► 门打开
            │                                                 │
            ├── 能量充足 ──► AMPK 失活 ──► TSC2/Raptor 磷酸化减少 ──► 激活
            │                                                 │
            └── 能量匮乏 ──► AMPK 激活 ──► TSC2↑/Raptor 磷酸化 ──► 门关闭
                                                                  │
                                                                  ▼
                                         底物(S6K1/4E-BP1)可及性 → 翻译/生长
```

**"门控"模型贯穿始终**：所有上游信号最终都通过"控制底物通道的开关"（Rheb 开门、AMPK 关门、雷帕霉素堵门）来调控 mTORC1——这是 mTORC1 结构设计的核心逻辑，也是"为什么雷帕霉素能抗衰而 ATP 竞争型抑制剂毒性更大"的结构解释（雷帕霉素只堵门、保留部分功能；ATP 竞争剂直接废掉酶）。

## 7.1 "门控"模型的统一性：从酵母到人类

TOR 的"门控"设计并非人类特有，而是从酵母到人类保守的"生长总开关"架构：

- **酵母 TORC1**：两个 TOR 蛋白（Tor1/Tor2）与 Kog1（Raptor 同源物）、Lst8（mLST8 同源物）组装——同样把活性位点深埋、用"门卫"控制底物进入；雷帕霉素-FKBP12（酵母 Fpr1）同样"堵门"抑制酵母 TORC1（雷帕霉素最初就是作为抗真菌药发现的）；
- **结构保守性**：mTOR 的激酶域折叠、FRB 域位置、活性位点深埋策略在真核生物中高度保守——"深埋活性位点 + 门控"是 TOR 家族应对"必须整合多路信号"的共同进化答案（不靠快速开关，而靠精细门控）；
- **进化启示**：TOR 选择"门控"而非"构象开关"（如许多激酶的磷酸化激活），可能是因为 mTORC1 的底物（翻译机器、自噬机器）需要"持续可调"而非"全或无"的输出——"门开多大"比"门开不开"更重要。

**这对理解雷帕霉素抗衰的启示**：雷帕霉素的"部分堵门"恰好落在"门控可调"的谱系中间——不完全关闭 mTORC1、保留基础翻译，正是 TOR 门控设计的"中间档位"。**"TOR 门控的可调性 = 抗衰干预的可调性"**——这是雷帕霉素作为抗衰候选药优于"完全抑制"策略（ATP 竞争剂）的结构哲学。

## 8. 与知识库主线联系

- **雷帕霉素抗衰**（[06-mtor-rapamycin](../04-drugs/06-mtor-rapamycin.md)）：本文给出"原子级"机制——雷帕霉素堵门而非堵酶，解释了"脉冲给药"的分子逻辑（间歇堵门、保留恢复窗口）；
- **AMPK-mTOR 对抗**（本专题 03 篇）：AMPK 磷酸化 Raptor（Ser722/792）——直接在"门卫"上贴"禁止通行"标签；
- **自噬调控**（[01-foundations/06-proteostasis-autophagy.md](../01-foundations/06-proteostasis-autophagy.md)）：mTORC1 磷酸化 ULK1（Ser757）抑制自噬起始——ULK1 是"底物通道"的另一个受益者/受害者；
- **癌症与抗衰的张力**（[06-mtor-rapamycin](../04-drugs/06-mtor-rapamycin.md) 第 5 节）：mTOR 激活突变（癌症）与过度抑制（免疫抑制）在结构上是一枚硬币的两面——"门"的调控精度决定临床结局。

### 8.1 结构视角的"mTORC1 与衰老标志的对应"

回到 [01-foundations/01-aging-hallmarks.md](../01-foundations/01-aging-hallmarks.md) 的十二大衰老标志，mTORC1 的结构门控与其中至少六项直接相关：①营养感知失调（mTORC1 就是营养感知的核心执行者）；②蛋白稳态丧失（mTORC1 抑制自噬 → 受损蛋白累积，ULK1/TFEB 门控失当）；③线粒体功能障碍（mTORC1 过度激活抑制线粒体自噬，PGC-1α 失衡）；④细胞衰老（mTORC1 激活与 SASP 分泌相关，S6K1-IRS1 负反馈致胰岛素抵抗）；⑤干细胞耗竭（过度合成代谢耗尽干细胞储备）；⑥细胞间通讯改变（mTORC1 驱动的炎症与代谢信号紊乱）。**"门控"模型把多个衰老标志统一为"一扇门"的调控问题**——门开太大（mTORC1 过度激活）加速衰老，门关太紧（完全抑制）带来毒性，理想的抗衰是"门控的精细调节"（部分抑制、间歇抑制、组织特异抑制）。这一结构视角与 [09-immortality/02-breakthrough-candidates](../09-immortality/02-breakthrough-candidates.md) 中 mTOR 路径 27/40 分的评估（证据强但逆转深度有限）一致——mTORC1 是"降速"而非"逆转"的靶点。

## 9. 开放问题

1. **全长 mTORC1 的高分辨结构**：5.9 Å cryo-EM 分辨率有限，亚基界面（Raptor-底物、DEPTOR 结合）的原子细节待更高分辨；
2. **底物呈递的动态过程**：Raptor 如何"抓住"TOS 基序并把底物"递"进活性位点的完整轨迹（cryo-EM 中间态在探索）；
3. **4E-BP1 部分抵抗的结构细节**：雷帕霉素结合态下 4E-BP1 仍能部分磷酸化的精确构象未知；
4. **mTORC2 的结构**：mTORC2（含 Rictor/SIN1）的完整高分辨结构直到近年才被解析，其与 mTORC1 的结构差异（为什么雷帕霉素急性期不抑制 mTORC2）仍有许多细节待明确；
5. **"门控"的别构调控药物**：能否设计"半开门"（部分抑制底物）的变构剂——既抑制过度 mTORC1 又保留必要翻译功能（抗衰理想药物）？

## 9.1 雷帕霉素类药物的结构-临床映射

雷帕霉素（西罗莫司）及其衍生物（依维莫司、替西罗莫司）的临床特性可从结构直接推导：

- **免疫抑制的结构逻辑**：FKBP12-雷帕霉素堵住 mTORC1 底物通道 → S6K1 磷酸化受抑 → T 细胞增殖所需蛋白合成被阻断——"堵门"对增殖旺盛的 T 细胞（高度依赖 mTORC1）打击最大，这是移植免疫抑制的分子基础；
- **抗肿瘤的结构逻辑**：癌细胞依赖 mTORC1 驱动生长（MYC/cyclin D1 翻译）——雷帕霉素"堵门"切断促生长蛋白翻译，同时保留部分 4E-BP1 抑制（雷帕霉素对 4E-BP1 不完全抑制意味着某些肿瘤可能耐药——"4E-BP1 逃逸"是雷帕霉素抗癌效果有限的已知机制）；
- **抗衰的结构逻辑**（[06-mtor-rapamycin](../04-drugs/06-mtor-rapamycin.md)）："堵门但不堵酶"的**部分抑制**特性恰是抗衰需要的——保留基础翻译功能（避免过度抑制的毒性）同时下调过度 mTORC1 信号。**间歇给药（每周/隔周）的结构解释**：脉冲式堵门 → S6K1 抑制峰 + 恢复窗口（门重新打开、翻译恢复）——在"抑制过度合成"与"保留必要合成"之间振荡；
- **mTORC2 的急性不敏感**：雷帕霉素-FKBP12 急性期只结合 mTORC1（FRB 域在 mTORC1 中可及）；mTORC2 的 FRB 域被 Rictor 部分遮蔽——慢性/高剂量时才破坏 mTORC2 组装（"mTORC2 慢性抑制"），这是雷帕霉素胰岛素抵抗副作用的结构根源（mTORC2 → Akt Ser473 磷酸化受损）。

## 9.2 "门控"模型对抗衰药物设计的启示

mTORC1 的"深埋活性位点 + 门控"结构给抗衰药物设计三条启示：

1. **变构优于正构**：ATP 竞争型抑制剂（Torin1、BEZ235）完全阻断激酶活性（"拆门"），毒性大（高血糖、胃肠）且临床失败；变构"堵门"（雷帕霉素类）保留部分功能——**抗衰需要"部分抑制"而非"完全阻断"**；
2. **底物选择性抑制是理想方向**：如果能设计"只挡 S6K1、不挡 4E-BP1"的选择性底物阻断剂，理论上可保留 4E-BP1 介导的保护性翻译（应激基因）同时抑制 S6K1 的促衰老信号——"4E-BP1 保留"正是雷帕霉素延寿机制的一部分（Bjedov 2010 果蝇实验），未来药物应放大这一选择性；
3. **组织靶向的必要性**：mTORC1 抑制的获益（免疫、代谢）与风险（免疫抑制、伤口愈合障碍）在不同组织不同——组织特异递送（纳米颗粒、ADC 式偶联）是"精准堵门"的方向（呼应 [06-mtor-rapamycin](../04-drugs/06-mtor-rapamycin.md) 4.4 节的组织特异性讨论）。

## 11. 结构视角的"为什么雷帕霉素能抗衰"

回到知识库的核心问题——雷帕霉素为什么能延长寿命（[06-mtor-rapamycin](../04-drugs/06-mtor-rapamycin.md) 第 4 节）？结构给出三层答案：

1. **部分抑制的"恰到好处"**：雷帕霉素"堵门不堵酶"→ 不完全抑制 → 保留 4E-BP1 部分功能 → 保留保护性翻译（应激基因）同时下调过度 S6K1 信号——"部分抑制"在结构上天然实现（FRB 堵门 vs 4E-BP1 挤门缝）；
2. **自噬激活的"门逻辑"**：mTORC1 抑制 → ULK1 去抑制（Ser757 不再被磷酸化）→ 自噬启动——"关门（mTORC1）→ 开门（自噬）"是同一结构开关的两面；
3. **间歇给药的"振荡设计"**：周期性堵门 → S6K1 在抑制/恢复间振荡 → 既获得"抑制过度合成"的延寿信号，又避免"持续抑制"的副作用（免疫抑制、伤口愈合障碍）——"脉冲式堵门"的分子逻辑。

## 12. mTORC1 结构研究的"实用工具箱"

- **雷帕霉素敏感 vs 抵抗的检测**：FRB 域突变（如 Ser2035Ile，破坏 FKBP12-雷帕霉素结合）使细胞对雷帕霉素抵抗——科研中用它区分"mTORC1 依赖 vs 非依赖"的表型（"雷帕霉素抵抗突变体"是机制研究的标准工具）；
- **ATP 竞争剂 vs 变构剂的联用**：Torin1（ATP 竞争，完全抑制）与雷帕霉素（变构，部分抑制）的差异可用于"剂量梯度"实验——区分"完全抑制"与"部分抑制"的不同表型（抗衰研究关注部分抑制）；
- **活性检测的"底物选择"**：p-S6K1（Thr389）是 mTORC1 活性的金标准读数，p-4E-BP1（Thr37/46）反映"雷帕霉素不敏感部分"——"双底物读数"可区分雷帕霉素敏感/抵抗的 mTORC1 活性（呼应 4E-BP1 部分抵抗的结构知识）；
- **结构启发的"下一代抑制剂"**：基于"FRB 堵门"设计"底物竞争肽"（模拟 S6K1 TOS 基序，与 Raptor 竞争底物）——"底物竞争"而非"激酶抑制"的下一代策略在概念验证阶段。

## 13. 结构-功能"五问"总结

| 问题 | 结构答案 |
|---|---|
| 为什么活性位点深埋？ | 限制底物进入 + 门控调控——"不是所有蛋白都能接近催化中心" |
| 雷帕霉素如何抑制？ | FKBP12-雷帕霉素结合 FRB 域 → 堵住底物通道（变构"堵门"而非"堵酶"） |
| 为什么 4E-BP1 部分抵抗？ | 4E-BP1 与 mTOR 的结合模式（TOS 基序 + 磷酸化位点空间位置）使其在门被堵时仍能部分接近 |
| 为什么急性期不抑制 mTORC2？ | mTORC2 的 FRB 域被 Rictor 遮蔽，FKBP12-雷帕霉素无法接近 |
| 抗衰为什么用间歇给药？ | 脉冲式堵门 → S6K1 抑制峰 + 恢复窗口——"部分、周期性抑制"兼顾获益与安全 |

**一句话总结**：mTORC1 是"深埋活性位点 + FRB 门卫"的生长总开关——雷帕霉素"堵门"而非"堵酶"的部分抑制特性，正是它既能延寿又保留必要功能的结构基础。

> **结构速览**：mTORC1 = mTOR(激酶深埋) + Raptor(底物呈递) + mLST8(稳定)。FRB 域是"门卫"，FKBP12-雷帕霉素"堵门"而非"堵酶"。Rheb-GTP 开门、AMPK 关门、雷帕霉素堵门——"门控"是 mTORC1 的全部调控逻辑。
