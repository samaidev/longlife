# 分子结构深潜 40：脂氧合酶（ALOX15）——"脂质过氧化的点火器"与铁死亡的助燃剂

> **专题定位**：10-structures（分子结构深潜）第 40 篇——解剖脂氧合酶（LOX, 主要是 ALOX15/15-LOX）的三维结构,理解"LOX 怎么把多不饱和脂肪酸（PUFA）氧化成脂质氢过氧化物（LOOH）"、"铁催化中心的原子机制"、以及它在"铁死亡-炎症-衰老"中的"点火器"角色。这是 GPX4 篇（[39-gpx4.md](39-gpx4.md)）的"对手篇"——GPX4 灭火, LOX 点火——完成"铁死亡"双雄叙事。
> **关联篇目**：GPX4 见 [39-gpx4.md](39-gpx4.md)（铁死亡闸门, 灭火）；Nrf2 见 [15-nrf2-structure.md](15-nrf2-structure.md)（抗氧化指挥）；cGAS-STING 见 [30-cgas-sting.md](30-cgas-sting.md)（炎症警报）；NF-κB 见 [14-nfkb-structure.md](14-nfkb-structure.md)（炎症主开关）；SIRT3 见 [34-sirt3-structure.md](34-sirt3-structure.md)（线粒体抗氧化）。

## 0. 结构速览

**一句话**：脂氧合酶（LOX）是"脂质过氧化的点火器"——用非血红素铁（Fe²⁺）把多不饱和脂肪酸（PUFA）氧化成脂质氢过氧化物（LOOH）。它是铁死亡（ferroptosis）的"助燃剂"（GPX4 是"灭火器"）——"LOX 点火, GPX4 灭火——火势'平衡'决定细胞生死"。

```text
脂氧合酶(ALOX15)结构:
  N端 β-桶(膜结合/调控) — 催化域(非血红素铁 + 底物通道)
                  │
  催化:  Fe³⁺ + PUFA → 自由基 → LOOH(脂质氢过氧化物) + Fe²⁺
                  │
  底物:  花生四烯酸(AA)/亚油酸 → 15-HpETE(氢过氧化物)
                  │
  铁死亡:  LOX产生LOOH → 铁催化Fenton → 脂质过氧化链 → 铁死亡
```

**三大结构特征**（决定其功能的原子基础）：
1. **非血红素铁催化中心**：Fe³⁺/Fe²⁺ 循环氧化 PUFA——"火种（铁）";
2. **长底物通道**：容纳 PUFA 长链（花生四烯酸 20C）——"引火线（底物通道）";
3. **N 端 β-桶**：膜结合/调控域——"点火器的'固定座'"。

**核心调控机制**：

```text
LOX 的"点火-灭火"平衡:
  LOX:  PUFA + O2 → LOOH(点火, 产脂质氢过氧化物)
       │
  GPX4:  LOOH → LOH(灭火, 还原氢过氧化物)
       │
  铁死亡:  LOX↑/GPX4↓ → LOOH累积 → 铁Fenton → 链式过氧化 → 细胞死亡
       │
  炎症:  LOX产物(白三烯/HpETE) → 炎症介质 → 慢性炎症
```

**"一句话记忆"**：脂氧合酶是"脂质过氧化的点火器"——铁（Fe³⁺ 抽氢）+ 长通道（定位）——"铁'点燃'PUFA → LOOH（火）——GPX4 灭火, LOX 点火——'平衡'定生死——抑 LOX（zileuton）+ 增 GPX4 + omega-3 膳食, '铁死亡抗衰'三管齐下"。

## 1. 为什么脂氧合酶结构重要

LOX 是"脂质氧化-炎症-铁死亡"的枢纽:

- **"脂质过氧化的点火器"**：LOX 是"酶促脂质过氧化"的主要来源（把 PUFA 氧化成 LOOH）→ 铁死亡的"助燃剂"——"点火器'点燃'脂质 → 火（LOOH）→ 铁死亡要'火'";
- **"与 GPX4 的对手戏"**：GPX4（[39-gpx4.md](39-gpx4.md)）"灭火"（还原 LOOH）;LOX"点火"（产 LOOH）→ 两者平衡决定铁死亡——"GPX4 灭火 vs LOX 点火——'火势'= LOX/GPX4 比值——抗衰要'灭火'（GPX4↑/LOX↓）";
- **"炎症介质工厂"**：LOX 产物（白三烯/脂氧素/HpETE）是炎症介质（白三烯: 哮喘/炎症）→ 慢性炎症（inflammaging）——"点火器'副产品'是'炎症信号'——LOX 促'炎性衰老'";
- **"药物靶点"**：LOX 抑制剂（白三烯合成抑制, 齐留通 zileuton 治哮喘）→ 抗炎/抗铁死亡——"熄'点火器' → 抗炎/抗铁死亡——已上市药物（zileuton）";
- **"抗衰证据"**：LOX 活性随龄/炎症↑ → 脂质过氧化↑ → 铁死亡/炎症↑ → 衰老——"点火器'越烧越旺' → 火患↑ → 衰老——抑 LOX 是抗衰方向";
- **"'老药新用'的'潜力'"**：zileuton（5-LOX 抑制剂, 已上市治哮喘）→ 抗铁死亡/抗衰"新用"——"已上市药'新用途'——'老药新用'是'快速路径'——LOX 抑制剂'现成'可用";

**结构研究的三个关键问题**：
1. 非血红素铁怎么催化 PUFA 氧化（铁-氧的原子机制）？
2. 底物通道怎么"定位"PUFA（区域选择性: 15-位 vs 12-位）？
3. N 端 β-桶怎么调控（膜结合/钙调控）？

这些问题在 1LOX（兔 15-LOX, 2.40 Å, 1997）、3V99（人 5-LOX+AA, 2.25 Å, 2012）等结构中得到回答——"两个 PDB, 一套'铁点火'逻辑——'点火器'从'结构'到'底物'看得清清楚楚——铁死亡'助燃剂'的'图纸'"。

## 2. 脂氧合酶的结构解剖

### 2.1 非血红素铁催化中心——"火种"

- 位置：催化域核心;
- 结构：单个非血红素铁（Fe³⁺/Fe²⁺）配位（3 个组氨酸 + C 端异亮氨酸 + 水）——"火种（铁原子）'安放'在'炉膛'（配位）里";
- 功能：Fe³⁺ 抽氢（从 PUFA 的 bis-allylic 碳）→ 自由基 → O₂ 加成 → LOOH——"火种'点燃'（Fe³⁺ 抽氢）→ 燃料'烧'（O₂ 加成）→ 火（LOOH）";
- **1LOX 的发现**：铁配位几何（八面体）→ 催化机制基础——"炉膛'结构'清楚——铁'怎么干活'看得见";
- **"铁配位的'精确'"**：Fe 与 3 个 His（N）+ C 端 Ile（O）+ 水（O）配位（八面体）→ 一个"空位"留给 O₂——"火种'六爪'固定（配位）→ 留'一爪'接氧（O₂）——配位'设计'";
- **"铁的'氧化态'循环"**：Fe²⁺（静息）→ Fe³⁺（活性, 抽氢）→ Fe²⁺（还原）→ 循环——"火种'静息-点燃-恢复'循环——铁'可循环'的'火种'";

### 2.2 长底物通道——"引火线"

- 位置：催化域内（从表面到铁中心）;
- 结构：长疏水通道（容纳 PUFA 长链, ~20C）——"引火线（通道）'穿过'到火种（铁）";
- 功能：PUFA 的碳链"穿"过通道 → 定位（区域选择性）→ 抽氢位点——"引火线'位置'决定'烧哪段'（15-位 vs 12-位）——通道'定向'氧化";
- **3V99 的发现**：人 5-LOX + 花生四烯酸（AA）→ 底物结合"清晰"→ 通道-底物相互作用——"引火线'插好'（AA 在通道）→ '点火位置'（5-位）确定——底物复合物'看清'区域选择性";
- **"通道的'疏水内衬'"**：通道内壁疏水（亮氨酸/苯丙氨酸等）→ 与 PUFA 长链"匹配"（疏水作用）→ 稳定底物——"引火线'油滑'（疏水内衬）→ 燃料'顺畅'滑入——疏水'匹配'";
- **"通道的'口径'"**：通道直径"刚好容纳"PUFA（不能太宽, 否则乱动）→ "定位"严格——"引火线'口径合适'（不松不紧）→ '定位'准确——尺寸'匹配'";

### 2.3 N 端 β-桶——"固定座"

- 位置：N 端;
- 结构：β-桶（膜结合/调控域）→ "点火器的'固定座'";
- 功能：膜结合（LOX 在膜上接触底物 PUFA）→ 钙调控（部分 LOX）——"固定座'贴膜' → 火种'够得着'膜脂——膜上'点火'".

## 3. "铁催化氧化"的分子逻辑：从结构到化学

### 3.0 一个原子一个原子地看：铁怎么"点燃"PUFA

很多人会问:LOX 怎么把"稳定的"PUFA 氧化?答案在"铁-氧的'自由基化学'"——"火种的'点火'机制":

**"'抽氢'（H 原子转移）"。** Fe³⁺-OH 从 PUFA 的"双烯丙基碳"（两个双键间的碳, 最易失氢）抽一个氢 → 形成"碳自由基"——"火种'夺走'燃料的'氢' → 燃料'活化'（自由基）——抽氢是'点火'第一步";

**"'氧加成'（O₂ 插入）"。** 碳自由基 + O₂ → 过氧自由基 → 抽氢（另一分子 PUFA）→ LOOH + 新自由基（链式）——"火'蔓延'：自由基 + O₂ → 过氧自由基 → 抢氢 → LOOH + 新自由基——链式'点火'";

**"'铁循环'（Fe 回收）"。** 催化后 Fe³⁺ → Fe²⁺ → 被 LOOH/氧再氧化回 Fe³⁺ → 循环——"火种'自己恢复'（铁循环）→ '持续点火'——铁是'可循环'的'火种'";

**"'为什么是 PUFA'"。** PUFA 的"双烯丙基碳"（C-H 键最弱）→ 最易抽氢 → LOX 专攻 PUFA——"燃料'易燃点'（双烯丙基）→ 点火'容易'——LOX 认'易燃'燃料（PUFA）".

### 3.1 "'区域选择性'之谜"：为什么"烧"特定位置

LOX 家族"区域选择性"（5/8/12/15-位）——"点火'位置'的'精确'":

**"'通道'的'长度/深度'"。** 底物通道的长度/形状决定 PUFA 的"插入深度"→ 抽氢位点不同（5-LOX 浅/15-LOX 深）——"引火线'长短'决定'烧哪段'——通道'深度' = 区域'选择'";

**"'通道'的'口袋'"。** 通道内的氨基酸口袋"锚定"PUFA 特定位置 → 双烯丙基碳对准铁——"引火线'卡位'（口袋锚定）→ '点火位'固定——口袋'定向'";

**"'3V99'的'证据'"。** 人 5-LOX+AA 结构（2.25 Å）→ AA 的 5-位碳对准铁中心 → 5-HpETE（区域特异）——"底物复合物'实拍'：AA '摆好' → 5-位'对准'铁——区域选择性的'结构证据'";

**"'生理意义'"。** 不同 LOX 产物（白三烯 5-/脂氧素 15-）→ 不同功能——"烧'不同位置' → 产'不同信号'（白三烯促炎/脂氧素抗炎）——区域选择性'功能分化'";

**"'5-LOX vs 15-LOX'的'对照'"**：5-LOX（白三烯, 促炎, 3V99）vs 15-LOX（脂氧素, 抗炎/铁死亡, 1LOX）→ "两个'点火器'：一个'点炎火'（5-LOX）, 一个'点铁死亡火'（15-LOX）——亚型'分工'"——"抑制'哪个'看'目的'（抗哮喘 5-LOX/抗铁死亡 15-LOX）";

**"'通道'的'可塑性'"**：3V99 显示 5-LOX 的 S663D 突变 → 变 15-LOX 活性（通道变化）→ 通道决定区域选择——"改'引火线'（突变）→ '烧哪'变——通道'可塑'（一突变换位）——结构'决定性'证据"。

### 3.2 "'LOX-GPX4'的'拔河'：铁死亡的'平衡'"

LOX（点火）vs GPX4（灭火）——"铁死亡的'拔河'":

**"'点火的'速度"。** LOX 酶促氧化（快, 定向）→ 产生 LOOH 的"主渠道"——"点火器'高效点火'——LOOH 的'主要来源'（酶促）";

**"'灭火的'容量"。** GPX4（[39-gpx4.md](39-gpx4.md)）还原 LOOH（GSH 依赖）→ 清除"火"——"灭火器'容量'（GSH 供应）→ '火'可清——GPX4 是'专职灭火'";

**"'平衡'的'决定'"。** LOX 活性 > GPX4 容量 → LOOH 累积 → 铁 Fenton → 链式过氧化 → 铁死亡——"点火'快于'灭火 → 火'失控' → 铁死亡——LOX/GPX4 '比值' = 生死'天平'";

**"'抗衰'的'双向'"。** ①增强 GPX4（灭火, [39-gpx4.md](39-gpx4.md) 篇）;②抑制 LOX（熄火, zileuton 等）——"灭火'同时'熄火——双管齐下防铁死亡——抗衰要'两头'管"。

### 3.30 "LOX 的'催化域'进化"：从植物到人的'保守铁'

LOX 家族从植物到人"铁催化"保守——"点火器'祖传'的'火种'":

**"'家族的'广泛分布"。** LOX 存在于植物（豆类 LOX）/动物（哺乳类 5/12/15-LOX）→ 铁催化核心"保守"——"点火器'家家有'（植物/动物）→ '火种'（铁）'祖传'——进化'保留'";

**"'结构域'的'演化'"。** 哺乳 LOX 加"N 端 β-桶"（膜结合/调控）→ 植物 LOX 无 → 功能"扩展"——"点火器'升级'（加'固定座' β-桶）→ '可贴膜'点火——动物'膜上'点火（膜脂氧化）";

**"'区域选择性'的'分化'"。** 5/12/15-LOX 从共同祖先"分化"（通道变异）→ 不同产物/功能——"点火器'分支'：烧'不同位置'（5/12/15）→ 不同'火警'（白三烯/脂氧素）——'分化'出'功能多样性'";

**"'进化'的启示"**：LOX 是"古老+保守"的酶（铁催化 30 亿年）→ "脂质氧化'古老'（生命早期就有点火器）→ 抗氧化（GPX4）也'古老'——氧化-抗氧化'平衡'是生命'基本张力'——抗衰要'维护平衡'（不极端）".

### 3.40 "LOX 的'底物'选择"：为什么'认'PUFA

LOX 认 PUFA（不认饱和脂肪酸）——"点火器'挑燃料'":

**"'双烯丙基碳'的'弱点'"。** PUFA 含"双烯丙基碳"（两个双键之间的 CH₂, C-H 键最弱 ~75 kcal/mol）→ 最易抽氢 → LOX 专攻——"燃料'薄弱点'（双烯丙基 C-H）→ 点火'容易'——LOX 认'易燃'点";

**"'饱和脂肪'的'难燃'"。** 饱和脂肪酸无双键 → 无双烯丙基碳 → LOX 不氧化——"没'易燃点' → 点不着——LOX '挑食'（只烧 PUFA）";

**"'膜脂'的'PUFA 含量'"。** 膜磷脂含 PUFA（心磷脂/磷脂酰胆碱）→ LOX 氧化"膜脂" → 膜损伤——"点火器'烧'膜脂（PUFA 丰富）→ 膜'烧穿'——铁死亡的'靶'是'膜'";

**"'抗衰启示'"**：减少"膜 PUFA 含量"（饮食: 少多不饱和油?）→ 降低"易燃性" → 铁死亡↓——但 PUFA 也是"必需脂肪酸"（不能缺）→ "平衡: 不过量'多不饱和油', 但保'必需'"——"燃料'适量', 火'可控'".

## 4. 脂氧合酶与衰老：结构视角的"点火器失控"

### 4.1 LOX 的衰老/疾病证据

- **随龄/炎症↑**：LOX 活性随龄/炎症因子↑ → 脂质过氧化↑ → 铁死亡/炎症↑——"点火器'越烧越旺' → 火患↑ → 衰老";
- **铁死亡**：LOX 是铁死亡"助燃剂"（LOX 抑制 → 铁死亡↓）→ 神经退行/缺血保护——"熄'点火器' → 铁死亡↓——LOX 抑制剂'防铁死亡'";
- **炎症**：LOX 产物（白三烯/HpETE）→ 炎症介质 → 哮喘/动脉粥样硬化——"点火器'副产品'（炎症介质）→ 慢性炎症——LOX 促'炎性衰老'";
- **癌症**：LOX 与肿瘤（12-LOX/15-LOX 促癌/抑癌双面）→ 复杂——"点火器在肿瘤'角色'复杂——双面";
- **神经退行**：LOX↑ → 脂质过氧化 → 神经元铁死亡 → AD/帕金森风险——"脑'点火' → 神经元铁死亡 → 退行".

### 4.2 "'脂质氧化'的'两员大将'"：LOX 与 GPX4 的结构对照

| 酶 | 角色 | 催化中心 | 结构篇 |
|---|---|---|---|
| LOX | 点火（产 LOOH） | 非血红素铁（Fe） | [40-lox.md](40-lox.md) |
| GPX4 | 灭火（还原 LOOH） | 硒代半胱氨酸（Sec） | [39-gpx4.md](39-gpx4.md) |

**"'一铁一硒'的'对照'"**：LOX 用"铁"（Fe 氧化 PUFA 点火）;GPX4 用"硒"（Sec 还原 LOOH 灭火）——"铁'点火', 硒'灭火'——两个'金属/准金属'催化, 一攻一守——'化学'决定'角色'";

**"'底物'的'同一'"。** LOX 产 LOOH, GPX4 吃 LOOH → 同一"分子"（LOOH）是"产物"也是"底物"——"火（LOOH）'被点'也'被灭'——同一物质, 两酶'对向'操作——'平衡'在 LOOH";

**"'结构'的'对比'"**：LOX 长通道（容纳 PUFA）+ 铁中心 vs GPX4 平坦面（宽特异）+ 硒中心——"一个'深炉膛'（LOX 长通道）, 一个'开放灭火位'（GPX4 平坦面）——'结构'适应'功能'";

**"'LOX 的'长通道' vs 'GPX4 的'平坦面'"**：LOX 要"定位"PUFA（长链）→ 深通道;GPX4 要"还原"各种 LOOH → 开放面——"点火'要精确'（通道定位）, 灭火'要广谱'（开放面）——'结构'呼应'功能'（一深一平）";

**"'机制'的'互补'"**：LOX 用铁（氧化）, GPX4 用硒（还原）→ "铁'氧化' vs 硒'还原'——'一攻一守'的'化学'——金属（铁）氧化, 类金属（硒）还原——'元素'决定'方向'"。

### 4.4 "LOX 与'膳食脂质'"：omega-3/6 的'双面'

LOX 的底物来自膳食脂质——"点火器'燃料'来源的'双面'":

**"'omega-6'的'促炎面'"。** omega-6（亚油酸/AA）→ LOX 氧化 → 白三烯/促炎介质 → 炎症——"燃料'偏促炎'（omega-6 → 白三烯）→ '火警'多——omega-6 过量'助炎'";

**"'omega-3'的'抗炎面'"。** omega-3（EPA/DHA）→ LOX 氧化 → 脂氧素/消退素（resolvin, 促消退）→ 抗炎/促修复——"燃料'偏抗炎'（omega-3 → 消退素）→ '熄火'信号——omega-3 有'抗炎'益处";

**"'平衡'的'膳食'"。** 现代饮食 omega-6/omega-3 比值↑（~15:1 vs 祖先 ~1:1）→ LOX 底物"偏促炎"→ 慢性炎症↑——"燃料'比例'失衡（omega-6 多）→ 火警'常响'——恢复'平衡'（omega-3↑/omega-6↓）";

**"'抗衰启示'"**：①膳食"调燃料"（omega-3 补充/omega-6 控制）→ LOX 产物"偏抗炎"——"换'燃料' → 火'小'且'信号好'";②LOX 抑制剂 + 膳食"双管"——"熄火'器' + 换'燃料'——脂质抗衰'饮食-药物'结合——'抗炎饮食'（地中海式）有'分子基础'（LOX 底物）"。

**"'抗衰启示'"**：脂质过氧化的"平衡"（LOX vs GPX4）是铁死亡/衰老的"核心天平"——"抗衰 = 压'灭火'（GPX4↑）+ 压'点火'（LOX↓）——'双向调控'脂质过氧化".

### 4.3 "LOX 与炎症衰老"：白三烯的'火警'

LOX 产物是"炎症介质"——"点火器的'火警'信号":

**"'白三烯'的'合成'"。** 5-LOX + 花生四烯酸 → 白三烯（LTB4/LTC4 等）→ 炎症介质（趋化/收缩）——"点火器'点燃'白三烯'火警'（炎症信号）→ 炎症'警报'";

**"'HpETE 的'信号'"。** 12/15-LOX 产 HpETE/HETE → 脂质信号（PPAR 配体等）→ 代谢/炎症调控——"火'烟'（HpETE）也是'信号'（调节）——脂质氧化产物'双面'（损伤+信号）";

**"'LOX 与 NF-κB/cGAS-STING 的对话'"。** LOX 产物促炎症（NF-κB, [14-nfkb-structure.md](14-nfkb-structure.md)）;损伤细胞释放 DNA（cGAS-STING, [30-cgas-sting.md](30-cgas-sting.md)）→ 炎症——"火警'串联'：LOX 产物 → NF-κB 炎症 → 细胞损伤 → cGAS-STING——炎症'放大器'";

**"'铁死亡'的'拔河'补充"**：LOX 抑制剂（RSL3 反证: RSL3 抑 GPX4 → 铁死亡, 而 LOX 抑制剂可部分保护）→ LOX 是铁死亡"执行者"之一——"拔河'实证'：撤灭火（RSL3）→ 火炸;熄点火（LOX 抑）→ 火小——'双向'验证铁死亡'平衡'".

**"'LOX 的'生理功能'"**：LOX 不只是"坏事"（正常生理: 红细胞成熟/皮肤屏障/脂氧素抗炎）→ 完全抑制有"副作用"——"点火器'也有用'（生理: 成熟/屏障/抗炎信号）→ '适度'抑制——'平衡'再次强调"。

## 7. 结构-衰老"五问"总结

| 问题 | 结构答案 |
|---|---|
| LOX 怎么氧化 PUFA？ | 铁（Fe³⁺）抽氢 → 自由基 → O₂ 加成 → LOOH |
| 为什么区域选择？ | 通道长度/口袋锚定 → 特定碳位对准铁 |
| 怎么促铁死亡？ | 产 LOOH → 铁 Fenton → 链式过氧化（助燃） |
| 怎么抗衰？ | 抑 LOX（zileuton）+ 增 GPX4 → 脂质过氧化↓ |
| 怎么干预？ | LOX 抑制剂 + Nrf2 激活 + 抗炎——"熄火+灭火" |

**五问之外的结构直觉**：LOX 的故事揭示了"脂质氧化的'酶促-非酶促'双源"——**"'脂质过氧化'不只会'自己烧'（非酶: 铁 Fenton/ROS）, 还有'点火器'（酶促: LOX 定向氧化）——LOX 是'可控'的'点火开关'（可抑制）——这给'干预'留了'把手'"**。抗衰启示: ①脂质过氧化"可酶促" → "可药物干预"（LOX 抑制剂, zileuton 已上市）——"熄'点火器'是'已可行'的抗衰策略（老药新用）";②LOX-GPX4 "平衡"是铁死亡核心——"抗衰不是'消灭氧化', 是'维护平衡'（压点火+增灭火）";③LOX 产物"双面"（损伤+信号）→ "干预要'适度'（不消灭 LOX, 只降活性）——'平衡'哲学贯穿铁死亡抗衰".

### 8.1 "LOX 与'铁死亡抗衰'的未解之谜"

LOX/铁死亡研究仍有多个"未解之谜"——"点火器的'盲区'":

**"'LOX 贡献'的定量"。** 铁死亡中 LOX（酶促）vs 非酶（Fenton）氧化的"比例"→ 未定论——\"点火器'烧了多少' vs '自燃'多少——定量未明\";

**"'亚型'的'分工'\"。** 5/12/15-LOX 在铁死亡/炎症中的"各自角色"→ 未完全清楚——\"几个'点火器'谁主谁次——分工未明\";

**"'抑制剂'的'选择性'\"。** 现有 LOX 抑制剂（zileuton 等）的"亚型选择性/副作用"→ 需优化——\"熄'哪个点火器'最好——选择性难题\";

**"'老药新用'的'证据'\"。** zileuton 抗铁死亡/抗衰的"人体证据"→ 待积累——\"已上市药'新用'——人体证据待补\";

**"'抗衰启示'**"：LOX 是"铁死亡抗衰"的'可干预'靶点（有药）——\"'老药新用'（zileuton）是'快速路径'——从'哮喘药'到'抗衰药'——'已上市'是'优势'——抗衰研究要'挖掘'现有药物\".
