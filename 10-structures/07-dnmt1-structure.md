# 分子结构深潜 07：DNMT1——DNA 甲基化的"写入者"与自抑制机制

> **专题定位**：10-structures（分子结构深潜）第 7 篇——解剖 DNMT1（DNA 甲基转移酶 1）的三维结构，理解它如何"读取"半甲基化 CpG、"写入"新的甲基、以及"自抑制"如何保证只维护不新建。这是知识库表观重编程主线（[08-frontiers/01-reprogramming/01-concept.md](../08-frontiers/01-reprogramming/01-concept.md)）与 TET（[05-tet-dna.md](05-tet-dna.md)）形成"写-擦"对的结构底座。
> **关联篇目**：TET 结构见 [05-tet-dna.md](05-tet-dna.md)；SIRT1 结构见 [06-sirt1-structure.md](06-sirt1-structure.md)；衰老时钟见 [01-foundations/02-aging-clocks.md](../01-foundations/02-aging-clocks.md)。

## 0. 结构速览

**一句话**：DNMT1 是"维护型"DNA 甲基转移酶——它只把甲基写到**半甲基化**的 CpG 位点（母链有甲基、子链没有），从而在 DNA 复制后"复制"甲基化模式；它用一个精巧的自抑制机制确保自己不去"从头"甲基化未修饰位点。

```text
DNMT1 结构域:  N端(调节域) — RFTS — CXXC — BAH1 — BAH2 — 甲基转移酶域(MTase) — C端
                              │       │      │      │
                    (复制叉靶向) (CpG识别) (蛋白互作) (催化核心)
```

**三大结构特征**（决定其功能的原子基础）：
1. **CXXC 锌指域**：专门结合**未甲基化** CpG——它是"门卫"，把 DNMT1 从没甲基的位点推开；
2. **BAH1/2 域**：蛋白-蛋白互作模块，BAH2 伸出一个 loop 把催化域的目标识别区（TRD）"按住"在回缩位——自抑制的"第二道锁"；
3. **甲基转移酶域（MTase）**：含催化亲核半胱氨酸（Cys1226，人源编号），以 S-腺苷甲硫氨酸（AdoMet/SAM）为甲基供体，催化胞嘧啶 C5 位甲基化。

**催化核心反应**：

```text
半甲基化CpG: 母链 5mC(已有甲基) ── 子链 C(无甲基)
                    │
   DNMT1: 子链 C 翻转出双螺旋 → Cys1226 亲核攻击 C6 → AdoMet 供甲基 → 子链 C 变成 5mC
                    │
   结果: 双链都带甲基 = 甲基化模式在复制后得以"继承"
```

## 1. 为什么 DNMT1 结构重要

DNA 甲基化（CpG 二核苷酸的胞嘧啶 C5 甲基化）是哺乳动物最重要的表观遗传标记之一：约 70-80% 的 CpG 位点被甲基化，参与基因沉默、印记、转座子抑制、X 染色体失活。**甲基化模式的"继承"依赖 DNMT1 在每次 DNA 复制后把母链的甲基化复制到新合成的子链**——如果 DNMT1 失职，甲基化模式一代代稀释丢失。

**结构研究的三个关键问题**：
1. DNMT1 如何识别"半甲基化"位点（而不是未甲基化或全甲基化）？（底物选择性）
2. 催化如何发生——胞嘧啶如何被翻转、甲基如何被转移？（催化机制）
3. 自抑制如何保证"只维护、不新建"？（保真度机制）

这三个问题分别在 3PTA（自抑制态结构）、4DA4（产物性催化态结构）中得到回答。

**与衰老的直接关联**：
- 随龄**全局 5mC 减少**（尤其重复序列、基因体），同时**特定 CpG 高甲基化**（启动子区）——"甲基化模式的漂移"是表观衰老时钟（Horvath 时钟）的分子基础；
- DNMT1 活性/表达随龄下降（部分细胞类型），错误定位增加——"写入者"的衰退导致甲基化谱的混乱；
- 与 TET 的平衡：DNMT1（写）与 TET（擦）的动态平衡决定甲基化稳态，衰老时平衡被打破（呼应 [05-tet-dna.md](05-tet-dna.md) 的去甲基化两面性）。

## 2. DNMT1 的多域架构：一个"多锁"酶

DNMT1 全长 1616 残基（人），是哺乳动物最复杂的甲基转移酶——它用多个结构域实现"精细门控"：

### 2.1 RFTS 域（复制叉靶向序列）

- 位置：N 端 ~350-600 残基；
- 功能：靶向 DNMT1 到 DNA 复制叉（结合 PCNA/复制机器）——"复制时在场，复制后立即开工"；
- 结构特征：含一个"口袋"，可被 UHRF1 的 UBL 域"停靠"（UHRF1 是半甲基化 CpG 的"读者"，把 DNMT1 招募到位）——"读者-写入者"协作的枢纽。

### 2.2 CXXC 域（CpG 门卫）

- 位置：~600-700 残基；
- 结构：CXXC 锌指（8 个保守 Cys/His 配位 2 个 Zn²⁺），识别**未甲基化** CpG 的 DNA 小沟/大沟；
- 关键特性：**只认未甲基化 CpG**（甲基化后空间位阻破坏识别）——它把 DNMT1 引导向未甲基化位点，但随之而来的自抑制又阻止甲基化（"吸引到门口，却不放进门"）；
- "门卫"逻辑：CXXC 结合未甲基化 CpG 时，CXXC-BAH1 连接区插入 DNA 与活性位点之间——**物理阻断 de novo 甲基化**。

### 2.3 BAH1/2 域（互作与自抑制）

- 位置：~700-1100 残基；
- 结构：BAH（bromo-adjacent homology）折叠，蛋白-蛋白互作模块（在其他蛋白中参与染色质识别）；
- 自抑制角色：BAH2 的一个 loop 与 MTase 域的目标识别区（TRD）相互作用，把 TRD "按在"回缩位，阻止其插入 DNA 大沟——**活性构象的"刹车"**；
- 这一刹车在遇到半甲基化 CpG 时才"松开"（结构重排 → TRD 释放 → 催化开始）。

### 2.4 MTase 域（催化核心）

- 位置：C 端 ~1100-1616 残基；
- 结构：经典甲基转移酶折叠（AdoMet 依赖），分催化叶与靶识别叶；
- 关键残基：**催化半胱氨酸 Cys1226**（人源）——亲核攻击胞嘧啶 C6，形成共价中间体；
- 辅因子：S-腺苷甲硫氨酸（AdoMet/SAM）结合在辅因子口袋，提供甲基。

## 3. 自抑制机制：为什么 DNMT1 "只维护不新建"

### 3.0 一个原子一个原子地看：自抑制是怎么"锁"住酶的

要理解 DNMT1 的"只维护不新建"，先理解它面临的"识别难题"。DNA 复制后，双链中一条是母链（带着原有的甲基化标记），一条是全新的子链（完全没有甲基）。此时基因组里同时存在三种 CpG 位点：**半甲基化**（母链有、子链无）、**未甲基化**（两条链都没有）、**全甲基化**（两条链都有）。DNMT1 必须做到：只处理半甲基化位点，绝不动未甲基化位点——这就像一把钥匙必须只开一把锁。

**难题在于：识别"半甲基化"需要同时感知"母链有甲基"和"子链无甲基"。** 3PTA 结构揭示的答案是——DNMT1 用"双重否定"来实现这个精确认知：

**第一重："门卫"挡路。** CXXC 锌指域专门识别未甲基化 CpG（它不认带甲基的 CpG，因为甲基会破坏识别面的空间匹配）。当 CXXC 碰到未甲基化 CpG 并绑上去时，紧挨着的 CXXC-BAH1 连接区（一段肽链）就像一根"横杆"，恰好横在 DNA 双螺旋和 MTase 活性位点之间——**DNA 被这根横杆物理顶开，根本无法把胞嘧啶送进催化袋**。这就是"锁一"：CXXC 把酶吸引到未甲基化位点，连接区却同时把催化功能锁死。有意思的是，这种"吸引+锁死"的组合恰恰保证了 DNMT1 不会在未甲基化位点犯错——它被吸引过来，却又干不了活。

**第二重："刹车"按住。** 即便有锁一，MTase 域本身还有自己的"手臂"——目标识别区（TRD），正常情况下它会伸出插入 DNA 大沟去"抓住"胞嘧啶。但 BAH2 域伸出一个 loop（一段环状肽链），像一只手一样**按住 TRD 的肩部**，把它固定在回缩位置——"手臂伸不出去，就没法抓底物"。这就是"锁二"。

**半甲基化位点如何解锁？** 4DA4 结构显示，当 DNA 是半甲基化时：母链的 5mC 甲基被 MTase 的一个浅疏水凹面"读到"（这个凹面就是为甲基量身定做的，未甲基化 C 放不进去）；这个"读甲基"的动作触发了全局构象重排——连接区让位、TRD 松开、子链胞嘧啶翻转进催化袋。**"读到甲基 = 松开刹车 = 开工"**——半甲基化才是真正的"钥匙"。

**这套设计的精妙之处**：DNMT1 不直接"识别半甲基化"（那很难，因为子链本来就是裸露的），而是"识别未甲基化→锁死 + 识别甲基→解锁"——用两个相对简单的识别事件组合出复杂的选择性。**"简单识别、组合决策"**是分子机器的常见设计哲学（与 [04-mtor-structure.md](04-mtor-structure.md) 中 Rheb/Rag "双钥匙"逻辑异曲同工）。

### 3.1 两个"锁"（3PTA 结构揭示）

3PTA（人 DNMT1(646-1600)+未甲基化 CpG DNA，3.60 Å，Song 2011 *Science*）揭示了完整的自抑制架构：

**锁一（CXXC-BAH1 连接区）**：CXXC 结合未甲基化 CpG 后，CXXC 与 BAH1 之间的连接区（linker）恰好**横亘在 DNA 与 MTase 活性位点之间**——把 DNA 从活性位点"顶开"，使胞嘧啶无法翻转进入催化袋。即使 CXXC 吸引了 DNMT1 到未甲基化位点，连接区也保证"来了也不干活"。

**锁二（BAH2-TRD 互作）**：BAH2 伸出的 loop 抓住 MTase 域的 TRD（目标识别区），把 TRD 稳定在**回缩构象**——TRD 本应插入 DNA 大沟识别胞嘧啶，现在被"按住"动弹不得。双重保险：底物进不来（锁一），识别元件出不去（锁二）。

### 3.2 自抑制的生物学意义

- **防止 de novo 甲基化错误**：如果 DNMT1 对未甲基化位点也干活，甲基化模式会被"污染"（该沉默的基因被错误沉默、转座子错误抑制）；
- **专一性来源**：DNMT1 的"维护"专一性不是靠"识别半甲基化"（它其实识别未甲基化 CpG 的 CXXC），而是靠"被未甲基化位点吸引后自抑制、被半甲基化位点激活"的**双重门控**；
- **进化逻辑**：把"维护"与"新建"分开（DNMT1 维护、DNMT3A/3B 新建），避免一个酶干两件事导致保真度下降——"专职化=高保真"。

### 3.3 半甲基化激活的构象变化（4DA4 揭示）

4DA4（小鼠 DNMT1(731-1602)+半甲基化 CpG DNA，2.60 Å，Song 2012 *Science*）捕捉到**产物性催化态**：

- 半甲基化 CpG 的母链 5mC 被识别：甲基位于 MTase 的**浅疏水凹面**（"读"甲基的存在）；
- 子链未甲基化胞嘧啶被**翻转出双螺旋**（base flipping），进入催化袋；
- 催化残基（Cys1229，小鼠编号≈人 Cys1226）与胞嘧啶 C6 形成共价中间体（结构捕捉到半共价态）；
- 双链 DNA 在 CpG 处**扭曲变形**（intercalation 腔），两侧链同时部分翻转（"双碱基翻转"）——DNA 变形是催化的前提；
- 对比 3PTA：自抑制态（未甲基化）vs 催化态（半甲基化）的结构差异，正是"门控开关"的原子快照。

## 4. 催化机制：从结构到化学

### 4.0 甲基转移的"化学芭蕾"：为什么 Cys1226 是不可替代的主角

上一节讲了"锁"与"钥匙"，这一节看"钥匙插进锁后怎么转"。DNMT1 的催化是胞嘧啶 C5 位甲基化的过程，全程的主角是催化半胱氨酸 Cys1226 和甲基供体 AdoMet。我们一步步看原子层面发生了什么：

**先看胞嘧啶的处境。** 胞嘧啶（C）是嘧啶环上的一个碱基，C5 位连着一个氢（-H）。要让甲基（-CH₃）取代这个氢，化学上非常困难：C5 位没有天然的反应活性（它不是亲核位点），直接"换氢"在生理条件下几乎不发生。**酶的破解之道：先让胞嘧啶"变活泼"，再装甲基。** 怎么做？靠 Cys1226 的硫醇（-SH）去亲核攻击 C6 位——这一攻击打断了 C5-C6 之间的双键，使 C5 从"烯烃碳"变成"负碳离子"（碳负离子），**负碳离子才是能接受甲基的亲核体**。这就是经典的"迈克尔加成"（Michael addition）：先加成、再甲基化、再消除。

**再看 AdoMet 的奉献。** AdoMet（S-腺苷甲硫氨酸）是细胞内的"通用甲基钱包"，它的硫原子连着一个"活化的甲基"（硫鎓离子使甲基极度缺电子，非常容易被亲核体抢走）。DNMT1 的辅因子口袋把 AdoMet 摆得恰到好处：甲基与 C5 碳负离子相距仅 2-3 Å，处于"伸手可及"的距离。甲基转移后，AdoMet 变成 SAH（S-腺苷同型半胱氨酸）——**"钱包空了"，而且 SAH 还是 DNMT1 的竞争抑制剂**（产物抑制，防止过度甲基化）。

**最后看消除。** 甲基装上后，Cys1226 从 C6 位"撤手"（β-消除），C5-C6 双键恢复，5-甲基胞嘧啶（5mC）形成——一个"负碳离子→甲基化→恢复双键"的完整循环。三步走完，胞嘧啶变成了 5mC，DNA 双螺旋恢复。

**为什么这解释了 5-Aza 的药理？** 5-氮杂胞苷（5-Aza）把胞嘧啶 C5 位的碳（C）换成氮（N）。迈克尔加成照常发生（Cys1226 攻击 C6），但问题出在最后一步：**氮无法进行 β-消除**（氮不能像碳那样失去质子恢复双键）——共价中间体永远卡死在 Cys1226 和 DNA 之间。结果：DNMT1 被"钉死"在 DNA 上，随后被降解——细胞里的 DNMT1 被耗尽，新复制的 DNA 失去甲基化维持（被动去甲基化）。**"自杀性底物"的化学本质，就是利用 Cys 催化机制的最后一步不可逆**——这是结构生物学解释药物机理的绝佳案例。

### 4.1 三步催化（甲基转移的化学）

```text
步骤1: 碱基翻转 + 亲核攻击
  子链胞嘧啶翻转出双螺旋 → Cys1226 的硫醇(-SH) 去质子化 → 亲核攻击 C6
  → 形成 Cys-S-C6 共价中间体（胞嘧啶 C5-C6 双键被"打断"）

步骤2: 甲基转移
  AdoMet(SAM) 的甲基 → 转移到胞嘧啶 C5 → 形成 5-甲基胞嘧啶(5mC)
  AdoMet 变成 S-腺苷同型半胱氨酸(SAH)

步骤3: 消除 + 释放
  C5 去质子化 → C6 的 Cys 消除（β-消除）→ 恢复 C5-C6 双键
  → 5mC 从催化袋释放，DNA 恢复双螺旋
```

### 4.2 为什么 Cys1226 如此关键

- 它是整个反应的"亲核开关"：Cys 的硫醇在生理 pH 部分去质子化（pKa 约 8.3），碱基翻转后活性位点环境（Arg/Lys 正电荷）进一步降低 pKa，保证亲核性；
- **Cys1226 突变 → 酶完全失活**（生化验证）；
- 这也解释了为什么**氧化应激/活性氧**能抑制 DNMT1：Cys 易被氧化（-SH→-SOH/-SO₂H），亲核性丧失——"氧化应激伤甲基化维持"的分子机制；
- 与 TET 的对比：TET 用 Fe(II) 做氧化催化（去甲基化），DNMT1 用 Cys 做亲核催化（甲基化）——"一写一擦，机制相反"。

### 4.3 AdoMet（SAM）的"甲基钱包"

- AdoMet 是细胞内主要甲基供体（"甲基循环"核心，与叶酸/甲硫氨酸代谢相连）；
- DNMT1 的辅因子口袋精确摆放 AdoMet，使甲基恰好伸向 C5 位置（2-3 Å 距离）；
- 甲基化后 AdoMet 变 SAH，SAH 是 DNMT 的竞争抑制剂（产物抑制）——"甲基循环顺畅则甲基化顺畅"（呼应 [07-interventions/04-supplements.md](../07-interventions/04-supplements.md) 的叶酸/B12 讨论）。

## 5. DNMT1 与衰老：结构视角的"时钟走慢"

### 5.1 甲基化漂移的三种模式

衰老时的 DNA 甲基化变化（结构层面解释）：

- **全局 5mC 减少**：重复序列（LINE-1、Alu）甲基化随龄丢失 → 转座子去抑制风险 → 基因组不稳定。结构解释：DNMT1 活性下降 + 氧化损伤（Cys1226 等氧化）+ 复制错误累积 → "写入"跟不上"稀释"；
- **启动子 CpG 岛高甲基化**：特定基因（抑癌基因、发育基因）启动子区异常获得甲基 → 基因沉默。这与 DNMT1 的"维护"逻辑不符（更像是 de novo 活动或 TET 失调）——"不该写的地方写了"；
- **时钟位点**：Horvath 等发现特定 CpG 位点的甲基化水平与年龄高度相关（表观时钟）——"时钟位点甲基化水平的可预测漂移"= 衰老的分子计时器。

### 5.2 DNMT1 与表观重编程

- 重编程（OSK/OSKM）过程需要**大规模去甲基化**（TET 主导）+ 甲基化模式重建（DNMT3A/3B de novo + DNMT1 维护）——"擦干净再重写"；
- 部分重编程（ER-100 等）的"年轻化"效果部分来自**甲基化模式的复位**——DNMT1 在其中的角色是"维护新写的模式"；
- 结构视角：重编程中的 DNMT1 需要"正确激活"（遇到半甲基化位点松开自抑制），也需要"正确抑制"（不干扰 TET 的擦除）——**"写-擦"平衡是重编程安全的关键**（呼应 [01-concept](../08-frontiers/01-reprogramming/01-concept.md) 的四层防御）。

### 5.3 5-氮杂胞苷（5-Aza）类药物的结构机制

- 5-氮杂胞苷/地西他滨（5-aza-2'-脱氧胞苷）是核苷类似物，掺入 DNA 后**捕获 DNMT1**：
  - 氮杂胞嘧啶的 C5 位是氮（N）而非碳（C），Cys1226 亲核攻击后**无法进行 β-消除**（氮不能像碳那样去质子化恢复双键）→ 共价中间体"卡死"→ DNMT1 被不可逆锁定在 DNA 上；
  - 结果：DNMT1 被"耗尽"（降解），细胞 DNA 甲基化被动去甲基化（复制稀释）；
- 临床应用：骨髓增生异常综合征（MDS）/急性髓系白血病（AML）——"用自杀性底物废掉甲基化写入者，唤醒沉默的抑癌基因"；
- 抗衰视角：低剂量 5-Aza 在动物中改善衰老表型（部分去甲基化），但**全局去甲基化风险大**（转座子激活）——"擦多少、擦哪里"是核心难题（呼应 TET 篇的两面性讨论）。

## 7. 与知识库主线联系

### 7.0 DNMT1-TET 的"写-擦"对：表观稳态的阴阳

知识库表观主线有两大执行酶：DNMT1（本文，写）与 TET（[05-tet-dna.md](05-tet-dna.md)，擦）。从结构看这对"阴阳"：

| 维度 | DNMT1（写） | TET（擦） |
|---|---|---|
| 反应 | 胞嘧啶 C5 甲基化（加甲基） | 5mC 氧化（去甲基化第一站） |
| 催化 | Cys1226 亲核（共价中间体） | Fe(II)-2OG 氧化（ferryl 中间体） |
| 辅因子 | AdoMet（SAM）供甲基 | 2OG + O₂ |
| 底物 | 半甲基化 CpG（维护） | 任何可及 5mC（氧化） |
| 结构核心 | 多域自抑制门控 | DSBH 折叠 + 碱基翻转 |
| 衰老趋势 | 活性↓（全局 5mC↓） | 部分上调/失调 |
| 干预 | 5-Aza 抑制（唤醒基因） | TET 激活（重编程） |

**"稳态"的结构本质**：甲基化水平 = DNMT1 写入速率 - TET 擦除速率 - 复制稀释速率。衰老时三者失衡（写入↓、擦除失调、稀释持续），甲基化谱漂移——表观时钟的"指针"就是这三者的净效应。**干预策略（5-Aza、TET 激活、重编程）本质都是"重新平衡写-擦"**，而结构研究提供"平衡点在哪、怎么调"的原子级依据——**"写-擦平衡"是表观稳态的阴阳，也是表观年龄可逆性的根本前提**。

### 7.1 主线篇目对话

- **TET 结构**（[05-tet-dna.md](05-tet-dna.md)）：写-擦对的另一半；两篇合读构成"DNA 甲基化循环"的完整结构图景；
- **表观重编程**（[01-concept](../08-frontiers/01-reprogramming/01-concept.md)）：重编程 = 大规模擦除（TET）+ 模式重建（DNMT3 家族 de novo + DNMT1 维护）——"擦干净再重写"的结构逻辑；
- **衰老时钟**（[02-aging-clocks](../01-foundations/02-aging-clocks.md)）：Horvath 时钟 = 特定 CpG 甲基化的年龄相关漂移——DNMT1/TET 平衡漂移是时钟的分子机制；
- **NAD⁺/SIRT1**（[04-nad-sirtuin](../01-foundations/04-nad-sirtuin.md)）：SIRT1 调控 DNMT1 活性（去乙酰化稳定 DNMT1）——"NAD⁺ 下降 → SIRT1 下降 → DNMT1 不稳 → 甲基化漂移"的间接链；
- **分子结构专题**：与 SIRT1（去乙酰化）、TET（去甲基化）、NOS（NO 信号）共同构成"表观-代谢-信号"的结构底座。

## 8. 结构-衰老"五问"总结

| 问题 | 结构答案 |
|---|---|
| 为什么 DNMT1 只维护不新建？ | 双自抑制：CXXC 门卫（锁一）+ BAH2 按 TRD（锁二），未甲基化位点"吸引但不放行" |
| 半甲基化如何激活催化？ | 母链 5mC 进浅疏水凹面（读甲基），子链 C 翻转进催化袋（翻转=激活信号） |
| 甲基怎么加上去？ | Cys1226 亲核攻击 C6 → AdoMet 供甲基到 C5 → β-消除恢复双键（三步） |
| 为什么氧化应激伤甲基化？ | 催化 Cys 与 Zn²⁺ 配位 Cys 都是氧化靶标 → 亲核性/结构完整性丧失 |
| 5-Aza 怎么"废掉"DNMT1？ | 氮杂 C5（N 非 C）无法 β-消除 → 共价中间体卡死 → DNMT1 降解耗尽 |

## 9. 开放问题

1. **全长 DNMT1 的结构**：RFTS 域与 MTase 域的动态关系（复制叉招募→到位→激活）缺乏全长快照；
2. **UHRF1 协作的完整图景**：UHRF1（半甲基化读者）+ DNMT1（写入者）的复合物结构/动态未完全解析；
3. **自抑制的"松开"动力学**：从自抑制态到催化态的构象变化路径（中间态）缺乏直接观察；
4. **组织/细胞类型差异**：DNMT1 在不同组织（干细胞 vs 终末分化）的表达与活性调控差异；
5. **表观时钟的可逆性**：时钟 CpG 的甲基化漂移是否（以及如何）被 DNMT1/TET 干预逆转——"表观年龄能否被写-擦平衡重调"仍是开放问题；
6. **de novo vs 维护的边界**：DNMT1 在特定条件下（如 UHRF1 过表达、DNA 损伤）是否会"越界"做 de novo 甲基化？——这是理解异常甲基化的关键开放问题。
