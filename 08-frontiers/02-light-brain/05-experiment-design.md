# 05 实验设计：验证"光照 → 下丘脑 → 逆龄"

## 机制（假说链）
完整链条：PBM（浅层）与 FUS（深部）分别激活线粒体 CCO 与下丘脑 SIRT1 神经元 → SIRT1 去乙酰化网络（PGC-1α/FOXO/NF-κB 等）→ 经神经-内分泌、自主神经、体液三大广播通路 → 外周代谢、炎症、循环、昼夜节律整体改善 → 衰老时钟减速。本设计把链条拆成可独立证伪的环节，逐环验证。

## 技术方案
**动物（小鼠）**：①FUS 组——微泡辅助 LIFU 靶向 DMH/LH（SIRT1-Cre 报告鼠验证靶点）；②PBM 组——头皮 810nm 照射（10–20 J/cm²）；③FUS+PBM 联合组；④假手术对照；⑤NAD⁺ 前体组（阳性药理对照）。**人体**：随机双盲对照三臂——tPBM（经颅 LED，浅层）、tPBM+LIFU（靶向下丘脑邻近区）、tPBM+LIFU+NMN/NR，干预 8–12 周。

## 证据（终点）
**动物**：衰老时钟（甲基化/转录组时钟）、SIRT1 活性与乙酰化组、代谢（体重/糖耐量）、炎症谱、运动与认知、生存曲线；组织学确认下丘脑 SIRT1 神经元激活。**人体**：表观遗传衰老时钟（Horvath/转录组时钟）、**炎症标志物**（IL-6/TNF-α/CRP）、**HRV**（心率变异性，自主神经功能）、**睡眠监测**（多导/可穿戴）、认知与情绪量表；安全性（神经影像随访、不良事件）。

## 瓶颈
链条长、环节多：经颅光到不了下丘脑，**因果只能靠 FUS 臂建立**；FUS 靶向人下丘脑的伦理与安全窗；衰老时钟的生物学意义（是否真"逆龄"）存方法论争议；组合干预无法归因单一机制；颅骨厚度、年龄等个体差异放大噪声。

## 实验设计（优化）
先动物整链，设**中间机制终点**（下丘脑 SIRT1 活性、血浆外泌体信号）连接"干预→下游"；人体先做**机制臂**（单次 FUS 后测 HRV、血浆标志物时间曲线）再进疗效 RCT；用交叉设计控制个体差异；预设亚组（年龄、基线炎症、睡眠质量）分层分析；多终点多重比较采用 FDR 校正。

## 路线图
Phase 0（0–3 月）：仿真、剂量、靶点确认 → Phase 1（3–12 月）：动物整链与安全性 → Phase 2（12–24 月）：人体 I 期安全 + 机制臂 → Phase 3（24–48 月）：双盲 RCT，主终点=衰老时钟+炎症谱，次要终点=HRV/睡眠/认知 → 正性结果进入多中心长期随访与监管申报。
