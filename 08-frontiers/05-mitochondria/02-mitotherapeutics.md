# 专题二：线粒体靶向药物

## 一、机制

线粒体靶向药的逻辑从"补充供能"升级为"结构修复 + 信号重编程"。心磷脂（cardiolipin）是线粒体内膜特征磷脂，与细胞色素 c 结合维系 ETC 超复合物；衰老/缺血时心磷脂氧化丢失→超复合物解体→ROS 外泄→mPTP 开放→细胞死亡。干预锚点即此：稳定心磷脂、抑制 mPTP、重建 NAD+/PGC-1α 信号轴。

## 二、技术方案

1. **elamipretide（SS-31）**：D-精氨酸四肽，选择性结合心磷脂，恢复其与 CCO 的结合、抑制 mPTP 开放；
2. **MOTS-c**：线粒体 DNA 短开放阅读框编码的线粒体衍生肽，调节 AMPK/Akt 通路与氨基酸代谢、改善胰岛素敏感性；
3. **辅酶 Q10 / MitoQ**：亲脂阳离子使抗氧化剂富集于内膜，兼具电子穿梭与 ROS 清除；
4. **NAD+ 前体（NMN/NR）**：提升 NAD+，激活 SIRT1→PGC-1α，联动线粒体生物发生与自噬；
5. **运动模拟物 AICAR**：AMPK 激动剂，模拟运动对线粒体的适应信号；
6. **线粒体移植**：将健康自体/同种异体线粒体导入受损细胞，直接补充功能性细胞器。

## 三、证据

- SS-31：2025 年获美国首批（线粒体相关适应证），临床前与 I/II 期显示改善老龄心肌与骨骼肌功能（Aging Cell 2025）；
- MOTS-c：临床前改善代谢稳态、增强运动耐力与肌纤维类型转换；
- CoQ10：对心衰与他汀相关肌痛显示部分获益；MitoQ 抗氧化明确但临床终点获益有限；
- NMN/NR：人体试验确认提升血液 NAD+，但功能终点结果不一；
- AICAR：临床前可靠模拟运动效应，人体证据不足；
- 线粒体移植：临床前改善缺血心肌，进入早期探索。

## 四、瓶颈

①阳离子靶向导致线粒体内富集浓度难精确控制；②抗氧化剂可能"钝化"有益的信号 ROS（mitohormesis 双刃剑）；③NAD+ 前体肝首过效应与组织分布不均；④线粒体移植的供体来源、免疫原性与移植后存活率；⑤多数药物缺乏硬终点（生存/功能）RCT。

## 五、实验设计

- 双盲 RCT：以 6 分钟步行距离、射血分数、握力为终点，分层纳入老龄肌少症/射血分数保留心衰人群；
- 生物标志物：血浆 mtDNA 拷贝数、GDF15、NAD+ 代谢组、心磷脂氧化产物；
- 线粒体移植：iPSC 来源同种异体线粒体 + 同位素/荧光示踪验证体内分布与整合。

## 六、路线图

1–3 年：SS-31 扩大适应症与真实世界证据；3–5 年：NAD+ 前体 + MOTS-c 组合方案、剂型优化；5–10 年：按"线粒体表型分型"（异质性/NAD+ 水平/动力学状态）指导个体化用药，线粒体移植进入临床。
