# 营养与禁食 Nutrition & Fasting

## 核心概念

营养是抗衰的第一层干预：**吃多少、何时吃、吃什么**直接影响 AMPK/mTOR/胰岛素信号——三大营养感应通路的平衡决定代谢健康与寿命。

## 分子机制

- **热量限制（CR）**：能量摄入↓ → AMPK↑（能量感应器）→ NAD⁺/SIRT1↑ → 自噬↑（清理受损细胞器）→ 线粒体质量↑
- **mTOR 抑制**：氨基酸/生长因子充足时 mTOR 激活（促合成代谢）；限制时 mTOR↓ → 蛋白稳态↑、细胞衰老↓
- **胰岛素/IGF-1 轴**：高糖/高蛋白持续刺激 → IGF-1↑ → 加速衰老信号；限制后 IGF-1↓ → FOXO 激活 → 抗氧化↑
- **间歇性禁食（IF）**：16:8 / 5:2 产生"代谢切换"（葡萄糖→酮体），激活酮体信号（β-羟基丁酸抑制 HDAC、激活 FOXO3a）

## 证据等级

| 干预 | 证据 | 说明 |
|---|---|---|
| 热量限制 | 动物实锤（延寿 20-40%）；灵长类有争议 | 恒河猴实验（NIA vs Wisconsin 结果不一） |
| 间歇性禁食 | 中-高（人体代谢改善明确） | 体重、胰岛素敏感性、血压改善 |
| 生酮/低碳水 | 中（代谢疾病有效） | 长寿证据不足 |
| 蛋白质限制（尤其蛋氨酸） | 动物证据 | 与 CR 部分重叠 |

## 临床/实验证据

- 16:8 禁食：人体研究显示改善胰岛素敏感性 20-30%、血压↓、炎症标志物↓
- 长期热量限制（CALERIE 试验）：健康人 CR 25% 两年 → 代谢率↓、氧化应激↓、衰老标志改善
- 二甲双胍（AMPK 激活剂）：TAME 试验正在进行（抗衰适应症 III 期）

## 与 NO 通路的联系

- 热量限制/禁食 → AMPK → eNOS 磷酸化激活 → NO↑（血管舒张）
- NO ↔ Sirt1 正反馈：CR 升 NAD⁺ → Sirt1 激活 → eNOS 去乙酰化激活 → NO↑ → 再增强 Sirt1
- β-羟基丁酸（酮体）本身可促进 NO 生物利用度

## 开放问题

- 长期 IF 的肠道菌群适应性
- CR 在人类的"剂量"（多少%最安全可持续）
- 个体差异（基因型×饮食交互）
