# 普通人日常抗衰执行清单

> 设计原则：低成本、可坚持、有证据。按"地基 → 支柱 → 升级"三层，从免费的开始。

## 第一层：地基（免费，证据最强）

### 1. 运动处方（NO 通路最强激活剂）

```
每周：
  有氧 3-4 次 × 30-45 分钟（快走/慢跑/骑行，中等强度）
  高强度间歇（HIIE）2 次 × 15-20 分钟（30 秒冲 + 90 秒慢，8-10 组）

机制：剪切应力 → eNOS-Ser1177 磷酸化 → NO↑
证据：I 级（最强）；HIIE 改善 FMD 达 8.25%
```

### 2. 膳食硝酸盐（每天吃的"NO 补充剂"）

```
每日：甜菜根汁 250ml 或甜菜根 1 个（400-800mg 硝酸盐）
      深绿叶菜 1-2 份（菠菜/芝麻菜/芹菜）
⚠️ 不要用含氯漱口水！（口腔菌是硝酸盐→NO 的工厂）

机制：硝酸盐 → 口腔菌 → 亚硝酸盐 → NO（不依赖 eNOS）
证据：II 级（100+ 人体试验）；血压降 4-10mmHg、运动耐力↑10-15%
```

### 3. 睡眠（大脑排毒 + SIRT1 供能）

```
每晚 7-9 小时；固定作息；睡前 1 小时不用手机；卧室黑暗凉爽
机制：睡眠期糖淋巴系统排毒（清除 β-淀粉样蛋白）；NAD⁺/SIRT1 节律恢复
```

### 4. 热量限制 / 间歇性禁食

```
可选：16:8 间歇禁食 / 5:2 轻断食 / 每餐八分饱
机制：能量限制 → AMPK↑ → NAD⁺/SIRT1↑ → 自噬↑ → 线粒体质量↑
证据：动物延寿 20-40%；人体代谢改善明确
```

### 5. 压力管理（迷走神经 + 抗炎）

```
每日 10-15 分钟：4-7-8 呼吸法 / 冥想 / 傍晚散步
机制：副交感激活 → 皮质醇↓ → NO 生物利用度↑；HRV↑ = 长寿标志
```

## 第二层：支柱（低成本，证据中高）

### 6. 中医药调理（益气活血 → NO 通路）

```
可选（需中医师辨证）：人参/黄芪（益气）、丹参/三七/川芎（活血）、
  枸杞/茯苓（药食同源）；参考生脉饮、复方丹参类方义
注意：阴虚火旺不宜温补；出血倾向慎用活血药；医师指导
```

### 7. 光照补充（PBM 红光，可选升级）

```
家用红光/近红外设备：630-670nm + 810-850nm，10-100 mW/cm²
每次 15-30 分钟，每周 4-5 次
诚实说明：家用设备作用于皮肤/浅表；"经颅深部逆龄"是研究前沿
证据：皮肤/局部有 RCT；脑/全身抗衰证据弱
```

### 8. 补充剂（审慎选择，非必需）

| 补充剂 | 机制 | 证据 | 建议 |
|---|---|---|---|
| NMN/NR | NAD⁺ 前体 → SIRT1 | 中 | 可选，正规产品，低剂量 |
| 甜菜根粉 | 硝酸盐→NO | 高 | 5-10g/日 |
| 维生素 D3+K2 | 骨骼/血管 | 中-高 | 缺则补 |
| Omega-3 | 抗炎 | 中-高 | 每周 2 次深海鱼 |
| 槲皮素 | 抗氧化/senolytic 辅助 | 中 | 食物来源更稳 |
| 镁 | 睡眠/线粒体 | 中 | 睡前补 |

## 第三层：升级（前沿，审慎跟进）

```
已临床验证的抗衰药物/技术（2026 现状）：
  · senolytic（达沙替尼+槲皮素 D+Q）——清除衰老细胞，临床试验中
  · senomorphic（Rentosertib 类）——让衰老细胞安静，III 期临床
  · 二甲双胍（TAME 试验）——抗衰适应症 III 期
  · 部分重编程（Yamanaka 因子）——动物逆转衰老，人体未开始

⚠️ 均为处方药/临床试验，普通人不能也不应自行使用
```

## 每日执行模板

```
早晨：甜菜根汁 250ml + 10 分钟日光
白天：有氧 30 分钟或 HIIE 15 分钟 + 深绿叶菜 + 16:8 进食窗口
      每 45 分钟起身活动 2 分钟
傍晚：5-10 分钟深呼吸/冥想 +（可选）红光设备 15-30 分钟
晚上：睡前 1 小时不用手机，23:00 前入睡，睡足 7-8 小时
每周：2 次 HIIE + 2 次深海鱼 +（可选）NMN 250-500mg
```

## 预期效果（诚实）

| 时间 | 变化 |
|---|---|
| 2-4 周 | 血压↓、精力↑、睡眠改善 |
| 1-3 月 | 运动耐力↑、血管功能改善、炎症指标↓ |
| 6-12 月 | 体脂↓、代谢改善、HRV↑ |
| 长期 | 延缓血管老化、降低慢病风险 = 延长健康寿命 |

**注意**："生物学年龄逆转 3-6 岁"是药物级效果，生活方式达不到；但生活方式能让"功能年龄"明显小于"日历年龄"——这是普通人最现实的"逆龄"。
