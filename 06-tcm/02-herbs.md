# 单味药机制：参丹七芪及益气活血代表药物的分子药理学深潜

## 核心概念

益气活血的代表性单味药——人参、丹参、三七、黄芪（参丹七芪），及川芎、葛根、当归、银杏叶——在分子层面以不同的作用层次共同靶向 **NO 通路**（一氧化氮 Nitric Oxide）与内皮健康。中药活性成分对 NO 系统的干预可归纳为三大策略：**上游激活**（经 PI3K/Akt、AMPK 等激酶磷酸化 eNOS-Ser1177，增加 NO 合成）、**NO 保护**（强效抗氧化清除自由基与 ONOO⁻，减少 NO 灭活、恢复生物利用度）、**血管舒缩与凝血调节**（直接作用于平滑肌钙信号、抑制血小板 TXA₂/αIIbβ3 通路）。这种"补原料（益气）+ 增活性（活血）"的多靶点、多通路干预，与 NO 基础生物学中"维持生理 NO 而非一味升高"的原则高度一致（详见 01-foundations/03-no-basics.md）。本库的核心洞察是：中药单体不等于提取物，提取物不等于全药；每味药需在**化学成分层级—证据等级—生物利用度**三个维度上被独立审视，才能避免把离体机制误读为临床疗效。

## 分子机制全链条

### 一、人参（Panax ginseng）——人参皂苷与 PI3K/Akt/eNOS

人参的核心活性成分为**人参皂苷（Ginsenosides）**，属达玛烷型三萜皂苷，按苷元分为**原人参二醇型**（Rb1、Rb2、Rc、Rd）与**原人参三醇型**（Rg1、Re、Rf、Rg2）。其中 **Rg1**（三醇型）与 **Rb1**（二醇型）是研究最充分的两种，二者靶向内皮信号的能力有别。

**Rg1 → eNOS 激活的分子链**：

```
Rg1 ──结合细胞膜/胞内受体──► PI3K ──► PIP3 ──► Akt (Thr308/Ser473 磷酸化)
                                              │
                                              ▼
                                     eNOS-Ser1177 磷酸化 (激活位点)
                                              │
                                              ▼
                              L-Arg ──eNOS──► NO ↑ ──► sGC/cGMP/PKG
                                              │
                                    ┌─────────┴─────────┐
                                    ▼                   ▼
                              血管舒张            抗血小板/抗平滑肌增殖
```

Rg1 还通过抑制 **PTEN**（PI3K 负调控因子）和上调 **caveolin 的解离**增强 eNOS 与小窝蛋白 caveolin-1 脱离而激活（详见 01-foundations/03-no-basics.md 中 eNOS 亚细胞定位机制）。机制研究表明，Rg1 可剂量依赖地上调内皮细胞 eNOS mRNA 与蛋白表达，并促进 NO 释放。

**Rb1 → 抗氧化/抗凋亡链**：Rb1 主要经**抗氧化与抗凋亡**通路发挥作用，而非直接强效激活 eNOS：上调 SOD、过氧化氢酶（CAT）、HO-1 等抗氧化酶，抑制 ROS 生成；激活 Nrf2/ARE 抗氧化应答；抑制线粒体凋亡通路（下调 Bax/Bcl-2 比值、抑制细胞色素 c 释放、抑制 caspase-3 激活）。Rb1 对缺血再灌注模型的保护涉及"eNOS 磷酸化恢复 + 氧化应激抑制"双通道，其抗炎作用经抑制 NF-κB 核转位、下调 TNF-α/IL-6 实现。

**人参皂苷与长寿网络**：Rg1/Rb1 可激活 **AMPK**（AMP/ATP 比值升高与 LKB1 磷酸化），继而磷酸化 eNOS 并上调 **SIRT1**；Rb1 还能上调 FOXO3a 与抗氧化靶基因——构成"人参皂苷→AMPK/SIRT1→eNOS"与 NAD+ 长寿网络的正向耦合。人参皂苷 Re、Rd 亦有激活 AMPK、改善胰岛素敏感性的证据。人参的**适应原（adaptogen）作用**表现为对下丘脑-垂体-肾上腺轴的温和调节与能量代谢优化，在应激下维持稳态。

### 二、丹参（Salvia miltiorrhiza）——丹参酮 IIA 与丹酚酸 B

丹参的活性成分分两大类：**脂溶性二萜醌类**（丹参酮 IIA 及其氧化物丹参酮 IIA 磺酸钠）与**水溶性酚酸类**（丹酚酸 B、丹酚酸 A、原儿茶醛、迷迭香酸）。

**丹参酮 IIA（Tanshinone IIA）→ eNOS/NO 链**：丹参酮 IIA 脂溶性、可穿透内皮膜，直接上调 eNOS 表达与活性、促进 Ser1177 磷酸化，增加 NO 生成；同时抑制 NADPH 氧化酶（NOX）的 p47phox 亚基膜转位，减少 O₂⁻ 生成——既"增产"又"防灭活"。

**丹酚酸 B（Salvianolic acid B, SalB）→ 抗氧化保护链**：丹酚酸 B 是强效自由基清除剂，其酚羟基可直接清除 O₂⁻、羟自由基与脂质过氧自由基，防止 NO 与 O₂⁻ 反应生成 **ONOO⁻**（过氧亚硝酸盐，扩散极限速率 ~10⁹–10¹⁰ M⁻¹s⁻¹）——这使 NO 的生物利用度不被"氧化灭活"吞噬。SalB 还抑制 NF-κB 炎症通路、下调 VCAM-1/ICAM-1，阻断单核细胞黏附（抗动脉粥样硬化关键环节）。

**隐丹参酮（Cryptotanshinone）→ 抗血小板/抗凝**：隐丹参酮抑制血小板活化与 TXA₂ 释放、降低 P-selectin 表达；丹参酮类对凝血系统的温和抗凝作用（抑制凝血酶诱导的血小板聚集）是丹参"活血"的分子基础之一。**丹参多酚酸盐注射剂**（以丹酚酸为主）在国内广泛用于冠心病/脑梗死的辅助治疗，其升高循环 NO、降低 ET-1、改善 FMD（血流介导舒张）已有小样本 RCT 支持。

### 三、三七（Panax notoginseng）——三七总皂苷（PNS）

三七的活性成分为**三七总皂苷（PNS）**，其中**三七皂苷 R1（Notoginsenoside R1）**与**人参皂苷 Rg1/Rb1**（三七与人参同属五加科，皂苷谱重叠）是核心。

**PNS → 抗血小板/NO 链**：

```
PNS (Rg1/Rb1/R1)
      │
      ├──► 抑制血小板活化: 降低 TXA₂、P-selectin、αIIbβ3 活化 → 抗聚集
      ├──► 抗炎: 抑制 NF-κB → 下调 IL-6/TNF-α、VCAM-1
      ├──► 促血管新生: 上调 VEGF、eNOS → 侧支循环建立
      └──► eNOS 激活: PI3K/Akt → Ser1177 磷酸化 → 轻度血管舒张
```

**与阿司匹林比较**：机制研究表明 PNS 与阿司匹林（抑制 COX-1→TXA₂）作用位点部分重叠但不完全相同——PNS 更强调多途径抑制血小板活化（包括 P2Y12、αIIbβ3 通路）而非单一阻断 COX。PNS 抗血小板强度弱于阿司匹林，但**出血风险更低、无胃肠道损伤**，因此在低出血风险人群中常作为阿司匹林的替代或辅助（需监测）。PNS 的促血管新生作用（上调 VEGF/eNOS、动员内皮祖细胞）是"活血生新"的分子基础，对缺血性心脑血管病有独特价值。

### 四、黄芪（Astragalus membranaceus）——黄芪多糖（APS）与黄芪甲苷 IV（AST IV）

黄芪活性成分两大核心：**黄芪多糖（Astragalus polysaccharide, APS）**与**黄芪甲苷 IV（Astragaloside IV, AST IV）**（四环三萜皂苷）。

**APS → AMPK/免疫双向链**：

```
APS ──► AMPK 激活 (LKB1/AMP 依赖)
        ├──► eNOS 磷酸化 → NO ↑ (益气→内皮)
        ├──► PGC-1α/线粒体生物发生 → 内皮代谢改善
        └──► 免疫双向调节:
              ├── 免疫低下: 增强巨噬细胞吞噬、NK 活性、T/B 增殖
              └── 炎症过度: 抑制促炎因子 (IL-6/TNF-α)、抑制 iNOS 过度表达
```

**AST IV → PI3K/Akt/eNOS 链**：黄芪甲苷 IV 是较 APS 更强效的内皮保护成分——直接激活 **PI3K/Akt** 磷酸化 eNOS-Ser1177、上调 eNOS 表达，同时抑制 NOX 源性 ROS、保护线粒体。机制研究表明 AST IV 在缺血再灌注、糖尿病血管病变、压力超负荷心肌肥大模型中均改善内皮功能与心脏功能。

**黄芪与端粒/抗衰**：黄芪甲苷 IV 在细胞与动物模型中可**上调端粒酶（Telomerase, TERT）表达与活性**、减少端粒缩短，保护造血干细胞与内皮祖细胞衰老；这一"端粒保护"通路与 12 大衰老标志中的**端粒耗竭（Telomere attrition）**直接对应（详见 01-foundations/01-aging-hallmarks.md）。黄芪对免疫的双向调节还与"**免疫衰老（immunosenescence）**"标志相关——改善胸腺输出与 T 细胞功能、减轻慢性炎症（inflammaging）。

### 五、其他补气活血药

**当归（Angelica sinensis）**：核心成分为**阿魏酸（Ferulic acid）**与藁本内酯（Ligustilide）。阿魏酸清除自由基、抑制 LDL 氧化、上调 eNOS/NO，并抑制血小板 TXA₂——"养血活血"（补血兼活血）的代表药。

**川芎（Ligusticum chuanxiong）**：核心成分为**川芎嗪（Ligustrazine, tetramethylpyrazine）**。川芎嗪为**钙通道拮抗剂**，抑制血管平滑肌与血小板胞内 Ca²⁺ 升高 → 舒张血管、抑制血小板活化；还抑制 TXA₂ 合成、改善微循环与红细胞变形性。"行气活血"的即刻舒缩调节使其常作复方中的"动药"。

**葛根（Pueraria lobata）**：核心成分为**葛根素（Puerarin）**。葛根素激活 eNOS 经 PI3K/Akt 增加 NO 生成、扩张冠脉与外周血管、降低血液黏度；其雌激素样效应与 β 受体阻滞样作用兼有。与川芎类似，偏重"行气"的即时血管调节。

**银杏叶（Ginkgo biloba）**：核心成分为**银杏内酯（Ginkgolides）**（PAF 受体拮抗，抗血小板）与**银杏黄酮**（强抗氧化）。银杏叶提取物（EGb761）可上调 eNOS、抗血小板、改善脑血流，广泛用于认知与循环障碍。

## 证据分级

### 证据等级框架

| 现象 | 证据等级 | 关键文献/依据 |
|---|---|---|
| 人参皂苷 Rg1/Rb1 激活 PI3K/Akt→eNOS-Ser1177、升 NO | 实锤（体外/离体） | Leung KW, Ng TB. *Chin Med* 2013；多项内皮细胞/主动脉环实验 |
| Rg1/Rb1 缺血再灌注模型恢复 eNOS 磷酸化、缩小梗死 | 动物支持 | 大鼠缺血再灌注、心脏梗死模型 |
| 人参皂苷激活 AMPK/SIRT1 | 强关联（机制） | 代谢研究、SIRT1 通路文献 |
| 人参在健康/心血管人群升高 NO、改善 FMD | 中等（人体观察/小 RCT） | 小型随机对照，样本量普遍 30–100 人 |
| 丹参酮 IIA 上调 eNOS、丹参滴丸升高冠心病患者血清 NO | 实锤（体外）+ 中等（人体） | 多项细胞/动物研究 + 小样本 RCT |

| 丹参多酚酸盐注射剂改善急性冠脉综合征内皮功能 | 中等（人体 RCT） | 国内多中心研究，样本偏小 |

| PNS 与阿司匹林抗血小板比较 | 中等（人体观察） | 对照试验，出血风险评估 |
| 黄芪多糖激活 AMPK、黄芪甲苷 IV 激活 PI3K/Akt/eNOS | 实锤（体外/动物） | Ma X et al.；AST IV 系列研究 |
| 黄芪甲苷 IV 上调端粒酶/TERT、保护内皮祖细胞衰老 | 动物支持 | 细胞与动物衰老模型 |
| 黄芪多糖双向免疫调节 | 强关联（体外/动物） | 免疫细胞实验、免疫缺陷模型 |
| 川芎嗪钙拮抗、葛根素 eNOS 激活 | 实锤（体外）+ 中等（复方人体） | 平滑肌/内皮细胞实验；多为复方研究 |
| 银杏内酯 PAF 拮抗、EGb761 上调 eNOS | 实锤（体外）+ 强人体 | EGb761 认知研究较多 |

### 证据分级要点

- **体外/离体实验证据密度最高**：所有上述成分均有扎实的细胞/主动脉环实验证明其 NO 通路机制，但这些证据**无法外推为临床疗效**。
- **人体证据普遍处于"中等"水平**：多为小样本（30–150 人）短期 RCT 或观察性研究，以**替代终点**（血清 NO、ET-1、FMD、炎症标志物）为主，缺乏以心血管硬终点（心梗、卒中、死亡）为目标的长期大样本试验——通心络 CTS-AMI 研究（大样本 RCT）属复方层面的例外，详见 06-tcm/03-formulas.md。
- **证据落差最大的环节是"成分→全药"**：单体的分子机制最扎实，但提取物/全药的生物利用度极低（皂苷、酚酸口服吸收差、首过效应强），导致"离体高效、体内打折"的普遍现象。

## 临床/实验证据细节

### 人参（Rg1/Rb1/人参提取物）

- 内皮细胞实验：Rg1（1–100 μM）剂量依赖地上调 eNOS 磷酸化与 NO 释放；Rb1（10–100 μM）激活 Nrf2/HO-1 抗氧化通路。
- 动物：大鼠脑缺血再灌注模型，Rg1 预处理显著减小梗死面积、恢复梗死区 eNOS 磷酸化；心肌缺血模型 Rb1 缩小梗死范围并改善再灌注后血管舒张功能。
- 人体：小型 RCT 显示人参提取物在健康老年人与 2 型糖尿病患者中升高循环 NO、改善内皮依赖性血管舒张与胰岛素敏感性；剂量多为人参皂苷 100–400 mg/d。心血管保护的人体证据为中等水平，尚缺硬终点试验。
- 生物利用度：人参皂苷口服生物利用度低（Rg1 ~1–2%），主要经肠道菌群转化为次级代谢物（如 Rg1→R1 人参加减），其体内效应可能部分经代谢物中介。

### 丹参（丹参酮 IIA/丹酚酸 B/复方丹参滴丸）

- 细胞/动物：丹参酮 IIA（1–10 μM）上调 eNOS、抑制 NOX 源性 O₂⁻；丹酚酸 B 清除自由基、防止 NO 氧化灭活；丹参酮 IIA 磺酸钠在脑缺血模型中改善神经功能。
- 人体：复方丹参滴丸在冠心病患者中多项小 RCT 显示升高血清 NO、降低 ET-1、改善 FMD 与运动耐量；丹参多酚酸盐注射剂在急性冠脉综合征/不稳定心绞痛患者中改善内皮功能与炎症标志物。
- **注意**：这些 RCT 多由国内团队开展、样本量有限（50–300 人）、随访期短，证据质量达不到国际主流心血管指南的强推荐级别；丹参制剂的心血管硬终点获益证据来自复方（如通心络）而非单味丹参。

### 三七（PNS/三七皂苷 R1）

- 血小板功能：PNS（0.1–1 mg/mL）抑制 ADP、胶原、花生四烯酸诱导的血小板聚集，降低 TXA₂ 与 P-selectin；R1 促血管新生（上调 VEGF/eNOS）在缺血肢体模型中显著。
- 与阿司匹林比较：小样本对照显示 PNS 抗血小板效力约当阿司匹林 50–70%，但出血时间延长较轻、胃肠道不良反应少；适合低出血风险人群替代/辅助，需个体化监测。
- 生物利用度：PNS 口服吸收差，临床多经静脉给药（血塞通/血栓通注射剂）或复方口服制剂给药；口服需注意剂量-反应曲线与个体差异。

### 黄芪（APS/AST IV）

- 细胞/动物：APS 激活 AMPK、改善内皮糖代谢与 eNOS 活性；AST IV（1–50 μM）经 PI3K/Akt 激活 eNOS、抗缺血再灌注损伤、抑制心肌肥大。
- 端粒/抗衰：AST IV 在衰老内皮细胞模型中上调 TERT、减少端粒缩短、延缓复制性衰老；在造血干细胞衰老模型中保护干性。
- 人体：黄芪提取物在代谢综合征人群中改善胰岛素敏感性、降低炎症标志物；免疫调节在老年人群（免疫低下）与肿瘤放化疗后（增强免疫）有观察性支持。**人体证据以免疫与代谢替代终点为主，抗衰硬终点（端粒长度、健康寿命）证据仍属早期。**

### 其他（阿魏酸/川芎嗪/葛根素/EGb761）

- 阿魏酸：抑制 LDL 氧化、上调 eNOS，当归在"补血"语境下改善循环与造血。
- 川芎嗪：钙拮抗、舒张脑血管，常与丹参配伍用于缺血性脑血管病；人体证据多为复合制剂研究。
- 葛根素：扩张冠脉、降血液黏度，其 eNOS 激活与雌激素样效应在离体实验扎实。
- 银杏叶 EGb761：上调 eNOS、PAF 拮抗抗血小板；认知改善有中等强度人体证据，但部分大型试验结果不一致。

## 中药单体 vs 提取物 vs 全药：三层证据不可混淆

对益气活血中药的循证解读，最大的方法学陷阱在于**混淆三个层级**：

| 层级 | 定义 | 证据特点 | 代表 |
|---|---|---|---|
| 单体（Monomers） | 单一纯化合物（如人参皂苷 Rg1、丹参酮 IIA） | 机制最清晰、体外/动物证据最扎实；但体内浓度难达、代谢未知 | Rg1、丹酚酸 B、AST IV、川芎嗪 |
| 提取物（Extracts） | 特定溶剂富集的成分群（如三七总皂苷 PNS、丹参多酚酸盐、EGb761） | 成分谱相对稳定、可标准化；证据介于单体与全药之间 | 复方丹参滴丸、血塞通、EGb761 |
| 全药/复方（Whole herb / Formula） | 原药材或按中医理论配伍的复方 | 与临床真实使用场景一致；但成分复杂、批次差异大、机制归因难 | 人参饮片、参丹七配伍、通心络 |

三层之间不能直接外推：**单体在 μM 级离体有效，不等于口服全药在体内达到有效浓度**。人参皂苷 Rg1 口服生物利用度仅约 1–2%，经肠道菌群代谢为次级皂苷后才部分吸收——这意味着口服人参的体内活性分子可能并非 Rg1 本身，而是其代谢产物，离体实验的"主成分归因"因此存在失真风险。丹酚酸、黄芪甲苷同样面临强首过效应与低口服吸收。反过来说，全药的临床获益（如通心络 CTS-AMI 研究的硬终点改善）也无法归因于单一成分——这正是"复方多靶点"与"单体靶点清晰"之间永远存在的解释张力。

**药物相互作用与出血风险**：活血化瘀类中药（三七、丹参、银杏、当归、川芎）与抗凝/抗血小板药物联用存在**叠加出血风险**，这是有真实临床报告支撑的安全问题：丹参与华法林联用可显著升高 INR 与出血事件；银杏叶制剂与阿司匹林/华法林联用有颅内出血个案报告；三七与抗凝药联用需监测出血倾向。人参虽非活血药，但与华法林联用可因 CYP3A4/糖皮质激素样效应干扰抗凝强度。原则：**服用任何抗凝/抗血小板药物者，使用活血类中药前必须咨询医师并加强监测**，不可自行叠加。

## 与 NO / NAD+ / 长寿网络联系

本库视角下，参丹七芪等益气活血药对 NO 通路的干预**不是孤立的血管效应，而是长寿网络的正向耦合点**：

```
                        ┌──── NAD+/SIRT1 长寿网络 ────┐
                        │                              │
益气活血药 ──► AMPK ──► SIRT1 ──► eNOS 去乙酰化激活 ──► NO
 (APS/AST IV)    │                       ↑
                 │                       │
                 └──── 人参皂苷 ──────────┘
                                      │
              NO ──► sGC/cGMP/PKG ──► 血管舒张/抗栓
              NO ──► AMPK/SIRT1 (正反馈) ──► 线粒体生物发生
              NO 防灭活 (丹酚酸抗氧化) ──► 生物利用度↑
```

具体耦合层次：

1. **eNOS 激活是共同汇聚点**：人参（Rg1）、黄芪（AST IV）、葛根（葛根素）均经 PI3K/Akt 磷酸化 eNOS-Ser1177；丹参酮 IIA 上调 eNOS 表达——共同指向"益气=增强 NO 合成能力"。
2. **NO 保护是"活血"的本质**：丹参（丹酚酸B）、三七（抗血小板）、川芎（钙拮抗）通过抗氧化、抗炎、抗血小板保护已生成的 NO，防止其被 O₂⁻ 灭活为 ONOO⁻——"活血=提高 NO 生物利用度"。
3. **AMPK/SIRT1/NAD+ 耦合**：黄芪多糖、人参皂苷激活 AMPK→SIRT1→eNOS 与 NAD+ 长寿网络形成正反馈，与热量限制、运动的内皮益处（详见 02-vascular/02-dietary-nitrate.md）机制重叠。
4. **端粒与免疫衰老**：黄芪甲苷 IV 上调 TERT、黄芪多糖双向免疫调节，直接对应 12 大衰老标志中的端粒耗竭与免疫衰老两环。
5. **双刃剑原则**：所有益气活血药都应遵循 NO 的"低浓度保护、高浓度硝化应激"悖论（详见 01-foundations/03-no-basics.md）——目标不是无限升高 NO，而是**恢复 eNOS 生理活性、抑制 iNOS 过度表达**（黄芪免疫双向调节正体现这一"调而非补"）。

---

## 干预方向与可执行建议

1. **优先保留证据最扎实的组合**：人参+丹参+三七（参丹七）经 NO 通路构成"上游激活（人参）—维持活性/抗氧化（丹参）—下游抗栓（三七）"的完整链条，是益气活血复方的分子基础；可优先采用复方制剂（如复方丹参滴丸、通心络）而非单味滥用。

2. **口服生物利用度是最大短板**：皂苷、酚酸口服吸收差，临床获益依赖长期规律使用或静脉给药（须在医师指导与适应证内）；自行大量服用皂苷类补剂意义存疑。

3. **安全性优先**：活血药（三七、丹参、银杏、当归）与抗凝/抗血小板药（阿司匹林、氯吡格雷、华法林、新型口服抗凝药）联用有**叠加出血风险**，须监测 INR/出血倾向；人参长期大量使用可致"人参滥用综合征"（血压升高、失眠、心悸）；黄芪等补气药对实热/阴虚火旺证不宜。

4. **替代/增效策略**：无出血风险人群可用三七/丹参类温和活血药辅助阿司匹林；配合运动（剪切应力→eNOS）与膳食硝酸盐（绿叶蔬菜、甜菜根，详见 02-vascular/02-dietary-nitrate.md）形成协同。

5. **"调而非补"**：目标是恢复 eNOS 生理功能与 NO 生物利用度，而非追求升高 NO——避免高浓度 iNOS 源性 NO 导致的硝化应激。

---

## 开放问题与争议

1. **成分-全药鸿沟**：单体分子机制扎实，但提取物/全药的生物利用度、代谢与靶向性不清；"有效成分是原皂苷还是肠道代谢物"仍无定论。
2. **剂量-反应与双向调节边界**：人参（兴奋 vs 镇静）、黄芪（免疫增强 vs 抑制）、三七（促循环 vs 抗凝）的"双向调节"在何种剂量、何种机体状态下切换，缺乏精确定量。
3. **抗血小板与出血风险的最优平衡**：PNS/丹参在"强效抗栓"与"安全性"之间如何取舍、与抗凝药联用的安全窗，缺少大规模前瞻数据。
4. **缺硬终点证据**：几乎所有单味药/提取物的人体试验都以替代终点（NO、FMD、炎症标志物）衡量，缺乏以心血管死亡、卒中、健康寿命（healthspan）为终点的长期大样本 RCT。
5. **质量控制与批次差异**：产地、炮制、提取工艺导致成分谱差异大，同一药名不同批次疗效可重复性存疑——这是中药循证化的结构性挑战。
6. **"益气活血"证候分型的分子化**：能否以 ADMA（eNOS 内源抑制剂）、NO 代谢产物、FMD 作为指导用药的生物标志物，尚无定论（详见 06-tcm/01-yiqi-huoxue.md）。
