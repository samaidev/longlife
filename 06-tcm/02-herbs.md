# 单味药机制：益气活血代表药物的分子药理学

## 核心概念

益气活血的代表性单味药包括人参、丹参、三七、黄芪、川芎、葛根。它们在分子层面各自靶向 NO 通路的**上游激活**（eNOS 磷酸化）、**NO 保护**（抗氧化/抗炎）或**血管舒缩调节**（平滑肌舒张），构成"多靶点、多通路"的中药网络药理学特征。

## 分子机制分述

### 人参（Panax ginseng）——Rb1 → PI3K/Akt/eNOS

人参皂苷 **Rb1**（原人参二醇型皂苷）是核心活性成分：与内皮细胞膜受体结合后激活 **PI3K/Akt** 通路，磷酸化 **eNOS-Ser1177** 并促进 NO 释放；同时上调抗氧化酶（SOD、HO-1）并抑制凋亡。动物与离体实验一致显示 Rb1 改善缺血后血管舒张功能。

### 丹参（Salvia miltiorrhiza）——丹酚酸 → eNOS / 抗氧化

丹酚酸类（Salvianolic acid B）与丹参酮 IIA 双途径起作用：直接激活 eNOS 增加 NO 合成，同时作为强效自由基清除剂减少 **NO 的氧化灭活**（保护生物利用度），并抑制 NF-κB 炎症通路。临床上广泛用于冠心病辅助治疗，改善 FMD 与微循环。

### 三七（Panax notoginseng）——PNS → 抗血小板 / 抗炎

三七总皂苷（**PNS**）可抑制血小板活化（降低 TXA₂、P-selectin 表达）、抗炎（下调 IL-6/TNF-α）、促血管新生，并通过 eNOS 通路轻度舒张血管。双向性体现在：低剂量促循环、高剂量抗凝，需注意出血风险。

### 黄芪（Astragalus membranaceus）——多糖 → AMPK / 免疫双向

黄芪多糖（APS）激活 **AMPK**，改善内皮代谢并上调 eNOS；同时具有**免疫双向调节**：免疫低下时增强巨噬细胞与 NK 活性，炎症过度时抑制促炎因子释放。与黄芪甲苷 IV（Astragaloside IV）共同构成益气主力。

### 川芎（Ligusticum）与葛根（Pueraria）——血管舒缩

- **川芎嗪（Ligustrazine）**：钙通道拮抗与 TXA₂ 抑制，舒张脑血管、改善微循环；
- **葛根素（Puerarin）**：β 受体阻滞样作用 + 雌激素样效应，扩张冠脉与外周血管、降低血液黏度。

两药偏重"行气活血"的即刻血管舒缩调节，常作为复方中的"动药"。

## 证据等级

| 药物 | 临床前 | 人体 |
|---|---|---|
| 人参（Rb1） | 高等 | 中等（健康/心血管人群 NO、FMD 改善） |
| 丹参 | 高等 | 中等（RCT 支持，样本偏小） |
| 三七 | 高等 | 中等（抗血小板，需监测出血） |
| 黄芪 | 高等 | 中等（免疫与代谢终点） |
| 川芎/葛根 | 中等 | 中等（多为复合制剂研究） |

## 临床/实验证据

- 人参皂苷 Rb1 在缺血再灌注模型中恢复 eNOS 磷酸化并减小梗死面积；
- 丹参滴丸在冠心病患者中升高血清 NO、降低 ET-1，改善内皮功能（多项小 RCT）；
- 黄芪多糖在代谢综合征人群中改善胰岛素敏感性与内皮标志物。

## 与 NO 通路的联系

六味药均以**恢复 eNOS-NO 轴**为共同药效核心，差异仅在作用层次：人参、黄芪主"益气"——提供上游激活信号（PI3K/Akt、AMPK）；丹参、三七、川芎、葛根主"活血"——保护 NO 生物利用度并直接调节血管张力。这种"上游激活 + 下游保护"的配合正是益气活血复方的分子基础。

## 开放问题

- 有效成分的人体药代动力学与生物利用度（皂苷/酚酸普遍偏低）不明；
- 剂量—反应与"双向调节"（免疫、凝血）的边界不清晰；
- 单药 vs 复方活性差异、成分间相互作用的系统评价不足；
- 缺乏以硬临床终点为目标的长期大型试验。
